## Prospective correction basis

V137 verified both immutable Leah-approved archetype workbook hashes and passed all retained deterministic apparatus/harness tests, then failed hidden semantic calibration on both approved archetypes. Its `distinct represented job` gate improved the class tests but still let each class independently re-parse the raw source. That architecture can simultaneously produce lexical/grammatical census behavior and omit coordinates whose role becomes visible only when the source's represented assertions, participant relations, and structural frames are considered together. It also permits one represented predicate relation to fragment into support/control/embedded pieces and then propagates those primitive errors into compounds.

The demonstrated defect is durable semantic resolution, not the deterministic harness. V138 therefore changes the construction architecture from independent class harvesting to **representation-ledger projection**.

No gold rows, expected counts, evaluator findings, scored predecessor outputs, canonical archetype extracts, case-specific hidden corrections/examples, or sealed holdout content are supplied to the worker.

## Controlling rule

> **READ THE WHOLE SOURCE. FIRST BUILD ONE INTERNAL SOURCE-ORDER LEDGER OF THE MATERIAL ASSERTIONS, CONFIGURATIONS, PARTICIPANT/REFERENT RELATIONS, CHARACTERIZATIONS, ORIENTATIONS, AND STRUCTURAL FRAMES THE SOURCE ACTUALLY REPRESENTS. FREEZE THAT LEDGER BEFORE CLASS EXTRACTION. THEN PROJECT PLACE, TIME, PERSON, OBJECT, LABEL, VERB, AND LOCATOR FROM THE ROLES THOSE SOURCE-STAGED ITEMS PLAY IN THE SHARED LEDGER. DO NOT RUN SEVEN INDEPENDENT WORD-HARVESTING PASSES. DO NOT INVENT A COORDINATE MERELY BECAUSE WORDING CAN BE PARSED AS A CLASS, AND DO NOT DELETE A SOURCE-STAGED COORDINATE MERELY BECAUSE IT IS UNNAMED, LOW-SALIENCE, OR INFERABLE FROM ANOTHER ROW. PRESERVE EXACT SOURCE WORDING AND POSTURE. FREEZE PRIMITIVES, THEN BUILD ONLY THE MATERIALLY DISTINCT LEDGER ASSERTIONS/CONFIGURATIONS THAT RECONNECT THEM.**

## Mission and primitive classes

Produce only a literal lightweight Researcher Inventory candidate from the supplied source.

Primitive classes are exactly:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is richer than a sparse semantic graph and narrower than a lexical, grammatical, or dependency census.

## 1. Construction order — representation ledger first

1. Read the complete source once without extracting primitives.
2. Resolve only strict coreference and source order.
3. Build one internal source-order **representation ledger**. Each ledger entry is one materially distinct source-staged assertion/configuration or one structural frame that organizes such material. Track, as applicable: actors/endpoints, things/content referents, relation identity, characterization, orientation/context, occurrence/participant/referent position, episode/frame, and source posture.
4. The ledger is not an output class and must not contain analyst abstractions, diagnoses, normalized paraphrases, hidden causes, or invented propositions. Use it only to stabilize what the source itself represents.
5. Freeze the ledger before primitive projection. Do not restart from raw tokens separately for each class.
6. Project candidate primitives from ledger roles into PLACE, TIME, PERSON, OBJECT, LABEL, VERB, and LOCATOR using the class rules below.
7. Run cross-class typing/non-substitution and same-class identity/deduplication.
8. Run a ledger coverage floor audit and a lexical/grammar ceiling audit.
9. Freeze primitive membership and exact source strings.
10. Build compounds only from frozen primitives and only for materially distinct ledger assertions/configurations.
11. Run final literal, posture, typing, compound, and isolation audits.

## 2. Ledger admission and granularity

A ledger item survives only when the source itself stages a materially distinct represented assertion/configuration or structural frame at natural lightweight worksheet grain.

Valid ledger material can be local, nested, one-use, uncertain, questioned, negated, remembered, reported, hypothetical, recurring, prospective, colloquial, or figurative. It need not be globally central.

Do not create a ledger item solely because:

- a sentence exists;
- a token has a part of speech;
- a phrase can be nominalized;
- a spatial/temporal/adjectival/verb-like expression appears;
- a parser can isolate a dependency;
- an analyst can infer a cleaner conceptual proposition.

Do not collapse multiple source-staged assertions merely because they share actors, setting, topic, sentence, or event. Do not split one represented relation/configuration into grammatical fragments.

## 3. Projection test for every primitive

A primitive must pass all four tests:

### 3.1 Source establishment
The source itself establishes the coordinate or the source clearly stages the class-native position/frame when unnamed PLACE/TIME is lawful.

### 3.2 Ledger role
The coordinate performs a distinct class-native role in at least one frozen ledger item: site/position, frame, actor/endpoint, thing/content referent, characterization, relation kernel, or orientation/context relation.

### 3.3 Independent addressability
At lightweight worksheet grain a researcher can address the coordinate as its own represented role. It need not be indispensable to reconstruct the story, but it cannot exist only because the worker re-parsed wording.

### 3.4 Natural identity/grain
Use the smallest complete source-native unit that preserves the role. Merge only true same-class same-identity coreference/repetition. Association, co-location, part/whole, container/content, actor/role, episode/subepisode, or semantic relatedness is not identity.

## 4. Primitive ceiling

Suppress material whose only contribution is:

- auxiliary/article/conjunction/argument marking/tense/aspect or other grammar detached from a complete represented relation;
- discourse management with no distinct relation;
- decorative wording with no staged referent/characterization/orientation role;
- duplicate cueing or alternate tokenization of a retained identity;
- worker-created synonym/restatement;
- a whole proposition reified only because it can be named;
- an adjective/adverb/preposition admitted only by lexical form;
- a cross-class reading that is possible but not separately represented.

This ceiling never authorizes deleting a low-salience role that the frozen representation ledger actually requires.

## 5. Cross-class typing and non-substitution

Type from represented ledger role, not surface form.

One source span may support more than one class only when the shared ledger presents genuinely different roles. Never create twins merely because grammar permits multiple descriptions.

A retained class cannot erase a separate role in another class: OBJECT does not absorb LABEL; LABEL does not absorb VERB; PLACE/TIME do not absorb LOCATOR; VERB does not absorb its actor/object merely because they participate in the relation.

## 6. PLACE — structural positions

`PLACE` inventories represented **sites, occurrence positions, and participant/referent positions** used by the shared ledger.

Retain a named or unnamed PLACE when one or more ledger assertions/configurations materially occur, wait, move, are remembered/reported/prospective, or stage a participant/referent at that position.

Rules:

- Physical naming is not required. A source-staged position may be unnamed.
- Co-located positions may remain distinct when the source stages them as different represented positions.
- Contained and broader settings may both survive when each independently structures ledger material.
- A source-treated object's position may qualify when the object is materially staged there.
- The present telling/reflection position may qualify only when the source distinctly stages that present occurrence.

Do not create PLACE from figurative spatial wording, body parts, surfaces, generic directions/spatial nouns, or a motion predicate alone unless the ledger actually stages a site/position role.

For lawful unnamed PLACE use `source_wording = null`, an exact source cue, and neutral mechanical wording.

## 7. TIME — structural frames

`TIME` inventories represented **episodes, periods, phases, transitions, recurrence frames, remembered/reported frames, prospective frames, and present telling/reflection frames** used to organize ledger material.

Retain a TIME when it groups or positions one or more ledger assertions/configurations as a distinct independently addressable frame.

Rules:

- No date/clock/duration/temporal noun is required.
- Short local episodes qualify when distinctly staged.
- Broader and nested frames may both survive when the source organizes material at both levels.
- Intention, recurrence, remembered material, future possibility, and present reflection can establish frames without asserting realization.
- A transition can establish a new frame when represented situation changes materially.

Do not create TIME from tense/aspect alone, every sentence/verb, an isolated date/duration/frequency phrase, or temporal wording that does not independently structure ledger material.

For lawful unnamed TIME use `source_wording = null`, an exact source cue, and neutral mechanical wording.

## 8. PERSON — stable represented actors/endpoints

`PERSON` inventories `B` plus every stable represented human or social actor/group appearing in a ledger role after strict coreference.

Retain actors who act, speak, perceive, are acted upon, possess/receive, serve as source/target/beneficiary/endpoint, or participate in remembered/reported/prospective relations. Minor, offscreen, brief, relational, institutional, or group actors may qualify.

Suppress rhetorical/generic addressees, generic hypothetical roles, pronouns with no stable actor, and true aliases/coreference duplicates.

Order non-speakers by first independent represented participation, not incidental possessive mention alone.

## 9. OBJECT — things and content referents

`OBJECT` inventories source-treated **things and content referents** that occupy a ledger role.

Retain concrete or abstract referents that participate in relations, are positioned, possessed, moved, selected, compared, evaluated, remembered, decided, questioned, pointed back to, or otherwise handled as things/content.

Lawful OBJECTs include concrete items/parts/containers/artifacts/amounts/values/sets/results and abstract decisions/choices/next steps/relations-as-content/conditions/services/mental contents when the source reifies them as referents.

Low salience is not decoration when the ledger materially positions, characterizes, compares, or acts on the referent.

Suppress pure coreferential pronouns, clause shells, propositions invented as nouns by the worker, metacommentary, and grammatical complements with no independent thing/content role.

## 10. LABEL — source-applied characterizations

`LABEL` inventories independently staged **characterizations** active in the ledger: states, qualities, statuses, identities, classifications, evaluations, comparisons, manners, polarities, corrections, rejections, and characterization questions.

Retain the smallest complete source-native wording that carries the characterization role. Preserve negation, question status, uncertainty, contrast, rejection, correction, and material intensity where identity-bearing.

A questioned characterization and a separately staged response/rejection may each survive when they are distinct characterization moves.

Do not create LABEL for every adjective/adverb/modifier. A description qualifies only when the characterization itself is an independently addressable source-applied handle in the ledger.

## 11. VERB — complete minimal relation kernels

`VERB` inventories source-represented **lexical relation kernels**: actions, experiences, cognition, speech, possession, stance, movement, selection, change, social acts, modal/state relations, and other operative predicates.

The unit is the **smallest complete lexical relation kernel that preserves one ledger relation identity**.

Rules:

- Do not independently harvest grammatical verb tokens.
- Keep support, modal, aspectual, control, infinitival, particle, negation, coordinated, or embedded material together whenever removing it changes, reverses, hollows out, or fragments the one represented relation identity.
- A control/support head and its complement are one VERB when the source presents them as one operative relation at worksheet grain; they split only when the source independently stages distinct relations that can each be addressed without reconstructing the other.
- Matrix and embedded predicates split only when they assert materially distinct ledger relations.
- Coordinated predicates split only when the source stages distinct relation jobs; otherwise retain the complete coordinated construction needed for the one relation identity.
- Semantically bound multiword predicates stay together.
- Copular/modal/possessive/locative/state constructions qualify when the relation itself is represented; never emit bare support tokens merely because grammar calls them verbs.
- Speech/cognition/reporting predicates qualify only where the source represents that relation, not as empty discourse scaffolding.
- Questions, negations, hypotheticals, intentions, recurrence, uncertainty, and future language preserve their supplied posture.

Do not swallow independent actor/object/place/time/label/locator arguments into the VERB merely to make a clause. The kernel is complete relation identity, not full sentence membership.

## 12. LOCATOR — independent orientation/context relations

`LOCATOR` inventories independently useful **orientation and context relations** active in the ledger.

These may include physical/relative position, containment, path, direction, approach/departure, origin/destination, proximity/distance, accompaniment, embodied/internal position, recurring/situational context, and materially useful figurative orientation.

Retain a LOCATOR only when orientation/context itself is a distinct source-presented relation. A LOCATOR may overlap PLACE/TIME/VERB only when it contributes a separate ledger role.

Suppress routine possession, recipient/topic marking, argument attachment, bare comparison support, isolated prepositions, and spatial wording that merely restates a PLACE without a distinct orienting relation.

## 13. Literal and posture lock

Preserve source wording character-for-character wherever source text is required. Never synonymize, lemmatize, repair grammar/spelling, normalize dialect, expand contractions, translate, polish, diagnose, or substitute a standard expression.

`source_wording` must be exact source text when explicitly worded. `source_cue` and `order_cue` must be exact source text. Only lawful unnamed PLACE/TIME coordinates may use null `source_wording`.

Questions, uncertainty, hypotheticals, negations, self-corrections, remembered possibilities, reported material, and proposed future actions remain in their source posture. Inventorying does not assert truth or realization.

## 14. `qualities_available`

`qualities_available` is only a mechanical boolean. True means the source supplies material qualities/descriptions associated with the coordinate; false otherwise. Do not create/split/interpret qualities to justify it. `Q` is never a primitive.

## 15. Ordering

Default within-class order is first material source anchor after filtering/coreference.

Tie rules:

- broad/whole setting before dependent/contained setting when introduced together;
- whole before dependent part at the same anchor unless the source stages the part first;
- PERSON follows participation order;
- remembered/reported/hypothetical/future frames remain at source position rather than external chronology.

The apparatus owns canonical IDs and deterministic numbering.

## 16. Ledger coverage floor audit

Replay the frozen ledger, not a fresh lexical scan. For every materially distinct ledger item ask whether all independently addressable class-native roles are represented by frozen primitives.

Specifically check:

- unnamed occurrence/participant/referent positions;
- short local, recurring, remembered, prospective, transition, and present-reflection frames;
- minor but stable actors/endpoints;
- low-salience concrete referents that materially participate;
- abstract choices/decisions/contents/relations treated as things;
- questioned/rejected/corrected source-applied characterizations;
- complete lexical relation kernels including low-salience/control/modal/state constructions;
- independently useful physical/figurative/context orientation relations.

If a ledger role is missing, add the primitive in the correct class. Do not widen a neighboring primitive to compensate.

## 17. Lexical/grammar ceiling audit

For every retained primitive ask:

1. Which frozen ledger item(s) require this class-native role?
2. What exact source material stages that role?
3. Could a researcher address the role without inventing or re-parsing it?
4. Is the unit the smallest complete natural source-native identity?
5. Is it distinct from same-class identities already retained?
6. Would it still exist if I ignored part-of-speech and lexical-class appearance?

If the only support is grammar, lexical form, decoration, duplicate cueing, alternate tokenization, or merely possible interpretation, remove it.

The target is not a count. It is faithful projection from the source's shared representation ledger.

## 18. Compound construction — ledger assertion packets

Freeze primitives before compound work.

A compound is a **selective packet for one materially distinct frozen-ledger assertion/configuration** made only from frozen primitive references.

Create a compound only when:

1. the ledger contains a materially distinct source-staged assertion/configuration;
2. the source binds two or more retained primitives in that item;
3. preserving the binding is useful for reconnecting the inventory;
4. it is not sentence membership, dependency closure, duplicate/subset view, alternate parse, or scene-wide bundling.

Include only primitives actually active in that ledger item: central relation kernel where present; active actors/endpoints and object/content referents; active LABEL/LOCATOR; PLACE/TIME anchors only when the source actively situates that item there.

A nonverbal compound is allowed for a materially distinct characterization/configuration without an operative VERB.

Do not create one compound per primitive, sentence, or verb; every pairwise/transitive closure; subset/superset variants; detached quality fragments; scene-wide mega-bundles; or a compound to repair a missing primitive. If a needed coordinate is absent, return to primitive review before compounds.

Canonical compound IDs/order and `Q` construction remain apparatus-owned.

## 19. Final contrast audit

### Too dense / census failure
Warning signs: bare support verbs; temporal words treated as TIME without structural frame; adjectives treated as LABEL solely because descriptive; clause shells as OBJECT; figurative phrases typed PLACE by spatial sound; isolated prepositions as LOCATOR; multiple fragments of one ledger predicate relation; compounds covering nearly every sentence/dependency.

### Too sparse / summary failure
Warning signs: missing unnamed positions; minor actors; low-salience participating referents; local/recurring/remembered/prospective frames; abstract source-treated choices/relations; questioned/rejected characterizations; complete embedded/control/modal relation kernels; orientation/context relations; or separate source assertions collapsed because they share a scene.

Correct toward the frozen shared representation ledger, not toward target density.

An unscored provisional output from another stateless pass may be used only if the governing apparatus explicitly allows it; it is never gold/evaluator feedback.

The worker must not depend on preexisting canonical IDs or expected outputs.

- mint an APA Blockchain ID;

## 23. Holdout boundary

The calibration worker must never receive the sealed holdout source, holdout answer, holdout score, or derivative example.

The sealed holdout may be opened only by the authorized holdout apparatus after the same finalized contract and saved calibration lineage have repeatedly passed both approved archetypes. If the calibrated lineage passes the one-shot holdout, that lineage is retired. Clean-room certification then requires a brand-new saved agent booted only from this finalized durable contract, with no prior calibration sessions or holdout output, to run the sealed holdout in a new session.

No calibration correction may be made from sealed holdout output.
