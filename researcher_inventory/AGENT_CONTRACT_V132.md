# APA Researcher Inventory Agent Contract V132

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`  
Contract version: `RI-CONTRACT-V132`  
Predecessor: `RI-CONTRACT-V131`  
Effective date: 2026-09-21  
Authority: Leah's standing Researcher Inventory calibration instruction

## Prospective correction basis

The predecessor calibration demonstrated that a single global semantic-unit ledger is not a reliable prerequisite for primitive admission. A global prefilter can suppress lawful low-salience class coordinates while still admitting explicit grammar, description, discourse scaffolding, and clause-shaped material that does not deserve an independent researcher coordinate.

V132 therefore returns the admission decision to the seven primitive classes themselves. Each class performs its own complete whole-source positive pass. Represented situations, episodes, and relations are still used to check coverage and reconstruct compounds, but they do not sit above the primitive layer as a universal permission gate.

No gold rows, expected counts, evaluator findings, scored prior outputs, canonical archetype extracts, case-specific hidden corrections/examples, or sealed holdout content are supplied to the worker.

## Controlling rule

> **READ THE WHOLE SOURCE. FOR EACH PRIMITIVE CLASS, RUN AN INDEPENDENT WHOLE-SOURCE POSITIVE PASS. RETAIN A SOURCE-SUPPORTED CANDIDATE WHEN REMOVING IT WOULD ERASE A MATERIALLY DISTINCT RESEARCHER COORDINATE OF THAT CLASS. DO NOT REQUIRE NARRATIVE IMPORTANCE OR PRIOR ADMISSION TO AN ABSTRACT SEMANTIC-UNIT LEDGER. EQUALLY, DO NOT ADMIT LANGUAGE MERELY BECAUSE IT IS A NOUN, MODIFIER, VERB, PREPOSITION, CLAUSE, OR EXPLICIT PHRASE. TYPE BY THE RESEARCHER QUESTION AND THE JOB THE SOURCE GIVES THE WORDING. AFTER ALL SEVEN CLASS PASSES, USE REPRESENTED SITUATIONS/EPISODES AS A COVERAGE CHECK, FREEZE PRIMITIVES, THEN BUILD ONLY THE SOURCE-PRESENTED MULTI-COORDINATE BINDINGS NEEDED TO RECONNECT THEM.**

## Mission

Produce only a literal lightweight Researcher Inventory candidate from the supplied source.

Primitive classes are exactly:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is a source-faithful coordinate system for later research reconnection. It is neither a plot summary nor a lexical/grammatical census.

## 1. Construction order

Use this order and do not invert it:

1. Read the complete source.
2. Resolve obvious coreference and broad source order.
3. Run a complete positive pass for `PLACE`.
4. Run a complete positive pass for `TIME`.
5. Run a complete positive pass for `PERSON`.
6. Run a complete positive pass for `OBJECT`.
7. Run a complete positive pass for `LABEL`.
8. Run a complete positive pass for `VERB`.
9. Run a complete positive pass for `LOCATOR`.
10. Apply class-local floor/ceiling and deduplication rules.
11. Perform cross-class audit.
12. Run represented-situation/episode coverage replay to detect omissions, not to veto already-valid class coordinates.
13. Lock literal source strings and freeze primitives.
14. Build compounds from frozen primitives only.
15. Run the final floor/ceiling and literal audit.

## 2. Class-local independent-coordinate gate

A candidate is retained when both are true:

### 2.1 Positive entitlement

The source itself supports the candidate, and the candidate performs a materially distinct job for the class being considered.

Ask the class-native researcher question. If removing the candidate would erase a distinct answer to that question that the source actually establishes, the candidate has positive entitlement even when it is local, unnamed, ordinary, dependent, backgrounded, figurative, colloquial, remembered, prospective, or used only once.

### 2.2 Ceiling check

The candidate is not merely:

- function grammar or auxiliary machinery;
- discourse management or a reporting shell with no separate class job;
- an arbitrary clause/proposition reification;
- decorative description with no independent state/coordinate job;
- an ordinary argument/complement marker with no orientation job;
- a duplicate tokenization or same-grain restatement;
- a true alias/coreference duplicate;
- analyst-created abstraction, paraphrase, diagnosis, normalization, or inference.

Explicit wording is evidence, not entitlement by itself.

## 3. No universal semantic-unit prerequisite

Do not first require every primitive to belong to an abstract action/state/scene ledger.

A lawful class coordinate may be a local occurrence position, episode frame, ordinary concrete referent, source-applied state, lexical predicate, or orienting relation whose value is visible only when its own class question is asked.

Conversely, a clause can describe a meaningful situation while some of its internal words still fail every primitive-class gate. Situation meaning does not automatically promote each grammatical piece.

## 4. Represented-situation coverage replay

After all seven class passes, replay the source by represented situations, episodes, interactions, descriptions, comparisons, reflections, and transitions.

Use this replay only to ask:

- did any source-established actor disappear?
- did any concrete/abstract referent needed to reconnect the material disappear?
- did a source-applied state or classification disappear?
- did an operative lexical relation disappear?
- did an orientation/path/context relation disappear?
- did a real occurrence position disappear?
- did a real episode/period distinction disappear?

If yes, return to the relevant class and apply that class's own gate. Do not create a new primitive merely because the replay produced a sentence or proposition.

## 5. PLACE

`PLACE` answers: **where is an occurrence, participant, referent, interaction, or telling positioned?**

Retain source-established named or unnamed occurrence positions, including when materially distinct:

- broad and contained settings;
- the position of a participant during an interaction, wait, conversation, action, or reflection;
- the position of an object when its location is itself represented;
- destinations, departures, arrivals, and other episode positions;
- remembered, reported, prospective, comparison, or present-telling positions;
- lawful unnamed positions supported by an exact source cue.

A PLACE does not need a proper name. For a supported unnamed PLACE, use `source_wording: null`, an exact `source_cue`, and a neutral mechanical tag.

Do not classify a word as PLACE solely because it sounds spatial. A thing, surface, body part, abstract space, comparison vehicle, direction phrase, or location adjective belongs to another class unless it actually functions as an occurrence/participant position.

## 6. TIME

`TIME` answers: **when, during what episode, period, phase, recurrence span, transition, or present-reflection frame does represented material occur?**

Retain materially distinct source-established frames, including unnamed frames when a distinct episode is supported but not named.

Episode boundaries may arise from action/interaction transitions, remembered versus present material, recurring periods, prospective periods, comparison/imagined periods, or other source-established temporal organization.

Do not create TIME merely from tense, a frequency token, a duration phrase, a temporal adverb, or a clause boundary. Group material when the source treats it as the same episode; split when the source establishes a materially different episode/period distinction.

## 7. PERSON

`PERSON` answers: **who or what stable social actor/group participates or is represented?**

Retain `B` plus every distinct source-supported human/social actor or stable group after true coreference when the actor performs a materially represented social, possessive, recipient, beneficiary, source, target, remembered/reported, prospective, comparison, or other participant role.

Minor, offscreen, possessive/relational, remembered, reported, prospective, and institutional actors may qualify. Exclude nonreferential/rhetorical addressees and true coreference duplicates.

## 8. OBJECT

`OBJECT` answers: **what concrete or abstract thing/referent/content does the source treat as a distinct research coordinate?**

Retain source-treated concrete things even when mundane, backgrounded, or used once, when they are materially represented as objects/referents rather than decorative words.

Retain abstract material when the source treats it as a thing/content that can be referred to, possessed, selected, compared, carried forward, or related to other coordinates.

Do not convert every noun phrase, clause shell, reporting content, vague placeholder, metaphor fragment, or discourse noun into an OBJECT merely because grammar allows nominalization. A proposition or whole clause requires source treatment as a distinct referent, not analyst reification.

## 9. LABEL

`LABEL` answers: **what state, value, quality, classification, evaluation, identity, status, manner, polarity, or characterization does the source itself apply?**

Retain the shortest complete source-native wording that preserves the independently reusable characterization. Preserve material negation, uncertainty, contrast, intensity, correction, question-status, attribution, or relational state when it changes the label's identity.

A LABEL may be colloquial, relational, or longer than an adjective when the source-native characterization requires it.

Do not emit every adjective, adverb, colorful description, question, comparison phrase, or evaluative sentence. The wording must carry a distinct source-applied state/characterization that a researcher could reconnect independently rather than merely decorate another coordinate.

## 10. VERB

`VERB` answers: **what distinct lexical action, relation, experience, cognition, possession, stance, movement, state-relation, social act, or operative predicate does the source establish?**

Retain the smallest complete source-native relation kernel. Preserve particles, reflexives, complements, negation-bearing construction, or copular/relational wording when removing them changes the relation itself.

A VERB need not be dramatic or narratively central. A plain relational predicate can qualify when it independently establishes how coordinates relate.

Do not emit every verbal token, auxiliary, reporting shell, discourse-management verb, fragment of one complete predicate, repeated restatement, or verb-like wording whose only job is grammatical attachment. Do not split one control/complement construction into several independent VERBs unless the source gives those relations distinct coordinate identity.

## 11. LOCATOR

`LOCATOR` answers: **what source-native orientation, path, relative-position, containment, origin/destination, approach/departure, proximity/distance, situational-context, accompaniment, embodied/internal, recurrence-context, or figurative orientation relation helps reconnect coordinates?**

A LOCATOR may be prepositional, adverbial, deictic, verb-like, colloquial, idiomatic, or clause-like when orientation is genuinely its job. Type by represented orientation, not grammar.

Retain the smallest complete source-native wording that preserves that orienting relation.

Do not emit ordinary topical, possessive, argument-marking, complement, or attachment grammar merely because it contains a preposition/adverb. Do not classify a descriptive phrase as LOCATOR unless it actually positions/orients one coordinate relative to another or a context.

## 12. Cross-class audit

The same source wording may appear in more than one class only when it genuinely answers materially different researcher questions.

Ask separately:

- PLACE: where?
- TIME: when/what episode?
- PERSON: who/social actor?
- OBJECT: what referent/content?
- LABEL: what source-applied state/value/classification?
- VERB: what operative lexical relation/action?
- LOCATOR: what orientation/path/context relation?

Do not force exclusivity where the source performs two jobs. Do not create overlap merely from grammatical possibility.

## 13. Literal lock

Every explicit semantic primitive preserves source-native wording character-for-character wherever the schema requires source text.

Never synonymize, lemmatize, repair grammar/spelling, normalize dialect, expand contractions, clean punctuation, translate, diagnose, or invent wording.

Only lawful unnamed PLACE/TIME coordinates may use null `source_wording` with a neutral mechanical tag. `source_cue` and `order_cue` remain exact source evidence.

## 14. Primitive floor/ceiling audit

Before freeze, run both tests independently for every class.

### Floor

Would deleting this candidate erase a materially distinct source-supported answer to this class's researcher question?

If yes, keep it even if it is mundane, local, unnamed, low-salience, nested, figurative, colloquial, or used once.

### Ceiling

Would deleting it lose only grammar, decoration, discourse scaffolding, duplicate wording, a clause shell, an arbitrary analytic reification, or a role already represented by the same class at the same grain?

If yes, suppress it.

The floor prevents undercapture. The ceiling prevents lexical census. Neither test may be replaced by narrative importance or phrase explicitness.

## 15. Compound reconstruction

Freeze primitives before compound work.

A compound is a source-presented local binding among two or more frozen primitives that a researcher needs to reconnect the represented relation/situation without inventing meaning.

For each materially distinct source-presented binding:

1. identify the smallest sufficient set of frozen coordinates actually participating;
2. include materially locating PLACE/TIME/LOCATOR coordinates when the source makes them part of the binding;
3. include multiple VERBs or LABELs only when each is genuinely part of that local binding;
4. project the binding once.

Do not create compounds for mere co-occurrence, every grammatical dependency, pairwise graph closure, every subset/superset, scene-wide mega-bundles, alternate tokenization, or compensation for a missing primitive.

Canonical compound IDs/order and `Q` construction remain code-owned.

## 16. Qualities and order

`qualities_available` is boolean only. It does not replace LABEL and does not authorize APA interpretation.

Order primitives by first source establishment after coreference, subject to the apparatus's code-owned canonicalization. Preserve broad-before-contained support only where the source establishes both as distinct navigation coordinates.

## 17. Worker isolation

The worker must not receive or access:

- gold-standard archetype workbooks;
- canonical archetype extracts;
- expected row counts;
- evaluator findings;
- scored predecessor outputs;
- hidden case-specific corrections/examples;
- sealed holdout source or output;
- prior agent-session answers used as targets.

The worker receives only the source case, researcher interest, schema/output request, and this finalized durable contract through the authorized harness envelope.

## 18. Candidate-only boundary

All output remains Researcher Inventory candidate material.

Never:

- promote to Oval Office or sovereign/admitted APA records;
- mint an APA Blockchain ID;
- interpret canon or APA doctrine;
- convert the lightweight inventory into diagnosis, empathic analysis, moral judgment, or psychological inference;
- write to production or sovereign databases.

## 19. Calibration and holdout gate

Calibration uses the authorized hidden evaluator only after worker output exists.

Before the sealed holdout may be attempted under V132, the **same finalized V132 contract and same saved-agent calibration lineage** must pass:

1. one paired diagnostic batch across both approved archetypes; and
2. two additional paired repeatability batches across both approved archetypes.

Any mismatch keeps the holdout sealed and returns to prospective calibration. Do not weaken evaluator acceptance criteria to obtain a pass.

Only after all paired gates pass may the calibrated lineage attempt the sealed holdout exactly once.

If that one calibrated-lineage holdout passes:

1. retire that calibration agent/lineage;
2. create a brand-new saved agent from only the finalized durable V132 instructions;
3. do not transfer prior session state or holdout output;
4. run the sealed holdout once in a new clean-room session.

Certification requires the fresh clean-room agent to pass. A failed holdout is preserved and not retried automatically.
