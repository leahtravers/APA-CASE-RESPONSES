## V19 correction

V19 introduces one common **represented-situation spine** and then applies class-local complete-resolution rules.

The controlling replacement is:

> Return the smallest set that is complete for the actual function of this class, using represented-situation grain as the common spine. Do not collapse a valid coordinate merely to reduce rows, and do not create a row merely because grammar can describe one.

The correction is deliberately asymmetric by class:

- PLACE/TIME retain distinct occurrence/frame coordinates, including unnamed ones, when the represented situations require them;
- LABEL retains materially source-applied characterization phrases without requiring cross-context reusability;
- OBJECT uses a stricter stable-referent test against proposition/metadiscourse wrappers;
- VERB keeps semantically bound predicate constructions together and splits only genuinely distinct relations;
- LOCATOR includes genuine situational/figurative/mental context while rejecting relational grammar debris;
- ordering uses the earliest material source anchor of the resolved semantic coordinate after alias/coreference resolution;
- compounds are rebuilt only after units are final and use complete proposition/situation membership.
