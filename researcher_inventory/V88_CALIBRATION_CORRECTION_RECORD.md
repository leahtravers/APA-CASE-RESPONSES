## Generalizable requirement admitted

V88 establishes **CLASS-LOCAL INDEPENDENT COORDINATE GRAIN**.

The controlling tests are:

1. Read the whole source and preserve material coverage.
2. Evaluate each requested class independently.
3. For each candidate, ask: if this coordinate were removed from this class, would a materially distinct function of this class disappear from the inventory?
4. If yes, retain it even when the same wording or source cue also supports another class.
5. Merge only true aliases, duplicate mentions, grammatical support, or inseparable multiword constructions whose pieces do not perform separate reusable jobs.
6. For VERB, default toward the smallest complete lexical predicate increment that contributes a distinct happening/state/stance/relation; matrix and embedded predicates split when they do different work.
7. For LOCATOR, retain independently useful position/path/origin/destination/context/orientation relations even when motion wording overlaps a VERB.
8. For PLACE/TIME, preserve materially distinct occurrence positions and episode/period frames even when they physically or temporally overlap broader retained settings/periods.
9. For LABEL, retain separately staged source characterizations independently from qualities and independently from other classes when the characterization itself is reusable.
10. For OBJECT, require source-treated independent referential identity; do not nominalize an unreified proposition merely to create coverage.
11. After primitive freeze, construct proposition-level compounds for materially distinct represented propositions/situations/questions/corrections/comparisons/reflections/prospective relations using only retained units.
