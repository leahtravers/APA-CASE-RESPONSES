# APA Researcher Inventory Agent Contract V149

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`  
Contract version: `RI-CONTRACT-V149`  
Predecessor: `RI-CONTRACT-V148`  
Effective date: 2026-09-21  
Authority: Leah's standing Researcher Inventory calibration instruction

## 1. Mission

Given one source case and the researcher interest `lightweight researcher inventory only`, return a source-faithful candidate Researcher Inventory that preserves the source's represented coordinates and source-native primitive roles at the grain needed to reconstruct the presented material.

This is a representational inventory. It is not a word census, clause parse, proposition inventory, event extraction, summary, diagnosis, interpretation, or ontology-building exercise.

The target lies between two errors:

- **undercoverage:** dropping a genuine source-staged coordinate because it is unnamed, low-salience, one-use, relation-bound, remembered, reported, recurrent, intended, questioned, prospective, figurative, or part of present telling;
- **overcoverage:** turning every lexical predicate, modifier, support word, discourse shell, syntactic relation, or sub-fragment of a larger source-native atom into its own primitive.

V149 preserves V148's class-local reasoning while correcting V148's tendency to treat any class-functioning fragment as a primitive. A retained primitive must be both class-valid and source-staged as a distinct inventory coordinate at that class's own grain.

## 2. Controlling V149 principle — class-local coordinate identity

For every primitive class, use two tests in order.

### Test A — represented class function

Does the source actually present this candidate as a PLACE, TIME, PERSON, OBJECT, LABEL, VERB, or LOCATOR function under the class rules below?

If no, exclude it.

### Test B — inventory-coordinate identity

Does the source stage this candidate as a distinct unit at that class's inventory grain, rather than merely as a dependent lexical/syntactic fragment inside another retained unit?

A candidate has inventory-coordinate identity when it can be tracked as one source-presented where/when/actor/referent/characterization/relation/orientation unit without inventing analyst structure.

Inventory-coordinate identity does **not** require global importance, repeated mention, independent reuse across contexts, or a scaffold-level distinction. Low-salience and one-use units remain valid when source-staged distinctly.

The second test prevents a semantic word census. It must not be converted back into V147's global relation ceiling.

## 3. Mandatory whole-source construction order

Perform one coherent whole-source pass.

### Pass A — map represented frames and transitions

Read the entire source in source order. Track current, remembered, reported, recurrent, intended, hypothetical, questioned, prospective, figurative, and present-telling material. Notice source-staged scene changes, phases, positions, recurrences, recollections, later explanations, and transitions without yet deciding final primitive density.

### Pass B — positive capture by class

Build candidate sets for all seven classes by represented source function:

- PLACE: represented where-coordinates;
- TIME: represented when/period/phase/frame coordinates;
- PERSON: stable represented human/social endpoints;
- OBJECT: source-treated referents;
- LABEL: source-applied characterizations/states/qualities/statuses/evaluations;
- VERB: source-native represented action/state/relation moves;
- LOCATOR: source-native orientation/path/context/relative-position moves.

Do not suppress a candidate merely because it is unnamed, one-use, generic, deictic, relation-bound, low-salience, reported, remembered, intended, questioned, recurrent, figurative, or present-telling.

### Pass C — coordinate-admission audit

For every candidate, apply both controlling tests from Section 2.

Exclude:

- unsupported inference or analyst paraphrase;
- true same-class alias/coreference/repetition already represented at the same grain;
- dependent lexical or syntactic fragments whose identity exists only inside a larger complete source-native atom;
- grammar-only material that performs no distinct inventory role;
- analyst-created proposition/content shells;
- alternate parses without a distinct source-staged coordinate;
- duplicate broader/narrower spans where one is merely an incomplete or redundant rendering of the same class unit;
- class mistakes caused by surface vocabulary rather than represented function.

Do not use `not globally important`, `only appears once`, or `not independently reusable` as exclusion reasons.

### Pass D — complete-source-atom reconciliation

For LABEL, VERB, and LOCATOR, use the **smallest complete contiguous source-native span** that expresses one whole retained class unit.

`Smallest complete` is not the same as `fewest words`.

A complete atom keeps the words needed to preserve the source unit's identity, including as applicable its predicate head, complement, particle, polarity, modality, degree, aspect, path, or orientation.

Do not emit as standalone primitives:

- dependent intensifiers or degree words whose identity belongs to a host characterization;
- bare support/copular/auxiliary/control fragments when the same source-native unit is completed by an adjacent predicate/complement;
- bare particles/prepositions/deictics whose meaning is only syntactic attachment;
- a shortened sub-fragment when removing neighboring words changes which source relation, characterization, or orientation is being represented.

Do split genuinely independent coordinated or serial source moves when each is separately staged as a relation/orientation/characterization unit.

### Pass E — structural-coordinate recall

Replay the source specifically for PLACE and TIME after relation-like lexical grain is stable.

Restore distinct source-staged structural coordinates lost because they were unnamed or implied by a scene/phase rather than named by a location/time noun.

An unnamed structural coordinate may be retained when the source distinctly stages its reconstructive identity through a scene, participant position, phase, recurrence, memory, intended period, later explanation, present-telling frame, or other bounded frame cue.

Do not manufacture a separate PLACE/TIME for every predicate. The source must stage a distinct frame or position, not merely logical existence somewhere/sometime.

### Pass F — PERSON/OBJECT recall and same-class identity reconciliation

Replay for stable human/social endpoints and source-treated referents. Merge only true same-class aliases/coreference/repetition at the same represented grain. Preserve materially distinct broad/contained, earlier/later, remembered/current, intended/actual, recurrent/single, and source/reported coordinates.

Freeze primitive membership before compounds.

### Pass G — compound replay

Replay the source and emit minimal source-presented bindings among two or more frozen primitives. Compounds reuse primitives only. They never create, merge, delete, retype, split, or repair primitives.

## 4. PLACE — represented where-coordinates

PLACE inventories distinct physical or institutional settings and represented positions/sites.

Positive capture includes:

- named settings;
- contained/local positions inside a broader setting when separately staged;
- participant/referent positions when the source distinguishes them;
- remembered, reported, prospective, or present-telling settings;
- unnamed settings or positions when a source-staged scene/interaction/transition gives the position a distinct reconstructive identity even though the exact physical place is unspecified.

A PLACE may be provisional as a distinct represented position even when the source does not prove whether it is physically different from another retained place. Do not collapse two source-staged positions merely because they could be co-located.

Exclude direction/path/orientation wording whose function is LOCATOR rather than site; every incidental container/surface/body-part solely because it is spatial; and duplicate sites already represented at the same grain.

For genuinely unnamed PLACE use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 5. TIME — represented phases/periods/frames, not every event

TIME inventories distinct represented temporal coordinates including periods, spans, phases, episodes, temporal positions, recurrence frames, intended/anticipated periods, remembered/reported periods, future-similar horizons, and present-telling/reflection frames.

A TIME does not require a date, duration, clock expression, or explicit temporal noun.

A source-staged action or interaction may anchor an unnamed TIME when the source presents it as a distinct **phase or episode** in the unfolding material, for example through sequencing, transition, recurrence, before/after structure, intended duration, later reflection, or grouping of multiple relations inside that frame.

Do not make every predicate its own TIME. The question is whether the source stages a distinct temporal frame/phase, not merely whether an action occurs.

Retain broad and contained temporal coordinates when each independently organizes source material.

For genuinely unnamed TIME use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 6. PERSON — stable represented human/social endpoints

PERSON inventories `B` plus every distinct stable human or social actor/group represented by the source after strict coreference.

A PERSON may qualify through acting, speaking, perceiving, being acted upon, possession, accompaniment, benefit, relation to another actor, remembered/reported presence, or prospective social standing. Prominent action or dialogue is not required.

Possessive or relational mention may establish a PERSON when it clearly identifies a stable human/social endpoint rather than a generic grammatical possessor.

Exclude rhetorical/generic addressees, unstable pronouns without resolvable endpoints, hypothetical placeholders without stable represented standing, and true aliases/coreference duplicates.

Order non-speakers by first material represented participation.

## 7. OBJECT — source-treated referents, not discourse shells

OBJECT inventories concrete or abstract things that the source itself treats as referents.

Positive capture includes source-native nominal, deictic, possessive, decision, choice, relation, internal, or abstract handles when the source gives them stable referential standing: they can be tracked, selected, possessed, compared, evaluated, questioned, revisited, acted on, pointed back to, or distinguished as a thing.

A referent may be one-use or relation-bound.

Exclude:

- analyst-created noun phrases summarizing a clause/relation;
- propositions or reports converted into objects without source reification;
- discourse shells, anaphoric packaging, or generic content handles whose entire identity resolves to an already retained relation/compound and which the source does not separately treat as a stable thing;
- pure argument placeholders whose identity is nothing beyond grammar;
- a setting duplicated as OBJECT when its only represented function is PLACE;
- unstable pronouns/demonstratives that resolve entirely to another retained coordinate.

Use the smallest **complete referential atom**, not the shortest noun-like fragment.

## 8. LABEL — complete source-applied characterization atoms

LABEL inventories source-applied states, qualities, statuses, identities, classifications, evaluations, comparisons, manners, intensities, polarities, corrections, rejections, uncertainty-marked characterizations, and characterization questions when the source stages them as distinct characterization units.

A LABEL may be local, one-use, relation-bound, colloquial, figurative, questioned, negative, or attributed.

Use the smallest complete characterization span. Keep degree, polarity, comparison, or complement wording when it belongs to the characterization's identity.

Do not turn a dependent intensifier, discourse adverb, support word, or manner fragment into its own LABEL merely because it modifies a clause. The source must stage a distinct characterization coordinate.

Exclude material whose represented role is only a VERB relation or LOCATOR orientation unless the same complete source span genuinely performs multiple retained functions.

Preserve wording and posture exactly.

## 9. VERB — complete source-native relation moves

VERB inventories distinct represented actions, processes, states, perceptions, cognitions, reports, intentions, possessions, comparisons, movements, waiting relations, question-bearing relations, negated relations, and other predicate/relation moves when the source stages them as distinct relation units.

A valid VERB does not need global scaffold importance or repetition.

Lexical grain:

- use the smallest **complete** exact contiguous span that preserves one whole source relation move;
- keep matrix/control/support wording together with its predicate/complement when together they constitute one source relation identity;
- do not emit a bare support/copular/auxiliary/control fragment when its semantic identity is completed by the same adjacent predicate or complement;
- keep polarity, modality, aspect, particle, and required complement wording when removing it changes relation identity or posture;
- split coordinated or serial moves only when each is independently source-staged as a distinct relation;
- do not absorb separable participants, referents, sites, times, or characterizations that are their own primitives;
- do not normalize to lemmas, analyst synonyms, or conventional predicate names.

A sentence may yield multiple VERBs, but not every verbal token or auxiliary is a separate inventory relation.

## 10. LOCATOR — complete orientation/context atoms

LOCATOR inventories source-native wording that locates, directs, orients, positions, contains, moves, approaches, departs, enters, exits, accompanies, carries, relates source-to-target, marks recurrence/situational placement, or supplies a represented figurative/comparison orientation.

A LOCATOR may be one-use, relation-bound, colloquial, verb-like, or context-like on the surface. Type by represented orientation function.

Use the smallest **complete orientation atom**. Preserve the words needed for the source direction/path/relative-position/context identity.

Exclude bare/routine prepositions, recipient/topic marking, possessive syntax, isolated deictics, or shortened path fragments whose only meaning comes from a larger source-native orientation unit.

LOCATOR does not replace a distinct PLACE/TIME coordinate. The same exact complete span may also be VERB or LABEL only when genuinely distinct represented functions coexist.

## 11. Cross-class typing and legitimate multiplicity

Type by represented source function, never by part of speech or vocabulary shape.

The same exact source span may appear in multiple primitive classes only when the complete span genuinely performs multiple represented functions. Do not create cross-class twins from uncertainty or alternate parsing.

No class absorbs another:

- OBJECT does not absorb LABEL;
- LABEL does not absorb VERB;
- PLACE/TIME do not absorb LOCATOR;
- VERB does not absorb participants/referents/sites/frames;
- LOCATOR does not replace PLACE/TIME.

## 12. Literal, contiguity, and posture lock

Every source-derived non-null string must preserve source language character-for-character where the schema requires source text.

Never synonymize, lemmatize, repair spelling/grammar, normalize dialect, expand contractions, translate, polish, diagnose, standardize a category name, change number, or substitute a conventional expression.

Never add a word that does not occur in the exact contiguous source span. Never concatenate noncontiguous fragments. `source_wording`, `source_cue`, and `order_cue` must be exact source text where applicable. Only genuinely unnamed PLACE/TIME may use null `source_wording`.

If validation reports that a proposed source string is not exact source text, correct by selecting an exact contiguous source span or an allowed unnamed structural coordinate. Do not invent a near-synonym or a grammatical repair.

Questions, uncertainty, hypotheticals, negations, corrections, remembered possibilities, reported material, attribution, and proposed future actions remain in source posture. Inventorying does not assert truth or realization.

## 13. `qualities_available`

`qualities_available` is mechanical. True means the source supplies material qualities/descriptions associated with that coordinate; false otherwise.

Do not create or split primitives to justify the boolean. `Q` is never a primitive.

## 14. Ordering

Default within-class order is first material source anchor after filtering/coreference.

Tie rules:

- broad/whole setting before dependent/contained setting when introduced together;
- whole before dependent part at the same anchor unless source order stages the part first;
- PERSON follows first material represented participation;
- remembered/reported/hypothetical/future material stays at source position rather than external chronology.

The apparatus owns canonical IDs and deterministic numbering.

## 15. Coordinate-completeness audit

Before compounds, replay the source separately for each class.

For each class ask:

1. Did I capture every source-staged coordinate that actually performs this class function?
2. Did I drop anything merely because it is unnamed, low-salience, one-use, local, deictic, reported, remembered, intended, prospective, questioned, recurrent, figurative, or present-telling?
3. Did I retain a fragment that has class-like meaning but no independent inventory-coordinate identity apart from a larger complete atom?
4. Did I fuse two independently staged complete atoms?
5. Did I invent a row from analyst paraphrase, grammatical necessity, or alternate parsing?
6. Did I type by surface vocabulary instead of source function?
7. Did I miss a distinct source-staged PLACE/TIME frame merely because it lacked explicit where/when vocabulary?

Correct structural omissions and lexical over-fragmentation before compounds.

## 16. Complete-atom audit

For every LABEL, VERB, and LOCATOR ask:

- Is this exact contiguous span source-native?
- Is it complete enough to preserve one whole source characterization/relation/orientation identity?
- Is any word inside merely a separable participant/referent/site/time rather than part of this atom?
- Is this candidate only an auxiliary, intensifier, support word, particle, preposition, or deictic whose identity depends on a larger host span?
- Did I incorrectly split a matrix/control/predicate unit that the source stages as one move?
- Did I incorrectly fuse independently staged coordinated/serial moves?
- If duplicated across classes, does the complete span genuinely perform both functions?

Prefer the smallest complete atom, not the shortest possible fragment.

## 17. Anti-reification and anti-census audit

A complete inventory is not a transcription.

Remove:

- pure grammar with no distinct inventory-coordinate identity;
- dependent lexical fragments whose function is already carried by a complete retained atom;
- analyst paraphrases and inferred categories;
- true aliases/coreference duplicates;
- alternate parses without distinct source staging;
- proposition/discourse shells without source reification;
- every-event-as-TIME or every-spatial-word-as-PLACE mistakes;
- scene-wide or clause-wide fused primitives that should be separate complete atoms.

Do **not** remove a genuine coordinate solely because it appears once, is locally bounded, generic, small, or not globally important.

Never aim for a hidden count.

## 18. Compound construction

Freeze all primitives first.

A compound represents one minimal source-presented binding among two or more frozen primitives that co-participate in a represented relation, characterization, orientation, state, transition, or other source-staged connection.

Create a compound when:

1. at least two frozen primitives are actively bound by the source in one reconstructively distinct connection;
2. preserving that binding improves reconstruction beyond isolated primitive rows;
3. the member set contains only primitives active in that connection; and
4. the compound is not an alternate parse, duplicate/subset alias, pairwise/transitive closure, or scene-wide mega-bundle.

One clause may yield multiple compounds when it presents multiple distinct bindings. Several clauses may contribute to one compound when they clearly continue the same binding.

VERB/LABEL/LOCATOR participate when active. PLACE/TIME participate when they actually locate or temporally organize the binding.

A compound cannot create, delete, merge, split, retype, or substitute for primitives.

## 19. Isolation and candidate boundary

The worker must never receive:

- Leah-approved archetype rows or workbooks;
- expected counts;
- evaluator findings;
- scored predecessor outputs;
- canonical archetype extracts;
- case-specific hidden corrections/examples;
- sealed holdout source or output;
- prior holdout sessions.

The worker receives only the durable contract, the bounded runtime request, and the source case authorized for that run.

All calibration output remains candidate research. Worker completion, repeated passes, evaluator success, or certification does not itself promote any record to admitted APA data, Oval Office records, or sovereign fabric.

## 20. Calibration and certification gate

Before any sealed holdout becomes eligible:

1. the immutable Case 2 and Case 6 workbook bytes must match their separately governed expected hashes;
2. both approved archetypes must repeatedly pass under the same finalized durable contract and saved-agent lineage;
3. all deterministic harness tests must pass;
4. all failed/partial attempts must remain preserved.

After that gate, the calibrated lineage may run the sealed holdout exactly once. No repair to that lineage may be learned from the holdout result.

If the one-shot holdout is archetypal, retire the calibrated lineage. Create a brand-new saved agent containing only this finalized durable contract, with no access to prior agent sessions or holdout output, and run the holdout once as clean-room verification.

Certification requires that fresh agent to succeed.

No worker, harness, or calibration action may promote records to Oval Office, mint APA IDs, or mutate APA database/fabric.
