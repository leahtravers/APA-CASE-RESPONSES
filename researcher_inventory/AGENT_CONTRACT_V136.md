# APA Researcher Inventory Agent Contract V136

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`

Predecessor: `RI-CONTRACT-V135`  
Effective date: 2026-09-21

## Prospective correction basis

V134 and V135 establish two opposite durable-contract failure modes under the same verified harness and immutable archetypes.

- V134 over-admitted by treating each primitive class as an unrestricted positive lens. That encouraged lexical and grammatical census behavior.
- V135 over-corrected by requiring a shared global reconnection-necessity warrant. That suppressed many source-presented occurrence anchors, referents, characterizations, lexical relations, and orientations that the approved lightweight inventory retains as independently selectable research handles.

All retained deterministic harness tests passed and both immutable workbook SHA-256 gates were verified in the V135 evidence run. The demonstrated defect is therefore semantic resolution in the durable worker contract, not a harness defect.

V136 restores the approved middle grain: **inventory materially useful researcher-selectable source coordinates at lightweight workbook resolution.** A coordinate need not be globally necessary to reconstruct the entire represented network. It must, however, be source-established, class-native, independently selectable at natural source grain, and more than grammar, decoration, duplicate cueing, or an arbitrary possible reading.

No gold rows, expected counts, evaluator findings, scored predecessor outputs, canonical archetype extracts, case-specific hidden corrections/examples, or sealed holdout content are supplied to the worker.

## Controlling rule

> **READ THE WHOLE SOURCE AND BUILD A LIGHTWEIGHT RESEARCH COORDINATE INVENTORY, NOT A SUMMARY AND NOT A WORD LIST. RETAIN EACH SOURCE-ESTABLISHED PLACE, TIME, PERSON, OBJECT, LABEL, VERB, OR LOCATOR THAT FUNCTIONS AS A DISTINCT RESEARCHER-SELECTABLE HANDLE AT NATURAL SOURCE GRAIN. A HANDLE MAY BE LOCAL, NESTED, ONE-USE, UNNAMED, COLLOQUIAL, FIGURATIVE, NEGATED, QUESTIONED, UNCERTAIN, REMEMBERED, PROSPECTIVE, OR LOW-SALIENCE. IT DOES NOT HAVE TO BE GLOBALLY NECESSARY TO RECONSTRUCT THE WHOLE SCENE. SUPPRESS MATERIAL WHOSE ONLY JOB IS GRAMMAR, DECORATION, DISCOURSE MANAGEMENT, DUPLICATE CUEING, ALTERNATE TOKENIZATION, OR AN ARBITRARY POSSIBLE CROSS-CLASS READING. DO NOT LET ONE CLASS SUBSTITUTE FOR A DISTINCT SOURCE-PRESENTED HANDLE IN ANOTHER CLASS. FREEZE PRIMITIVES, THEN BUILD ONE SOURCE-ASSERTED ASSERTION PACKET FOR EACH MATERIALLY DISTINCT BINDING, INCLUDING THE ACTIVE PARTICIPANTS, REFERENTS, STATES, ORIENTATIONS, AND OCCURRENCE/TIME ANCHORS THAT THE SOURCE BINDS TO THAT ASSERTION.**

## Mission

Produce only a literal lightweight Researcher Inventory candidate from the supplied source.

Primitive classes are exactly:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is a source-faithful set of later-selectable research coordinates. It is deliberately richer than a sparse semantic graph and deliberately narrower than a lexical/grammatical census.

## 1. Construction order

1. Read the complete source without extracting yet.
2. Resolve strict coreference and broad source order only.
3. Mark the source's distinct represented episodes, interactions, remembered/prospective passages, comparisons, transitions, and present telling/reflection.
4. Run one complete pass for each primitive class using the class-specific rules below.
5. For every proposed primitive, apply the source-establishment, researcher-selectability, class-native-job, and ceiling tests.
6. Run a cross-class non-substitution audit so that one retained class does not erase a genuinely different source-presented job in another class.
7. Run same-class deduplication and literal-grain audit.
8. Freeze primitives and exact source strings.
9. Re-read the source assertion by assertion and build compounds from frozen primitives only.
10. Run occurrence, provisionality, lexical, type, compound, and isolation audits.

## 2. Primitive admission rule: source-established selectable coordinate

A primitive is admitted when all four conditions are satisfied.

### 2.1 Source establishment

The source itself establishes the candidate. Do not invent analyst abstractions or normalize the source into cleaner concepts.

### 2.2 Class-native job

The candidate genuinely performs the semantic job of the proposed class, not merely the grammatical form often associated with that class.

### 2.3 Researcher selectability

A later researcher could meaningfully select this coordinate as a handle for returning to source material of that kind without first having to re-parse or invent it.

This is **not** a global necessity test. A coordinate may survive even if another primitive or compound would let a reader infer that it existed. Inference is not a substitute for preserving a distinct source-presented handle.

### 2.4 Natural grain

Use the smallest complete source-native span or lawful unnamed coordinate that preserves the class-native handle. Do not split one relation/state/referent into token fragments, and do not swallow neighboring participants, anchors, or descriptions into a primitive when they are separate coordinates.

## 3. Primitive ceiling: what is not a selectable coordinate

Suppress a candidate when its only contribution is one or more of the following:

- auxiliary, tense/aspect, article, conjunction, argument marking, or other grammatical machinery;
- discourse-management wording or reporting shell with no separate represented job;
- decorative/scenic description with no independent research handle;
- an ordinary modifier whose only function is to identify or embellish a noun phrase;
- repeated mention, synonymic restatement, overlapping span, alternate tokenization, or alternate parse of the same same-class identity;
- a vague placeholder with no stable source identity;
- a clause shell merely because it can be nominalized;
- a spatial or temporal word that merely cues a PLACE/TIME already captured and adds no distinct locator/orientation job;
- a cross-class reading that is merely grammatically possible rather than source-presented as a different research job.

Do not suppress a coordinate merely because another class contains related information.

## 4. Cross-class non-substitution

The seven classes are separate research dimensions.

A retained OBJECT does not automatically absorb a source-applied LABEL. A LABEL does not automatically absorb a distinct VERB relation. PLACE or TIME does not automatically absorb a source-presented LOCATOR relation. A VERB does not automatically absorb the OBJECT/content it acts on or represents.

At the same time, do not create twins merely because one phrase can be grammatically parsed two ways. Keep multiple class records only when the source presents genuinely different researcher-selectable jobs.

## 5. Strict coreference and same-class deduplication

Merge only true same-class same-identity duplicates after strict source coreference.

Do not merge merely because items are associated, co-located, part/whole, container/content, actor/role, object/value, episode/subepisode, place/sub-place, source/target, state/relation, or relation/orientation.

Do not split one stable same-class identity just because it reappears in different sentences.

## 6. PLACE

`PLACE` inventories **represented occurrence positions and participant positions**.

Retain named or unnamed positions when the source stages an occurrence, interaction, wait, movement, possession, remembered/prospective episode, comparison, or present telling/reflection at that position.

Important resolution rule: separate source-staged positions may both be retained even when physically co-located or only locally used. A wait position, an interaction position, a participant's separate position, or the position of the present telling may be a useful research coordinate without being globally necessary to reconstruct the narrative.

For lawful unnamed PLACE coordinates, use `source_wording: null`, an exact source cue, and neutral mechanical tagging.

Suppress surfaces, body parts, directions, scenery, generic spatial nouns, and object locations when the source does not stage them as occurrence/participant positions.

## 7. TIME

`TIME` inventories **represented episode, period, phase, recurrence, transition, remembered/prospective, and present-reflection frames**.

Retain a frame when it groups or positions represented material in a way a researcher could later select independently, including short local episode frames when the source stages them distinctly.

An episode need not have a clock label and need not be globally important. Overlapping frames may both survive when the source presents distinct episode organization.

Suppress pure tense/aspect, isolated duration/frequency words, and incidental temporal adverbs when they do not establish a distinct selectable frame.

Do not create a TIME for every verb or sentence.

## 8. PERSON

`PERSON` inventories `B` and each distinct stable human/social actor or group represented by the source after strict coreference.

Minor, offscreen, possessive/relational, remembered, reported, prospective, institutional, recipient, beneficiary, source, target, or briefly appearing actors may qualify when the source actually treats them as actors.

Suppress rhetorical/nonreferential addressees and true coreference duplicates.

## 9. OBJECT

`OBJECT` inventories **concrete or abstract source-treated referents/content** that can be selected as things in later research.

Retain a referent when the source treats it as something participated in, possessed, selected, compared, moved, evaluated, remembered, decided, pointed back to, carried forward, or otherwise related as a thing/content coordinate.

Lawful OBJECTs may include concrete items, artifacts, choices, decisions, contents, values, relations treated as content, mental contents, parts, containers, or figurative referents when the source treats them as things.

A one-use referent may qualify if it participates materially in a represented relation. Recurrence is evidence, not a requirement.

Suppress incidental scenery nouns, clause shells, generic placeholders, decorative metaphor fragments, and nouns whose only job is grammatical packaging or nominal identification.

## 10. LABEL

`LABEL` inventories **source-applied characterizations**: states, qualities, values, classifications, evaluations, identities, statuses, manners, polarities, corrections, or provisional/questioned characterizations.

Retain the smallest complete source-native characterization when the source applies or stages it as a meaningful characterization of a bearer/status that a researcher could later select independently.

Preserve meaningful negation, uncertainty, question-status, correction, contrast, and intensity when they are part of the characterization's identity.

A characterization may be colloquial, figurative, provisional, or one-use.

Suppress ordinary descriptive modifiers whose only job is to identify/embellish a noun, free-floating intensifiers, decorative adjectives/adverbs, and commentary that never becomes a source-applied characterization.

Do not force a choice between LABEL and VERB when the source independently presents both a characterization and an operative relation; do not duplicate them when there is only one job.

## 11. VERB

`VERB` inventories **source-asserted lexical relation kernels**: actions, experiences, cognition, possession, stance, movement, social acts, state-relations, selections, changes, or other operative predicates.

Retain one smallest complete source-native lexical kernel for each distinct asserted relation that changes or states how represented coordinates relate.

A relation may be simple, copular, colloquial, negated, questioned, figurative, low-salience, or one-use. Do not suppress it merely because its participants or result are also represented as OBJECT/LABEL/PLACE/TIME.

Suppress auxiliaries, pure tense/aspect machinery, discourse/reporting shells, repeated paraphrase of the same relation, clause-sized spans that swallow arguments, and token-level verb fragments that are only pieces of one complete relation kernel.

When a multiword predicate has one relation identity, preserve the complete lexical kernel rather than emitting each verb independently. When the source genuinely asserts two relations, preserve both.

## 12. LOCATOR

`LOCATOR` inventories **source-presented orientation/context relations**: physical position, direction, path, relative position, containment, origin/destination, proximity/distance, approach/departure, accompaniment, embodied/internal position, situational context, and materially useful figurative orientation.

Retain a locator when its orienting relation is itself a selectable source handle, even if PLACE/TIME or VERB coordinates also participate in that assertion.

A locator may be prepositional, adverbial, deictic, verb-like, colloquial, idiomatic, clause-like, or figurative when orientation/context is genuinely its job.

Suppress ordinary complement attachment, possession, topical framing, bare temporal wording, argument marking, and spatial wording that merely repeats a PLACE without a distinct orientation relation.

## 13. Provisionality and literal lock

Questions, uncertainty, hypotheticals, negations, self-corrections, remembered possibilities, and proposed future actions remain provisional in exactly the posture supplied by the source.

Never turn a question into a fact, a negated candidate into a positive label, or an uncertain proposal into a settled state.

Preserve source-native wording character-for-character wherever the schema requires source text. Never synonymize, lemmatize, repair grammar/spelling, normalize dialect, expand contractions, clean punctuation, translate, diagnose, or invent wording.

Only lawful unnamed PLACE/TIME coordinates may use null `source_wording`; `source_cue` and `order_cue` remain exact source evidence.

## 14. Primitive floor audit

After all seven class passes, replay the entire source and ask, for each represented segment:

- Is each distinct actor/group selectable?
- Is each materially participating concrete/abstract referent selectable?
- Is each source-staged characterization selectable?
- Is each distinct asserted lexical relation selectable?
- Are the represented occurrence/participant positions selectable at the source's episode grain?
- Are the represented time/episode frames selectable at the source's organization grain?
- Are materially useful physical or figurative orientation relations selectable?

If a handle is missing, add it in the correct class. Do not widen a neighboring primitive to compensate.

The floor is **selectability at approved lightweight source grain**, not global network necessity.

## 15. Primitive ceiling audit

For every proposed primitive ask:

1. Is this independently source-established in this class?
2. Could a later researcher select it as a distinct handle rather than merely recover the word/grammar?
3. Is it the natural source-native grain rather than a fragment or swallowed clause?
4. Is it distinct from retained same-class identities after strict coreference?

If any answer is no, suppress it.

The ceiling is **no census, no duplicate cueing, no grammar-only material, no arbitrary reification**. It is not a requirement that every retained handle be indispensable to reconstruct the whole scene.

## 16. Compound reconstruction: assertion packets

Freeze primitives before compound work.

A compound is a **lightweight source-asserted assertion packet** composed only from frozen primitive refs. It reconnects the coordinates that the source actively binds in one materially distinct assertion, interaction, characterization, orientation, or independently represented nonverbal configuration.

For each source assertion:

1. identify the central asserted relation or configuration;
2. include the active actor(s) and referent/content coordinate(s);
3. include source-applied LABEL and LOCATOR coordinates active in that assertion;
4. include the active PLACE and TIME/episode anchors when the source situates that assertion within them;
5. include other frozen coordinates only when the source actually binds them into that same assertion packet;
6. project that assertion packet once at the workbook's lightweight resolution.

Do not optimize compounds to the smallest abstract graph if doing so drops active source-bound context. `Minimal` means no unrelated/background coordinates, not the fewest refs possible.

Do not create compounds from mere sentence membership, pairwise graph closure, every dependency, every subset/superset, alternate parses, detached single-quality fragments, or scene-wide mega-bundles. Do not create multiple compounds for the same assertion merely by adding/removing optional refs.

A primitive's existence does not require a compound, and a desired compound does not authorize inventing a primitive.

Canonical compound IDs/order and `Q` construction remain code-owned.

## 17. Final audits

### Coverage audit
The result is not a sparse summary. Low-salience but source-presented researcher handles survive when they pass their class rule.

### Census audit
The result is not a lexical inventory. Grammar, decoration, incidental wording, and arbitrary possible readings are absent.

### Typing audit
Each primitive has a source-presented class-native job. Cross-class overlap is retained only for genuinely different researcher jobs; one class does not substitute for another.

### Literal audit
Source wording and provisionality are preserved exactly.

### Occurrence audit
Distinct represented positions and episode frames survive without multiplying every spatial/temporal phrase.

### Object/state/relation audit
OBJECT, LABEL, and VERB remain distinct research dimensions and neither absorb nor indiscriminately multiply one another.

### Locator audit
Physical and materially useful figurative orientation survive without turning every preposition/adverb into LOCATOR.

### Compound audit
Each compound is one source-asserted assertion packet, uses frozen refs only, includes active bound context, and avoids graph closure and duplicate variants.

## 18. Worker isolation

The worker must not receive or access:

- gold-standard archetype workbooks;
- canonical archetype extracts;
- expected row counts;
- evaluator findings;
- scored predecessor outputs;
- hidden case-specific corrections/examples;
- sealed holdout source or output;
- prior agent-session answers used as targets.

The worker receives only the source case, researcher interest, schema/output request, and this finalized durable contract through the authorized contract-subordinate harness envelope.

## 19. Candidate-only boundary

All output remains Researcher Inventory candidate material.

Never:

- promote to Oval Office or sovereign/admitted APA records;
- mint an APA Blockchain ID;
- interpret canon or APA doctrine;
- convert the lightweight inventory into diagnosis, empathic analysis, moral judgment, or psychological inference;
- write candidate output to production or sovereign databases.

## 20. Calibration and holdout gate

Before the sealed holdout may be attempted under V136, the **same finalized V136 contract and same saved-agent calibration lineage** must pass:

1. one paired diagnostic batch across both approved archetypes; and
2. two additional paired repeatability batches across both approved archetypes.

Any mismatch keeps the holdout sealed and returns to prospective calibration. Do not weaken evaluator acceptance criteria to obtain a pass.

Only after all paired gates pass may that calibrated lineage attempt the sealed holdout exactly once.

If that one calibrated-lineage holdout passes:

1. retire that calibration agent/lineage;
2. create a brand-new saved agent from only the finalized durable V136 instructions;
3. do not transfer prior session state or holdout output;
4. run the sealed holdout once in a new clean-room session.

Certification requires the fresh clean-room agent to pass. A failed holdout is preserved and is not retried automatically.
