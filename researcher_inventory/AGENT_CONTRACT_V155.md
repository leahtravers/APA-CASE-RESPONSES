# APA Researcher Inventory Agent Contract V155

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`

Authority: Leah's standing Researcher Inventory calibration instruction

## 1. Mission

Given one source case and the researcher interest `lightweight researcher inventory only`, return a source-faithful candidate Researcher Inventory that preserves the source's represented settings, temporal frames, actors, referents, characterizations, relations, orientations, and minimal bindings at the source's own represented grain.

This is a **researcher-addressable representational inventory**. It is not a summary, diagnosis, ontology, topic list, word census, clause parse, proposition census, predicate census, or inventory of every class-compatible surface phrase.

The unit layer preserves one source-native researcher handle for each distinct represented coordinate or role that the source actually stages in its situation graph. A primitive may be local, one-use, low-salience, unnamed, reported, questioned, negative, prospective, figurative, or bound to one relation. It does not need global importance or recurrence.

V155 preserves V154's whole-source graph, structural lattice, class-native grain, exact-source lock, candidate boundary, worker isolation, structural recall, cross-class multiplicity, deterministic apparatus controls, and holdout/certification gates. It supersedes V154 only where V154 allowed **class compatibility and span minimization to occur before a strong admission decision**, producing a lexical relation/description census while structural coordinates remained undercomplete.

## 2. Controlling principle — admit the represented role before choosing its span

Use this order:

`whole-source situation graph → structural lattice → primitive admission → class assignment → source-native span → same-class identity reconciliation → recall/audit → frozen primitive graph → selective minimal compounds`

Do not reverse admission and span selection. A phrase is not a primitive merely because it can be assigned a class or shortened to a valid class-native nucleus.

### Stage A — represented-role admission

Admit a primitive only when the source gives it a distinct researcher-addressable function in the represented situation graph.

At least one of these must be true:

1. it is a stable PERSON endpoint, source-treated OBJECT referent, PLACE coordinate, or TIME frame;
2. it is a relation occurrence that establishes, changes, maintains, interrupts, transfers, perceives, reports, intends, or otherwise materially connects represented participants, referents, scenes, or frames;
3. it is a characterization act applied to a retained coordinate or retained relation;
4. it is an orientation relation that materially positions or relates a retained coordinate, participant, referent, movement, or comparison frame; or
5. the source itself reifies the occurrence as an addressable thing.

Class-compatible wording alone is not admission.

Do not admit a candidate merely because it is:

- a grammatical predicate or auxiliary;
- a copula/support/control/reporting/cognition verb in a clause;
- an adjective, adverb, modifier, discourse reaction, or intensity word;
- a preposition, path word, comparison marker, or deictic;
- a conversational-management move, self-edit, filler, metalinguistic telling move, or narration scaffold;
- an explicit temporal/spatial expression;
- a noun phrase or proposition shell.

Such material may still qualify when the source **stages that occurrence itself as a distinct represented role**. The prohibition is against automatic lexical admission, not against any word category.

A useful check is: **if this candidate were removed while the retained source graph still represents the same people/things/scenes/frames and the same materially staged connections, characterizations, and orientations, it is probably support/evidence rather than a primitive.**

### Stage B — class assignment

After admission, assign every admitted role to each class function it independently supplies:

- PLACE — represented where-coordinate, scene, interaction/relationship position, or situated participant/referent position;
- TIME — represented when-coordinate, episode, phase, period, span, recurrence frame, remembered/reported/prospective frame, or present-telling frame;
- PERSON — stable represented human/social endpoint;
- OBJECT — source-treated concrete, abstract, decision-like, relational, internal, figurative, event-like, or proposition-like referent with independent standing;
- LABEL — source-applied characterization, category, state, identity, classification, evaluation, comparison, manner, polarity, correction, rejection, or questioned condition;
- VERB — admitted source-native action/state/process/relation occurrence;
- LOCATOR — admitted source-native orientation, path, relative position, movement-direction, containment, situational positioning, or figurative/comparison orientation.

The same occurrence may enter more than one class only when each class passes admission independently.

### Stage C — source-native grain

Only after admission and class assignment choose the source span.

For PERSON, OBJECT, PLACE, and TIME, preserve the smallest source-faithful handle or neutral unnamed coordinate that identifies the admitted endpoint/referent/scene/frame.

For LABEL, preserve the smallest exact contiguous source span that expresses the admitted characterization act without unrelated material.

For VERB and LOCATOR, preserve the **smallest exact contiguous source-native relation nucleus that still identifies the admitted relation occurrence**. Retain particles, polarity, modality, aspect, fixed relation markers, phrasal-verb material, and other wording required for relation identity. Exclude separable participants, referents, scene/time coordinates, labels, independent orientations, and open-clause relations when the admitted relation remains identifiable without them.

Span minimization cannot create admission. A perfectly minimal lexical nucleus must still be excluded if it is only grammatical, discursive, incidental, or otherwise not a distinct represented role.

### Stage D — identity reconciliation

Reconcile within each class only aliases, coreferences, repetitions, nested restatements, or overlapping spans that instantiate the **same represented role occurrence**.

If two spans express the same same-class occurrence at different widths, keep the smallest admitted class-native span that preserves the role.

Do not collapse distinct source-staged occurrences merely because they use identical wording. Do not collapse legitimate cross-class overlap when both functions independently pass admission.

## 3. Structural lattice freezes before relation admission

Read the complete source and map its represented situation graph before finalizing LABEL, VERB, LOCATOR, or compounds.

Freeze a provisional structural lattice in this order:

1. stable PERSON endpoints;
2. source-treated OBJECT referents;
3. macro PLACE scenes and interaction/relationship settings;
4. contained or participant/referent PLACE positions that the source stages separately;
5. macro TIME episodes, phases, periods, spans, recurrence frames, remembered/reported frames, prospective frames, and present-telling frames;
6. contained or action-defined TIME frames that organize represented material separately.

The lattice follows what the source **stages**, not merely explicit spatial or temporal vocabulary.

A distinct interaction, relationship position, waiting/transition position, remembered/reported scene, participant/referent position, or present-telling scene may require an unnamed PLACE even without a location noun.

A distinct action-defined episode, conversation frame, waiting phase, recurrence span, relationship period, remembered/reported period, prospective horizon, or present-telling phase may require a TIME even without a date/adverb.

The lattice is not an event census. Do not create PLACE/TIME for every predicate, noun, preposition, adverb, movement, duration expression, or tense cue. Create a structural coordinate when it organizes represented material as a distinct where/when address.

Structural omission is not repaired by creating more VERB/LOCATOR rows. Relation selectivity is not permission to compress the structural lattice.

## 4. PLACE — staged where-coordinates

PLACE inventories where represented material occurs or where a participant/referent is distinctly positioned in a scene.

Retain named settings, distinct contained settings, separately staged participant/referent positions, relationship/interaction positions whose geography is unspecified, remembered/reported/prospective/figurative scene settings when they function as represented where-coordinates, waiting/transition positions, and a present-telling location when distinctly represented.

Do not create PLACE merely from a surface, container, body part, object, destination word, spatial noun, movement path, metaphorical spatial wording, or clause containing motion. Explicit location-like language is evidence, not automatic admission.

A physical noun can be OBJECT, PLACE, or both only when the source independently establishes each function.

For a genuinely unnamed PLACE use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 5. TIME — staged when-coordinates

TIME inventories the source's distinct temporal organization, not every temporal expression and not every verb occurrence.

Retain a TIME when the source stages a distinct episode, phase, earlier/later period, interaction/conversation/waiting/transition phase, recurrence span, relationship/life span, intended/anticipated period, remembered/reported frame, prospective/future-similar horizon, or present reflection/telling frame.

An action or relation may define the boundary of a TIME frame. The action is not automatically a TIME, but an episode does not need explicit time wording to qualify.

Temporal adverbs, durations, recurrence markers, event predicates, tense cues, or discourse markers do not create separate TIME rows unless they establish a distinct organizing frame.

Contained phases may each qualify when the source clearly transitions among them.

For a genuinely unnamed TIME use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 6. PERSON — stable human/social endpoints

PERSON inventories `B` plus every distinct stable represented human or social actor/group after strict coreference.

A PERSON may qualify through acting, speaking, perceiving, being acted upon, possession, accompaniment, benefit, relationship, remembered/reported presence, or a clear social reference.

Do not create separate PERSON rows for aliases or pronouns that resolve to an existing endpoint. Exclude rhetorical or generic addressees without a stable represented endpoint.

## 7. OBJECT — source-treated referential handles

OBJECT inventories distinct source-treated things or abstractions with independent referential standing in the represented graph.

Eligible referents may be concrete, abstract, internal, deictic, relational, decision-like, choice-like, figurative, event-like, or proposition-like when the source itself treats them as an addressable thing.

A source phrase has OBJECT standing when the source handles, possesses, selects, points back to, compares as a thing, questions/decides about as a thing, or otherwise gives it stable referential role.

A relation, choice, event, or internal construct may be an OBJECT when the source reifies it. Do not exclude it merely because its content also participates in another class.

Exclude aliases, transient deictics/discourse placeholders, wh/proposition/metalinguistic shells that exist only as grammar/discourse, bare grammatical complements with no referential standing, and noun phrases admitted solely because they are nominal.

One-use referents may qualify. Recurrence is not required.

## 8. LABEL — admitted characterization acts

LABEL inventories source-applied characterizations only after Stage A admission.

A LABEL must characterize a retained coordinate or admitted relation, or itself be staged as a distinct represented state/category whose characterization is researcher-addressable.

Retain identity/role categories, status/condition judgments, explicit evaluations, speaker-applied self/other characterizations, relation-state descriptions, asserted operational states, comparisons/figurative characterizations, questioned/negated/rejected/corrected/uncertain labels, and manners/intensities when the source stages them as independent characterization acts.

Do not turn every adjective, adverb, modifier, noun-phrase descriptor, scene texture, evaluative aside, conversational reaction, or descriptive fragment into a LABEL. Descriptive language can remain source evidence/quality without becoming a primitive.

When overlapping spans characterize the same target in the same way, retain the smallest admitted class-native span. Preserve separate labels when the source stages separate characterization acts.

`qualities_available` is mechanical metadata and does not force LABEL admission.

## 9. VERB — admitted material relation occurrences

VERB is **not a predicate census**.

First decide whether the source stages the action/state/process/relation as a distinct represented connection in the situation graph. Only then choose its minimal source-native relation nucleus.

A relation is normally material enough for VERB admission when it establishes or changes a connection among retained participants/referents/coordinates, changes a represented state, transfers or withholds something, moves or positions something, perceives or reports represented content in a way that the source stages as an independent act, or otherwise supplies a distinct researcher-addressable relation in the represented situation.

Support, copular, control, reporting, cognition, intention, possession, modal, and discourse verbs are **not automatically excluded**, but neither are they automatically primitives. Retain one only when the source stages that act itself as a distinct represented relation. If it merely hosts, frames, hedges, narrates, or manages another represented relation, inventory the hosted relation and omit the scaffold.

For every admitted VERB, preserve the smallest exact contiguous relation nucleus that retains its identity and posture. Keep required phrasal particles, polarity, modality, aspect, fixed relation markers, and fixed multiword material. Exclude separable arguments, scene/time coordinates, labels, independent locator material, and open-clause relations.

Do not emit overlapping VERB widths for one admitted relation. Serial/coordinated actions remain separate when the source stages distinct material moves. Repeated identical wording may remain separate when it represents distinct occurrences.

## 10. LOCATOR — admitted orientation occurrences

LOCATOR is **not a preposition/path census**.

First decide whether the source stages an orientation/positioning relation that materially locates or relates a retained coordinate, participant, referent, movement, or comparison frame. Only then choose the smallest exact contiguous source-native orientation nucleus.

Retain genuinely represented relative position, path/direction, containment, source-to-target spatial relation, movement orientation, and figurative/comparison orientation when independently staged.

Do not create LOCATOR merely from recipient/dative markers, possession/genitive markers, topic/aboutness relations, abstract argument/complement markers, ordinary object selection, temporal/discourse framing, a preposition that exists only as grammar, or a comparison marker with no distinct orientation function.

Decompose adjacent orientations when the source stages separate relations. Do not merge path, accompaniment, destination, waiting context, temporal context, or another orientation merely because they occur in the same clause.

A movement/state expression may be both VERB and LOCATOR only when the occurrence independently passes both admission tests.

## 11. Cross-class multiplicity

Class membership is not globally exclusive.

The same source wording or occurrence may appear in more than one class only when each retained row independently passes represented-role admission for that class.

Do not duplicate a phrase across classes merely because its words permit several linguistic interpretations. Do not use cross-class de-duplication to erase independently represented functions.

## 12. Recall and anti-inflation audit

After initial extraction, replay the whole source by scene/episode.

### Structural recall

Restore low-salience, unnamed, relationship-bound, participant-position, reported, prospective, action-defined, or present-telling PERSON/OBJECT/PLACE/TIME coordinates that the source clearly stages.

Structural recall may recover omitted coordinates but may not harvest every noun, temporal phrase, spatial phrase, or predicate.

### Relation recall

For LABEL/VERB/LOCATOR, search for **missed admitted roles**, not missed class-compatible words.

For each relation candidate ask:

1. What retained coordinate or admitted relation does it characterize, connect, change, maintain, position, or orient?
2. Is that function distinct in the represented graph, or is the wording only grammar, narration, discourse management, emphasis, or support?
3. Would removing it erase a researcher-addressable relation/characterization/orientation, or merely remove wording around a relation already represented?
4. If admitted, what is the smallest exact source-native span that preserves its identity and posture?

Reject candidates that cannot answer the first and third questions with a distinct represented function.

## 13. Literal, contiguity, and posture lock

Every source-derived non-null string must preserve source language character-for-character where the schema requires source text.

Never synonymize, lemmatize, repair spelling/grammar, normalize dialect, expand contractions, translate, polish, diagnose, standardize category names, change number, or substitute a conventional expression.

Never add a word not present in the exact contiguous source span. Never concatenate noncontiguous fragments. `source_wording`, `source_cue`, and `order_cue` must be exact source text where applicable. Only genuinely unnamed PLACE/TIME may use null `source_wording`.

Questions, uncertainty, hypotheticals, negations, corrections, remembered possibilities, reported material, attribution, and proposed future actions remain in source posture. Inventorying does not assert truth or realization.

## 14. Ordering and identity

Default within-class order is first material source anchor after same-class identity reconciliation.

Tie rules:

- broad/whole setting before dependent/contained setting when introduced together;
- whole before dependent part at the same anchor unless source order stages the part first;
- PERSON follows first material represented participation;
- remembered/reported/hypothetical/future material stays at source position rather than external chronology.

Repeated identical wording may receive separate units only when it instantiates separate represented role occurrences. The apparatus owns canonical IDs and deterministic numbering.

## 15. Primitive audit before compounds

Before compounds, replay the complete source and verify:

1. every distinct represented scene/interaction/relationship/participant position is present, including unnamed and present-telling positions;
2. every distinct organizing episode/phase/period/span/frame is present, including action-defined and unnamed frames;
3. stable people and source-treated referents are present without pronoun/discourse-shell inflation;
4. every LABEL has a characterized target/state and is not incidental texture;
5. every VERB is an admitted material relation occurrence, not merely a predicate/support/discourse token, and uses one minimal source-native nucleus;
6. every LOCATOR is an admitted orientation occurrence, not merely grammar/context, and uses one independent orientation nucleus;
7. same-class aliases/repetitions/nested restatements of the same role occurrence are reconciled without collapsing distinct occurrences;
8. low-salience, one-use, negative, questioned, reported, prospective, figurative, or relational primitives remain when they still pass admission;
9. every retained source string is exact and posture-faithful.

Do not aim for a hidden count. Do not maximize lexical coverage. Aim for one row per distinct researcher-addressable represented role at its class-native source grain.

## 16. Compound construction — replay the frozen admitted graph

Freeze all primitives first.

A compound represents one minimal source-staged binding among two or more frozen primitives that actively co-participate in one represented connection.

Create a compound only when:

1. at least two frozen primitives are actively bound by the source;
2. the binding adds reconstructive relational information beyond listing the members;
3. every member actively participates in that exact binding; and
4. the result is not a duplicate, alternate parse, transitive closure, arbitrary subset, nested restatement, or scene-wide mega-bundle.

A compound cannot create, delete, merge, split, retype, justify, or substitute for primitives. If the primitive ledger is wrong, do not repair it through compounds.

Qualitative/support material can be available around a binding without forcing every support primitive into the compound. `qualities_available` reports support availability; it is not a graph-closure instruction.

## 17. `qualities_available`

`qualities_available` is mechanical metadata. True means the source supplies material descriptive/qualitative evidence associated with that coordinate or binding; false otherwise.

It is not an alternate primitive layer and it is not a reason to omit or create a LABEL.

`Q` is never a primitive and never a compound member ref.

## 18. Isolation and candidate boundary

The worker must never receive:

- Leah-approved archetype rows or workbooks;
- expected counts;
- evaluator findings;
- scored predecessor outputs;
- canonical archetype extracts;
- case-specific hidden corrections/examples;
- sealed holdout source or output;
- prior holdout sessions.

The worker receives only this durable contract, the bounded runtime request, and the source case authorized for that run.

All calibration output remains candidate research. Worker completion, repeated passes, evaluator success, or certification does not itself promote any record to admitted APA data, Oval Office records, or sovereign fabric.

## 19. Calibration and certification gate

Before any sealed holdout becomes eligible:

1. immutable Case 2 and Case 6 workbook bytes must match their separately governed expected hashes;
2. both approved archetypes must repeatedly pass under the same finalized durable contract and saved-agent lineage;
3. all deterministic harness tests must pass; and
4. all failed/partial attempts must remain preserved.

After that gate, the calibrated lineage may run the sealed holdout exactly once. No repair to that lineage may be learned from the holdout result.

If the one-shot holdout is archetypal, retire the calibrated lineage. Create a brand-new saved agent containing only this finalized durable contract, with no prior agent session, archetype answer, evaluator result, or holdout output available to it, and run the sealed holdout once in a new session.

Certification requires the fresh agent to pass that clean-room holdout. Until then status remains `NOT CERTIFIED`.

Never promote records to Oval Office, mint APA IDs, or write candidate calibration output into admitted APA database/fabric as part of this process.
