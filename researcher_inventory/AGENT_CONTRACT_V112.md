## Mission

Read the complete source and recover a lightweight, source-faithful researcher inventory in exactly seven classes:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is comprehensive at **class-native research grain** but is not a token census, parse tree, semantic graph, or summary. Each class is an independent lens on the same source.

Do not perform APA scoring, protected-thread analysis, psychological interpretation, promotion, APA-ID creation, executive analysis, sovereign/admitted writing, or APA Data Fabric/database mutation.

## 1. Whole-source map, then seven independent class passes

Read the whole source before extracting any class. Silently map episodes/scenes, participants, acted-on or referred-to content, characterizations/states, relation edges, orientations, memories, reports, questions, intentions, alternatives, recurring relations, prospective situations, and present reflection.

Then inventory each class as though that class were the only class being requested. Do not economize across classes. A valid LABEL is not removed because a VERB or OBJECT helps express the same source moment. A valid LOCATOR is not removed because a PLACE or TIME exists. A valid TIME/PLACE support coordinate is not removed because compounds can reconstruct the scene.

Cross-class overlap is allowed when the same source material genuinely performs more than one class-native function. Same-class duplication is not.

## 2. Primitive admission: exact source identity + class-local selectability

Admit a primitive only when both gates pass.

### Gate A — exact class-native source identity

The source establishes the candidate at the smallest complete natural literal span for the requested class. Legitimate unnamed PLACE/TIME support may use `source_wording = null` with an exact source cue and a neutral mechanical tag.

### Gate B — class-local selectability

Ask only:

**If I were building this class by itself, does this source establish a distinct selectable entry of this class, rather than grammar, decoration, a same-class duplicate, or a fragment of a larger class-native entry?**

Do not ask whether the candidate is globally indispensable, important, central, recurring, unique across all seven classes, or unreconstructable from compounds. Do not use another class as a substitute for the requested class.

A legitimate entry may be local, one-use, mundane, neutral, nested, subtle, remembered, reported, prospective, uncertain, corrective, or low-salience.

## 3. Same-class economy only

Deduplicate only within the requested class when two mentions are true aliases, coreference, inflection-only repeats of one relation identity, or restatements of the same class-native entry.

Do not merge or suppress a candidate because a different class captures related meaning. Do not create one oversized primitive to do several class jobs.

When one source span contains several different class-native entries, keep the smallest complete span for the requested class and leave the other class jobs to their own passes.

## 4. Functional precedence over surface grammar

Classify by what the source is doing with the span, not by its part of speech or phrase shape.

- human/social participant → `PERSON`
- stable thing/content/referential handle → `OBJECT`
- characterization/state/identity/evaluation/comparison/posture → `LABEL`
- scene/location support → `PLACE`
- episode/period/phase support → `TIME`
- event/state/relation predicate → `VERB`
- orientation that situates retained structure → `LOCATOR`

When a phrase looks nominal, locative, comparative, or verbal but its source function is to characterize/evaluate/state what something is like, `LABEL` takes precedence over its surface syntax. When a phrase merely names content/thinghood without characterizing it, use `OBJECT`. When it actually situates something relative to a place/path/direction/container/origin/destination/accompaniment/context, use `LOCATOR`.

Do not force one class to absorb another class's job.

## 5. PLACE — scene/location support ledger

Build a ledger of distinct source-established scenes/locations supporting represented material.

Retain broad and contained/local support separately when they are different scene coordinates. Retain legitimate unnamed support when a materially differentiated occurrence, object location, destination, waiting scene, later interaction, remembered scene, or present telling/reflection requires a place coordinate even though the source does not name the place.

For unnamed support use `source_wording = null`, an exact source cue, and a neutral mechanical tag. Do not invent a location name.

Reject physical nouns, possessions, destinations mentioned only as objects, and spatial wording that does not establish a distinct scene/location support coordinate.

## 6. TIME — episode/phase support ledger

Build a ledger of distinct source-established temporal frames in source progression.

Retain materially differentiated attempts/conditions, response/help episodes, transitions/departures, waits, intended periods, later conversations/reports, recurring spans, remembered phases, prospective/future situations, and present telling/reflection when each is a separately selectable TIME frame. A TIME does not need an explicit clock/date/temporal noun.

For unnamed TIME use `source_wording = null`, an exact source cue, and a neutral mechanical tag. Preserve prospective/questioned/intended posture without asserting occurrence.

Reject tense/aspect grammar, isolated temporal words, duration fragments, recurrence words, and one-time-per-action proliferation when they do not establish a separate episode/period/phase.

## 7. PERSON — participant ledger

Retain the speaker and every distinct source-established human/social actor or stable group that functions as a participant after true coreference.

Participation may be direct, offscreen, remembered, reported, relational, institutional, possessive within a material relation, or prospective. Merge aliases/coreference. Reject rhetorical, generic, and nonreferential addressees and incidental mentions that never become represented participants.

## 8. OBJECT — referential-handle ledger

Retain each source-established concrete, abstract, internal, relational, decision/choice-like, value-like, set/category, content, or figurative handle that is treated as a separately selectable thing/content.

A handle may be acted on, possessed, exchanged, checked, contrasted, questioned, remembered, reported, selected, decided about, located, valued, contemplated, or otherwise reified.

Reject noun census, generic pronouns/deixis, incidental props, arbitrary nominalizations, discourse wrappers, and clause-sized propositions whose content is already carried by class-native units.

**LABEL precedence:** do not type a phrase as OBJECT merely because it is a noun phrase if its source function is to characterize, evaluate, compare, identify, or state what a person/thing/situation is like.

## 9. LABEL — characterization/state ledger

Retain each smallest complete source-native characterization, quality, state, identity, evaluation, comparison, correction, acceptance/rejection, polarity, manner, question/candidate label, or posture that the source assigns to represented material.

Local, one-use, idiomatic, colloquial, negated, uncertain, figurative, comparative, and corrective labels may qualify. Preserve the source's exact posture.

**Function beats shape:** a phrase that syntactically resembles an object, location, comparison, or clause is still LABEL when its represented job is characterization/state/evaluation.

Reject pure intensification, exclamation, rhetorical flourish, scene color, and modifiers that do not independently characterize represented material.

## 10. VERB — lexical relation ledger

Retain each materially represented lexical predicate increment that establishes an event, state, action, response, movement, possession, perception, communication/report, cognition, intention, question, decision, comparison, evaluation, transition, or location/state relation.

Use the **smallest complete lexical predicate construction**. Preserve a required particle, reflexive, negation, modal, or bound complement when needed for the predicate's identity. Do not swallow a separately typed subject, object/content handle, label, locator, place, or time merely to make the verb phrase sound complete.

Split matrix/embedded or coordinated predicates when they perform different represented relation jobs. Retain simple and one-use lexical relations. Reject auxiliaries, tense/aspect support, bare copular grammar when it adds no lexical relation beyond a LABEL/state, discourse organizers, and same-relation restatements.

Inventorying a predicate under negation, uncertainty, question, intention, hypothetical, report, recurrence, or future language does not assert that it occurred.

## 11. LOCATOR — orientation ledger

Retain each smallest complete exact source span that independently orients a retained node/relation/scene by position, containment, path, direction, origin/destination, proximity, accompaniment, recurrence, procedure/relation, internal/mental context, temporal position, or figurative/comparative orientation.

A LOCATOR must answer an orienting relation such as where/into-from/through-toward/with-relative-to/within-context, not merely supply any prepositional or adverbial phrase.

Reject bare prepositions, ordinary purpose/beneficiary/topic/argument markers, discourse connectors, degree/intensifier phrases, generic deictics, bare duration/how-long wording, aspectual words, and duplicated TIME support when they do not orient retained structure.

**LABEL precedence:** if the phrase's primary represented job is characterization/evaluation/comparison rather than orientation, classify it as LABEL even if its syntax appears spatial or comparative.

## 12. Atomic span and literal lock

For every admitted primitive choose the smallest exact contiguous source span that preserves its class-native identity.

Preserve required particles/prepositions, reflexives, complements, negation, modality, uncertainty, questions, attribution, comparison, idiom/dialect, and hypothetical/prospective/reported/corrective posture when semantically required.

Never normalize, clean, improve, translate, diagnose, euphemize, paraphrase, lemmatize into a different surface form, or substitute synonyms.

Every non-null `source_wording`, every `source_cue`, and every non-null `order_cue` must be a character-for-character contiguous source substring. Neutral mechanical tags are allowed only for legitimate unnamed PLACE/TIME support.

## 13. Coverage matrix and freeze audit

Before freezing primitives, perform a coverage matrix over the whole source:

1. enumerate each differentiated scene/episode in source order;
2. for each scene/episode, ask independently whether it establishes at least one selectable entry in each of the seven classes;
3. add every legitimate class-native entry found by that pass, including local and one-use entries;
4. then run an anti-census pass to remove grammar, discourse carriage, incidental props, stylistic color, purpose/topic fragments, and same-class duplicates;
5. run functional-precedence review to correct OBJECT/LABEL/LOCATOR/VERB drift;
6. run atomic-span and literal-lock review;
7. repeat the matrix once after corrections and freeze only when no class-native omission or same-class duplicate remains.

The matrix is an omission detector. It does not require every scene to contain every class.

## 14. Ordering and identity

Primitive identity follows class-local semantic identity, not mention count. Merge true aliases/coreference and same-class repeats. Do not merge genuinely distinct class entries merely because related or reconstructable from one another.

Code owns canonical IDs. The worker supplies neutral identity keys only for merge. Order by first source establishment after coreference, subject to apparatus speaker-first PERSON and genuine broad-before-contained support rules. Do not reorder by importance or real-world chronology.

## 15. Relation-instance compounds

Only after all seven class inventories are frozen, reread the source relation by relation.

For each retained VERB relation instance, emit the smallest complete compound linking the frozen coordinates that actually participate in that exact represented relation. Include participant, content/object, characterization, support, and orientation refs when they are part of that relation instance. Do not omit a participating class-native unit merely because the relation remains intelligible without it.

Additional non-VERB compounds are allowed only for represented relation/state structure not already captured by a retained VERB relation.

Do not emit graph closure, every possible pair, arbitrary co-occurrence bundles, singleton equivalents, generic question closure, duplicate restatements, subset/superset permutations, scene mega-bundles, or compounds containing rejected non-class-native detail. Compounds never substitute for missing primitives and never justify deleting a valid primitive.

## 16. Completion standard

The inventory is complete when the whole source was read; all seven class-local ledgers were independently audited; legitimate low-salience, local, unnamed support, lexical relations, characterizations, handles, and orientations were retained; cross-class economy did not suppress a valid class projection; same-class duplicates and non-class-native detail were removed; functional type precedence is correct; exact source wording/posture is preserved; and compounds reconstruct relation instances only from frozen units.

Never target hidden counts or infer hidden gold.
