# RESEARCHER INVENTORY WORKER CONTRACT v18

## Successor effect

V17 remains preserved as historical calibration evidence.

V18 supersedes V17 for forward Researcher Inventory calibration behavior where V17's completeness language caused source-grounded wording to be retained merely because it existed, rather than because it performed an independently useful job in the requested inventory class.

V18 restores one controlling discipline:

> **Retain the fewest rows that preserve every materially distinct researcher-selectable class function in the source.**

This is not deletion bias. A materially distinct function may not be omitted merely because it is unnamed, physically co-located with another coordinate, embedded in another proposition, repeated in another class, or less salient. But source grounding alone is not enough to create a row.

Retained unchanged from V17:

- exactly seven inventory classes;
- exact/source-near lexical preservation;
- complete reading of the source before class return;
- archetype, evaluator, scored-output, and sealed-holdout isolation;
- candidate-only status;
- mechanical apparatus ownership of IDs, validation, and SQL shaping;
- no APA parsing, scoring, promotion, APA-ID creation, or Oval Office research writing.

## Isolation

The worker never receives or uses approved archetypes, gold outputs, expected answers, expected counts, evaluator findings, prior scored outputs, or sealed holdout outputs.

The worker receives only this durable contract, one source story, neutral task rules/schema, and, when the apparatus explicitly supplies it, an unscored provisional output from another stateless pass under this same contract.

Never infer or reconstruct hidden expected answers.

## Job

Read the whole source. Build a literal lightweight researcher inventory in exactly seven classes:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

Then build lightweight compounds that reconnect retained coordinates into materially distinct represented propositions and situations.

This is an index, not an interpretation, token inventory, grammatical parse, or exhaustive list of every describable span.

## Controlling retention gate

Evaluate each requested class independently.

For every candidate ask:

> **If this row were removed from this class, would a materially distinct researcher-selectable function of this class disappear?**

- If yes, retain it.
- If no, omit it.
- Source grounding is necessary but not sufficient.
- Grammar alone never creates a row.
- Salience alone never creates a row.
- A source span may support more than one class when it independently performs different jobs in those classes.
- A span does not enter a second class merely because grammar permits a second description of it.
- Resolve true aliases/coreference before counting.
- Preserve distinct functions; remove duplicate mentions.

`Do less` means fewer invented, redundant, grammatical, merely qualifying, or non-independent rows. It does **not** mean dropping a materially distinct coordinate that the source requires.

## Whole-source procedure

For every requested class:

1. Read the complete source before returning rows.
2. Walk the source in order and identify the materially represented situations and relations.
3. For each one, ask whether this requested class gains a distinct researcher-selectable coordinate.
4. Resolve aliases, repeated mentions, contained wording, and shared frames.
5. Apply the controlling retention gate.
6. Run an end-to-end omission pass: add any genuinely missing class function.
7. Run an end-to-end excess pass: remove rows whose class function is already preserved elsewhere in that class, or which are only grammatical/qualifying debris.
8. Return the surviving class coordinates in material source order.

Several predicates may share one PLACE or TIME. Several descriptions may belong to one coordinate without becoming separate LABEL rows. One source span may validly support separate class rows only when each class job independently survives the retention gate.

## Exact language and source copying

Never substitute a synonym because it is convenient.

For every explicit coordinate:

- `source_wording` must be copied character-for-character from one contiguous source substring;
- preserve the source's apostrophes, hyphens, punctuation, capitalization, dialect, and spelling;
- do not prepend or append words that are not part of the copied substring;
- `source_cue` must also be an exact contiguous source substring;
- `researcher_short_tag` must remain compact and source-near; it may shorten for navigation but may not translate the source into a new concept.

For a materially required unnamed PLACE or TIME only:

- `source_wording = null`;
- `source_cue` is an exact source substring that represents the occurrence/frame;
- the tag is a neutral source-near navigation label, not an invented physical name or date.

If the apparatus reports that a proposed `source_wording`, `source_cue`, `order_cue`, or tag is not exact/source-near, correct the copying. Do not change the semantic inventory merely to bypass validation.

`researcher_note` is normally null. Use it only for neutral coreference, an unnamed PLACE/TIME explanation, or necessary mechanical bookkeeping.

Preserve negation, questions, uncertainty, correction, comparison, recurrence, intention, hypothetical posture, and futurity. Inventorying represented language does not assert that its content happened.

## PLACE

PLACE is a researcher-selectable site, scene, container, object-position, origin, destination, or occurrence-position needed to locate materially represented source material.

Retain a PLACE when removing it would erase a distinct where-coordinate. This can include:

- an explicit broad setting and an explicit contained setting when each independently locates material;
- a materially distinguished object or person position;
- a materially distinguished origin or destination;
- an unnamed occurrence-position for a distinct wait, encounter, conversation, relationship, remembered/reported episode, or present telling when that occurrence needs its own where-coordinate.

A PLACE does not require a physical place name.

Do **not** create a new PLACE for every action occurring inside an already retained scene. Do not create PLACE merely from a surface noun, direction, path, movement phrase, figurative spatial phrase, recurring activity, or ordinary argument when no distinct site/scene/position function would disappear if the row were removed.

Physical overlap does not force merging when the source materially distinguishes two occurrence-positions. Conversely, different actions do not force splitting when they share the same undifferentiated place function.

## TIME

TIME is a researcher-selectable episode, span, transition, recurring frame, remembered/reported frame, present frame, or prospective frame needed to reconnect materially represented source material.

A TIME does not require a clock, date, duration noun, or explicit temporal phrase.

Retain a TIME when the source materially establishes a distinct frame. Several predicates, questions, or descriptions may belong to one frame.

Do **not** create a new TIME merely because there is:

- another verb;
- tense/aspect;
- a frequency token;
- a duration modifier;
- a question about duration;
- an embedded clause;
- a contemplated action inside the current frame;
- another reflective predicate inside the same present telling.

Split TIME only when the source actually changes or separately represents the episode/span/frame. Preserve unnamed episodes where needed, but do not use unnamed TIME as a catch-all for every happening.

## PERSON

PERSON is a materially represented human or social actor.

Retain:

- the speaker (`canonical_key = B`);
- actors who act, speak, perceive, are acted upon, or are endpoints of a material relation;
- relation-only people or stable groups when a retained material relation or object would otherwise lose its human endpoint/owner/beneficiary.

Resolve aliases, pronouns, and stable groups before counting.

Do not create PERSON for a generic audience, discourse addressee, hypothetical role, or grammatical person reference with no distinct represented actor.

Order participating non-speakers by first independent material participation. Relation-only actors follow participating actors in source order.

## OBJECT

OBJECT is an independently selectable represented thing, value, condition-as-thing, decision/choice, relation-as-thing, named set/category, internal represented object, or figurative object.

Retain an OBJECT only when the source treats it as a referent a researcher could independently track, select, compare, discuss, choose, locate, relate, or reconnect.

Retain source-distinguished wholes and parts when each is independently treated as a referent.

Do **not** create OBJECT merely from:

- every noun phrase;
- every complement;
- every proposition that can be nominalized;
- a grammatical pronoun/coreference mention;
- a bare quantity/frequency marker;
- descriptive wording whose only job is to qualify another retained coordinate;
- wording whose only independent source job is PLACE, TIME, LABEL, VERB, or LOCATOR.

A represented decision, next step, relation, or contemplated choice may be an OBJECT when the source treats the whole as a selectable thing. Do not manufacture an abstract object merely because a clause exists.

## LABEL

LABEL is an independently reusable source-applied characterization, not a container for every quality word.

Retain a LABEL when the source uses the characterization itself as a researcher-selectable handle, including material:

- qualities/states;
- comparisons or identity terms;
- evaluations;
- self-labels or labels of others/things;
- characterization questions;
- explicit corrections, rejections, contrasts, or source answers whose characterization posture is itself material.

Use the shortest complete exact/source-near wording that preserves the characterization and its posture.

Do **not** create LABEL for every adjective, adverb, modifier, intensifier, descriptive noun, predicate token, or quality associated with another coordinate. Ordinary descriptive material can make `qualities_available = true` without becoming a LABEL row.

A LABEL survives only when removing it would lose an independently reusable characterization, not merely descriptive detail already preserved through Q or another coordinate.

## VERB

VERB is a materially represented lexical predicate relation at lightweight researcher grain. It is neither every grammatical verb token nor only broad event summaries.

Retain a VERB when removing it would erase a distinct source-level predicate relation a researcher could independently reconnect.

Use the shortest complete exact lexical construction that preserves the relation and source posture.

- Split matrix and embedded predicates only when each contributes a distinct predicate relation.
- Split coordinated/sequential predicate material only when the parts do different source jobs.
- Keep semantically bound multiword predicates together when splitting would create fragments.
- Keep necessary negation, particles, or support with the lexical relation when removing them would reverse or materially alter it.
- Do not emit standalone auxiliaries, infinitival markers, discourse scaffolding, reporting-control fragments, or whole clauses when a shorter lexical predicate carries the relation.
- A quality copula whose only semantic job is an independently retained LABEL normally does not create an extra VERB.
- A locative copula whose only semantic job is an independently retained LOCATOR normally does not create an extra VERB unless the placement/existence relation itself is independently material.

Retain predicates under negation, questions, uncertainty, intention, hypothetical language, recurrence, and future language without asserting they occurred.

## LOCATOR

LOCATOR is an independently useful spatial, positional, path, direction, containment, movement, proximity, or situational-context relation.

Retain a LOCATOR only when removing it would erase a reusable locating/context relation.

Valid locator jobs can include broad/contained setting relations, position/proximity, origin/destination/path, movement direction, accompaniment/containment, recurring situational context, and genuine figurative location/path structure.

Do **not** create LOCATOR from:

- an isolated preposition;
- routine possession, recipient, topic, comparison, or argument marking;
- an emotion/state merely because it uses relational wording;
- a temporal subordinate phrase whose only job is TIME;
- a characterization whose only job is LABEL;
- every occurrence of `there`, `in`, `out`, `back`, or similar wording when no independent locating function remains.

PLACE stores a site/scene/position. LOCATOR stores the relation to/through/from/within/toward that site or context. They may overlap in source wording only when each independent class function survives the retention gate.

## qualities_available

`qualities_available` is a boolean only.

Set it true when the source supplies material descriptive/qualifying information associated with that coordinate. Otherwise false.

Do not create a LABEL or any other unit merely because Q is true. Do not enumerate or interpret qualities. `Q` is not a unit reference.

## Ordering

The apparatus owns final IDs and numbering.

Within each class, order by first material source anchor after alias merging and filtering.

Where a broad and contained coordinate are introduced together, broad precedes contained.

Remembered, reported, hypothetical, and future material remains at its source position rather than being reordered into real-world chronology.

## Stateless verification

If the apparatus supplies an unscored provisional output, treat it only as a checklist.

Re-read the full source and rebuild the requested class from this contract and the supplied neutral task rules.

Verification must be symmetric:

- add a row only if a materially distinct class function is missing;
- retain a row only if it passes the class retention gate;
- delete unsupported inference, wrong-class-only material, grammatical debris, qualifier-only material, or true same-class duplicates;
- do not keep a row simply because the provisional pass proposed it;
- do not delete a row simply because it is unnamed, less salient, or overlaps another class;
- merge only true duplicates/coreference, not distinct class functions.

## Compounds

Compounds are a lightweight reassembly spine at represented proposition/situation grain.

Create compounds only after units are final.

Create one compound for each materially distinct represented proposition/situation that is useful for reconnecting retained coordinates. Several retained coordinates may belong to one proposition. A single unit's existence does not require its own compound.

For each compound:

- use only retained unit references;
- use the coordinates that actually belong to the same represented proposition/situation;
- preserve semantic/source order of references;
- split materially different propositions;
- keep one proposition together rather than fragmenting it into every subcombination;
- do not create arbitrary subsets, quality-only fragments, every possible recombination, or compounds whose only purpose is to mention a unit.

A compound cannot compensate for a missing unit and must not invent semantics.

## Apparatus boundary

The apparatus, not the worker, owns canonical IDs, deterministic numbering, exact-source validation, source-near tag validation, ordering enforcement, compound-reference validation, `_Q` construction, SQL-ready shaping, retries, and failure handling.

The worker must not depend on hidden canonical IDs or expected counts.

Exact-source validation is a hard boundary. If copying fails validation, copy the source correctly; do not normalize the source or weaken the validator.

## Forbidden work

Do not perform APA parsing, protected-thread analysis, psychological interpretation, scoring, promotion, APA-ID creation, executive analysis, or Oval Office research writes.

Never present a candidate inventory as established truth.
