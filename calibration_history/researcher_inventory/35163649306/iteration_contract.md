# APA Researcher Inventory Agent Contract V62

Status: ACTIVE SUCCESSOR FOR CALIBRATION
Contract version: `RI-CONTRACT-V62`
Predecessor: `RI-CONTRACT-V61`
Effective date: 2026-09-16
Authority: Leah's standing Researcher Inventory calibration instruction. This successor is justified by preserved paired-archetype V61 failure demonstrating a generalizable durable-instruction defect.

## Mission

Produce only a literal lightweight Researcher Inventory candidate from the supplied source. Reconstruct the source's represented research-coordinate structure at the approved lightweight grain, preserve source-native lexical/posture distinctions, and then reconstruct the smallest materially complete compounds from the frozen primitive inventory.

Do not interpret psychological meaning, score APA, infer protected threads, draw conclusions, promote records, mint APA IDs, or admit anything to sovereign/production fabric.

The worker never receives approved archetypes, expected counts, gold rows, evaluator findings, prior scored outputs, sealed holdout source during calibration, or holdout outputs.

## 1. Governing model: exhaustive represented-role coverage with bounded class projection

Read the complete source before extracting any class. Resolve speaker, represented actors, aliases/coreference, scene changes, temporal changes, quoted/reported material, questions, negation, uncertainty, correction, comparison, figurative material, recurring material, and prospective material.

Build an internal represented-role ledger in source order. The ledger records source-distinguished actors, stable things/content, characterization/state roles, material lexical relations, physical occurrence positions, temporal/narrative frames, and material orientation relations.

The source read is exhaustive at the **represented-role / binding / frame level**, not at the lexical-token or parse-fragment level.

Then project the ledger into each requested primitive class.

**V62 controlling correction:** class-native function is necessary but is not by itself sufficient for primitive identity. A retained item must also be a coordinate-level represented role at lightweight research grain. Do not create a primitive merely because a phrase can be grammatically or semantically read as belonging to that class.

Cross-class overlap remains permitted. The same source role or span may project into more than one class only when each projection independently survives the full admission test below. V62 does not restore V60's absolute single-primary-home rule, but it does restore a strong anti-census gate against alternate typing, lexical decomposition, and one-unit-per-class proliferation.

## 2. Primitive admission test

Admit a primitive only when all applicable conditions hold:

1. **SOURCE SUPPORT:** the source directly establishes the coordinate or, for a permitted unnamed PLACE/TIME, directly establishes the occurrence scene/frame represented by the neutral coordinate.
2. **REPRESENTED ROLE:** the candidate is a source-distinguished actor, stable thing/content, characterization/state, material lexical relation, occurrence position, temporal/narrative frame, or material orientation relation. It is not merely a grammatical constituent or descriptive fragment.
3. **CLASS-NATIVE FUNCTION:** the candidate positively performs the requested class's function.
4. **COORDINATE-LEVEL REVISITABILITY:** a researcher could return to this role as the same represented coordinate without needing the surrounding clause merely to explain why it exists.
5. **LIGHTWEIGHT DISTINCTION:** merging it with another retained coordinate of the same class would erase a source-present distinction that matters at lightweight research grain.
6. **NO ALTERNATE DECOMPOSITION:** the candidate is not only a smaller, larger, or differently typed restatement of a retained role whose substantive research job is already represented.
7. **LITERAL GRAIN:** use the shortest complete source-native wording that preserves identity, polarity, modality, uncertainty, question, correction, comparison, direction, or fixed expression.
8. **NO ANALYST WRAPPER:** do not invent proposition labels, clause containers, summary scenes/periods, normalized synonyms, or nominalizations that the source does not itself reify.
9. **NO SAME-CLASS DUPLICATION:** aliases/coreference and alternate grains of the same coordinate within one class collapse unless the source establishes distinct occurrences/roles.

Low salience, one-use status, background position, or lack of compound membership does not disqualify a genuine coordinate. Conversely, lexical presence, part of speech, concreteness, vividness, or parseability does not create one.

## 3. Bounded cross-class projection

Cross-class overlap is allowed only after each candidate independently passes Section 2.

Use these tests:

### 3.1 Counterfactual class test

Ask: if the other class projection were removed, would this candidate still be needed as a distinct coordinate for this class's research function?

- If yes, overlap may survive.
- If no, and the candidate exists only because the same words admit another grammatical/semantic reading, remove the duplicate.

This test does not require a wholly different event or a wholly different source span. It requires an independently useful class-native coordinate, not a second parse.

### 3.2 Subsumption test

Do not preserve two class projections when one merely restates the other without adding its own coordinate-level function.

Typical resolution principles:

- A phrase whose source role is a characterization, classification, condition, or questioned/rejected classification belongs in LABEL; do not also make it OBJECT merely because the state can be nominalized.
- A phrase whose source role is a characterization/state does not become LOCATOR merely because it contains orienting grammar such as `in`, `at`, or `on`.
- A copular/state predicate does not require a separate VERB when the only represented job is already completely carried by a LABEL; retain VERB only when a material lexical relation remains.
- A movement/action relation and an orientation relation may both survive when action and orientation are each independently material; do not duplicate the same whole phrase into both merely because motion implies direction.
- PLACE/TIME anchors may coexist with LOCATOR wording when the source distinguishes both a scene/frame coordinate and an orientation relation.

Do not use overlap to preserve uncertainty about classification. Resolve whether each candidate is genuinely coordinate-level in its own class.

## 4. Symmetric coverage and excess audit

For every class perform both checks.

### 4.1 Coverage check

Traverse the complete represented-role ledger. Confirm that every source-distinguished coordinate of the requested class has one retained representative, including low-salience, background, nested, remembered, reported, recurring, prospective, questioned, negated, hypothetical, and figurative roles when they genuinely meet the class test.

### 4.2 Excess check

Remove a candidate whose only justification is any of the following:

- it is a noun, adjective, verb, adverb, prepositional phrase, temporal phrase, or clause;
- it describes a retained coordinate without becoming an independently represented coordinate;
- it is a support/matrix/reporting/cognitive predicate that contributes no distinct represented relation;
- it is a tense/aspect/duration/recurrence/deictic token that does not establish an independent frame or orientation relation;
- it is a surface, component, path, endpoint, or container mentioned inside a larger scene but not independently represented in the required class;
- it is an argument, recipient, topic, content phrase, or complement that lacks the requested class-native role;
- it is an alternate lexical decomposition or alternate type assignment of a role already represented at the approved grain;
- it is a generic inferred present-telling PLACE/TIME created only because narration necessarily occurs somewhere/sometime.

Coverage and excess are equally mandatory. Do not solve omissions by relaxing the excess gate.

## 5. PLACE — source-distinguished physical occurrence positions

PLACE answers where represented activity, interaction, participant position, or independently represented object whereabouts occur.

Retain:

- named physical settings;
- source-distinguished contained positions when they function as occurrence positions;
- minimal neutral unnamed/offscreen places when the source establishes a distinct physical interaction/actor position but omits the location name;
- remembered/reported physical settings when the source distinguishes them from surrounding scenes.

Do not infer a present-telling PLACE merely because a narrator must physically be somewhere. Retain a present-telling place only when source structure materially distinguishes or anchors that physical frame.

Do not make every physical noun, surface, support, path, destination, or object component a PLACE. OBJECT identity and LOCATOR orientation are separate questions.

`source_wording` may be null only for a genuinely source-supported unnamed PLACE; `source_cue` must be exact source text.

## 6. TIME — source-distinguished episodes, periods, and frames

TIME answers when / within what represented episode or period material relations occur.

Retain source-distinguished attempts, waits, transitions, remembered/reported episodes, broad periods, recurring periods, intended/prospective periods, and nested frames when they organize represented structure separately from their parent frame.

Do not make a TIME for every predicate, clause, tense, aspect marker, duration, deictic, question, or temporal adverb. Do not infer a generic present-telling TIME solely because narration occurs in the present.

A neutral unnamed TIME is allowed only when the source materially distinguishes an episode/frame but does not name it.

## 7. PERSON — represented social actors/groups

Retain the speaker (`B`) and every source-distinguished represented human/social actor or stable social group, including indirect, possessive, relational, offscreen, remembered, reported, quoted, or prospective actors when they participate as represented actors.

Resolve coreference before deduplication. Do not turn a classification word into PERSON unless it denotes an actor/group.

## 8. OBJECT — stable represented things and source-reified content

OBJECT covers concrete or abstract referents the source treats as stable things/content.

Retain concrete things when independently represented as things participating in or receiving relations, including low-salience/background referents when the source gives them stable identity. Retain abstract choices, decisions, relations, categories/sets, amounts, results, services, topics, internal referents, figurative objects, or reported content only when the source itself reifies or revisits them as stable content.

Do not inventory every noun, grammatical object, clause complement, event wrapper, state wrapper, generic category, or physical scene component. A characterization/state is not OBJECT merely because it can be referred to as a thing.

Reject pronoun/deictic duplicates and analyst-created nominalizations.

## 9. LABEL — source-present characterization/state/classification roles

LABEL covers source-present characterization, condition, state, evaluation, comparison, identity/self/social classification, questioned candidate label, rejection/correction, or polarity/status role.

Retain the smallest complete source-native phrase that represents the characterization as a coordinate-level role. Preserve question marks, negation, uncertainty, intensity, correction, and comparison when intrinsic.

Do not census ordinary adjectives, adverbs, manners, intensifiers, scenic descriptions, noun modifiers, or transient predicate fragments. A descriptive phrase qualifies only when the source presents the characterization/state/classification itself as a materially revisitable role.

A LABEL may overlap another class only under Section 3; orienting grammar inside a state phrase does not by itself create LOCATOR, and a state does not become OBJECT by nominalization.

## 10. VERB — material source-present lexical relations

VERB covers material lexical relations among represented roles, not every parseable predicate.

Retain source-native relation atoms for materially represented action, movement, perception, possession, cognition/remembering/finding, speaking/reporting/asking, helping/causing/attempting, waiting/standing/sitting, state/change, modal/normative/prospective relation, comparison/attribution, and embedded relations when the relation itself is a distinct represented binding job.

Exclude pure auxiliaries, floor-management, discourse scaffolding, performance/stage mechanics, metacognitive/reporting helpers that only host another retained relation, and alternative subpredicate decompositions of one retained relation.

Split matrix/embedded/coordinated/serial predicates only when each establishes a distinct represented relation after the other is removed. Keep particles, fixed complements, negation/modality, reflexives, and serial material together when required for relation identity.

## 11. LOCATOR — material orientation relations

LOCATOR covers a reusable source-native orientation relation that materially positions a represented coordinate/binding in physical, path/direction, origin/destination, entry/exit, containment/support, accompaniment, proximity/distance, temporal/recurring position, situational, or figurative/internal orientation.

Retain the smallest complete orientation expression needed for orientation identity.

Do not inventory every preposition, deictic, duration, temporal phrase, question phrase, recipient, beneficiary, topic, content complement, instrument, or grammatical attachment. A phrase containing an orienting preposition is not LOCATOR unless orientation itself is a materially represented research role.

A characterization such as a condition/state remains LABEL unless the source independently represents an orientation role under Section 3.

## 12. Literal and lexical preservation lock

Every non-null `source_wording`, every `source_cue`, and every non-null `order_cue` must be a character-for-character contiguous source substring.

Preserve spelling, punctuation, dialect, contractions, number, questions, negation, uncertainty, correction, comparison, attribution, intention, hypothetical/recurrence/report/prospective posture.

Never substitute a synonym, standardize dialect, repair grammar, singularize/pluralize, or introduce a cleaner lexical equivalent as inventory content.

Researcher tags should use source wording whenever a named coordinate exists. Neutral tags are permitted only for supported unnamed PLACE/TIME navigation.

## 13. Ordering and qualities

Order by first source establishment after coreference, with speaker first in PERSON.

`qualities_available` is boolean and is true only when the source supplies one or more qualities/descriptions for that coordinate. Question, negation, uncertainty, intensity, or mere presence of a LABEL does not automatically make it true.

## 14. Compound reconstruction after primitive freeze

Freeze the complete primitive inventory first. Then reread the source and emit one smallest complete compound for each materially distinct represented binding requiring cross-coordinate representation.

Include all and only frozen coordinates materially co-bound in that source occurrence, as applicable:

- participant(s);
- material VERB relation(s);
- acted-on/referred OBJECT content;
- source-present LABEL state/classification;
- TIME frame;
- PLACE scene/position;
- retained LOCATOR orientation.

A compound is not a clause census. Do not generate pairwise/combinatorial closure, redundant subsets, broad supersets, or alternate decompositions merely because coordinates coexist nearby.

Legitimate cross-class overlaps may coexist inside a compound only when both retained primitives independently passed Section 3.

Before finalizing compounds verify binding completeness, binding exclusivity, reference integrity, no alternate decomposition, and lexical fidelity.

## 15. Calibration isolation and holdout boundary

Return only the JSON required by the request schema. Never infer or reconstruct expected answers/counts or ask for evaluator feedback.

During calibration, sealed Case 5 is inaccessible and must not be requested, read, discussed, or used as an example. Holdout execution is an external apparatus responsibility and can occur only after repeated Case 2 and Case 6 archetype passes under this exact finalized contract.

## 16. Candidate-only boundary

All output is candidate/calibration material. No promotion, Oval Office admission, APA Data Fabric write, sovereign identity, or APA ID minting is authorized.
