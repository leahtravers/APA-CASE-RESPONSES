## 1. Whole-source construction order

### Pass A — read the whole source

Walk the represented source from beginning to end before extracting any class. Consider actual, remembered, reported, relational, recurring, reflective, intended, questioned, hypothetical, negated, corrected, figurative, and prospective material without flattening its posture.

### Pass B — evaluate each class independently

For every plausible coordinate in the requested class ask:

> If this coordinate were removed from this requested class, would a materially distinct function of this class disappear from the inventory?

- If yes, retain it.
- If no, omit it.
- Grammar alone never creates a coordinate.
- Salience alone never creates a coordinate.
- Low salience never defeats a genuine class function.
- The same source span may independently qualify in more than one class when it performs different jobs.
- Never omit a legitimate coordinate merely because related wording is already retained in another class or compound.
- Never duplicate one class job through aliases, repeated mentions, alternate tokenization, or grammar-only fragments.

### Pass C — literal and coreference audit

Resolve true aliases/coreference, preserve exact source wording, preserve source posture, and order by first source establishment subject to the class rules below.

### Pass D — primitive freeze

Freeze all retained units before compounds. A compound may not repair a missing primitive or justify an otherwise unsupported primitive.

### Pass E — proposition-level compounds

Map the represented source using only frozen units. Preserve materially distinct propositions, situations, predicate relations, characterization propositions, questions, corrections, comparisons, reflections, and prospective relations that are useful for reconnecting the inventory.

## 2. Smallest sufficient functional grain

Retain the smallest complete source-native coordinate that preserves the distinct class job.

Do not atomize auxiliaries, articles, bare prepositions, repeated pronouns, inflectional material, or grammatical support into standalone coordinates. Conversely, do not merge neighboring lexical relations, orientations, episode frames, values, or occurrence positions merely because they occur in one sentence, clause, scene, or broad semantic bundle.

Pieces remain together only when separating them would destroy the source-native identity of one coordinate or create grammar debris rather than two independently reusable class functions.

## 3. PLACE — site and occurrence position

PLACE represents a materially useful site or occurrence-position.

Retain when independently useful:

- broad and contained physical/institutional settings;
- materially represented object positions;
- origin/destination positions when they function as places;
- positions of distinct waits, encounters, conversations, reports, remembered scenes, comparison scenes, and present telling/reflection;
- unnamed occurrence positions even when physically overlapping another retained PLACE.

Different represented episodes may require distinct PLACE coordinates at the same physical venue when the occurrence-position itself is useful for reconnection.

Do not create PLACE merely from every spatial noun, body part, surface, path, distance phrase, deictic, or figurative expression. Type by the actual class job.

For genuinely unnamed places, use `source_wording: null`, an exact source cue, and a neutral researcher tag.

## 4. TIME — episode and period frame

TIME represents a materially distinct episode or period needed to reconnect the source.

Retain frames such as:

- initial attempt/condition;
- response/help episode;
- departure/transition episode;
- wait;
- intended period;
- later conversation/report;
- recurring span;
- relationship period;
- remembered/comparison frame;
- present reflection/telling;
- separately represented prospective/future frame.

Several actions may share one TIME, but split when the source materially stages a new episode/period. A temporal word, duration, frequency marker, tense, or sequencing phrase does not by itself create TIME.

For genuinely unnamed times, use `source_wording: null`, an exact source cue, and a neutral frame tag.

## 5. PERSON

Retain `B` plus every distinct represented human/social actor or stable group after true coreference when the source gives that actor a distinguishable participant, relational, reported, remembered, prospective, or institutional role.

Minor, possessive/relational, offscreen, remembered, reported, and prospective actors may qualify. Suppress true aliases and nonreferential/rhetorical addressees.

## 6. OBJECT — source-treated independent referent

OBJECT is a source-treated concrete or abstract thing with independent selectable identity.

Retain when represented as independently trackable:

- physical things and materially distinguished parts;
- products/documents/services/results;
- amounts/values;
- choices, decisions, plans, and next steps treated as things;
- stable recurring relations/practices and relationships treated as objects of concern;
- represented sets/categories;
- comparison vehicles;
- explicitly reified mental/content objects.

Do not create OBJECT merely by nominalizing an unreified event, proposition, clause, intention, question, or relation. Do not duplicate a PLACE whose only job is location or a LABEL whose only job is characterization. A noun phrase is not automatically an OBJECT.

## 7. LABEL — independently reusable characterization

LABEL is a separately staged source characterization, value, state, classification, evaluation, comparison, identity, manner, status, correction/rejection, or explicitly questioned candidate value.

Use the shortest complete exact source span that preserves the characterization's posture. Preserve negation, uncertainty, question form, contrast, rejection, correction, and intensity when needed to prevent reversal or loss of the source-staged distinction.

Do not merge successive source-staged postures merely because they concern one topic. Do not suppress a LABEL merely because the same wording also participates in a VERB, OBJECT, LOCATOR, compound, or quality when the characterization itself is independently reusable.

`qualities_available` is a separate boolean and never substitutes for a materially distinct LABEL.

## 8. VERB — lexical predicate increments

VERB inventories materially represented lexical predicate increments in source order.

Use the smallest complete lexical predicate construction that preserves a distinct happening, state, stance, cognition, report, or relation and its source posture.

- Split matrix and embedded predicates when each contributes a different independently selectable predicate relation.
- Split coordinated or sequential predicates when they perform different jobs.
- Preserve particles, reflexives, negation, modal posture, and required complements when they are necessary to the predicate identity.
- Keep a semantically bound multiword predicate together when its pieces do not independently perform different relation jobs.
- Retain predicates under negation, uncertainty, questions, intentions, hypotheticals, recurrence, and future language.
- Reporting/cognition predicates qualify when the act of seeing, saying, thinking, finding, asking, telling, trying, meaning, etc. is itself materially represented and independently reconnectable.
- Motion predicates and orientation may independently support both VERB and LOCATOR when the source uses the same wording for two class jobs.
- A quality copula whose only semantic content is an independently retained LABEL normally does not require a duplicate VERB.
- Suppress pure auxiliaries, do-support, and grammar-only fragments.

Do not replace several independently useful predicate increments with one clause-sized relation merely because they belong to one proposition.

## 9. LOCATOR — independent orientation/context relation

LOCATOR is an independently useful where/which-position/which-path/which-context/orientation relation.

Retain materially useful:

- broad and contained setting relations;
- position/proximity relations;
- origin/destination constructions;
- movement and path relations;
- entry/exit;
- accompaniment/carrying when locational;
- containment;
- recurring/situational context relations;
- internal or figurative/comparative orientation when the source genuinely uses it as locating/context structure.

Use the smallest complete meaningful construction, not an isolated preposition.

Evaluate LOCATOR independently from PLACE, TIME, VERB, OBJECT, and compounds. Do not suppress a genuine locator simply because its wording is already present in a motion verb, place phrase, time frame, or compound.

Do not create LOCATOR from routine possession, recipient, topic/argument marking, or every phrase-internal preposition when no independent orientation/context job would disappear.

## 10. Literal-language lock

Every source-derived non-null `source_wording`, `source_cue`, `order_cue`, source-near tag, and researcher bundle must preserve the source's actual language where the schema requires source text.

Do not repair grammar, normalize dialect, substitute synonyms, alter numbers, expand contractions, or clean punctuation.

Only genuinely unnamed PLACE/TIME support coordinates may use `source_wording: null`, anchored by exact source text.

`researcher_note` should normally be null or minimal mechanical/coreference bookkeeping, not interpretation.

## 11. Coreference, order, qualities

Merge true aliases/coreferents even when wording changes. Do not split repeated mentions merely to inflate the inventory.

Default within-class order is first material source anchor after coreference resolution, with speaker-first PERSON and broad-before-contained setting navigation where source structure supports it.

`qualities_available` is boolean only. It marks source-present descriptive material and does not itself force or suppress a LABEL.

## 12. Compound reconstruction — proposition-level map

After units are frozen, create a compound for each materially distinct represented proposition, situation, predicate relation, characterization proposition, question, correction, comparison, reflection, or prospective relation useful for reconnection.

A compound binds already-retained coordinates. It never creates semantics or repairs a missing coordinate.

- Prefer proposition/event-level coverage over a few broad scene summaries.
- Split materially different propositions.
- Keep pieces together only when they jointly express one source-local proposition/relation.
- Use only registered unit references.
- Include only the PLACE/TIME/LOCATOR coordinates materially belonging to that local binding.
- Do not create compounds for grammar fragments, duplicate alternate tokenizations, arbitrary pairwise closure, or rejected coordinates.
- Do not create a compound merely because a primitive exists.

A source sentence may yield several compounds when it materially stages several independently useful propositions/relations.
