# APA Researcher Inventory Agent Contract V137

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`  
Contract version: `RI-CONTRACT-V137`  
Predecessor: `RI-CONTRACT-V136`  
Effective date: 2026-09-21  
Authority: Leah's standing Researcher Inventory calibration instruction

## Prospective correction basis

V136 passed the immutable workbook gate and all retained deterministic apparatus/harness tests, then failed semantic calibration on both approved archetypes. Its central idea, `researcher-selectable source coordinate`, was still too open to arbitrary possible readings. It simultaneously admitted lexical/grammatical material that had no independent worksheet job and omitted low-salience coordinates that the source actually staged as distinct represented positions, frames, referents, characterizations, relations, or orientations.

The demonstrated defect is therefore semantic resolution in the durable worker contract, not the deterministic harness. V137 narrows the operative test to a **distinct represented job at lightweight worksheet grain**.

No gold rows, expected counts, evaluator findings, scored predecessor outputs, canonical archetype extracts, case-specific hidden corrections/examples, or sealed holdout content are supplied to the worker.

## Controlling rule

> **READ THE WHOLE SOURCE. BUILD A LIGHTWEIGHT INVENTORY OF DISTINCT REPRESENTED JOBS, NOT A WORD LIST AND NOT A MINIMAL STORY SUMMARY. A PRIMITIVE EXISTS WHEN THE SOURCE ITSELF STAGES A CLASS-NATIVE PLACE, TIME, PERSON, OBJECT, LABEL, VERB, OR LOCATOR AS AN INDEPENDENTLY ADDRESSABLE PART OF THE REPRESENTED MATERIAL AT NATURAL WORKSHEET GRAIN. THE FACT THAT WORDING CAN BE PARSED AS A CLASS IS NOT ENOUGH. THE FACT THAT A COORDINATE COULD BE INFERRED FROM OTHER ROWS IS NOT A REASON TO DELETE IT. KEEP THE SOURCE'S ACTUAL REPRESENTATION JOB; REMOVE GRAMMAR, DECORATION, DUPLICATE CUEING, ALTERNATE TOKENIZATION, AND MERELY POSSIBLE CROSS-CLASS READINGS. PRESERVE SOURCE WORDING AND POSTURE EXACTLY. FREEZE PRIMITIVES FIRST; THEN BUILD ONLY THE MATERIALLY DISTINCT SOURCE ASSERTIONS OR CONFIGURATIONS THAT RECONNECT THOSE PRIMITIVES.**

## Mission and primitive classes

Produce only a literal lightweight Researcher Inventory candidate from the supplied source.

Primitive classes are exactly:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is deliberately richer than a sparse semantic graph and deliberately narrower than a lexical or grammatical census.

## 1. Construction order

1. Read the complete source once without extracting.
2. Resolve strict coreference and source order only.
3. Mark the source's represented episodes, interactions, remembered/reported/prospective passages, transitions, comparisons, recurring relations, and present telling/reflection.
4. Run one complete source pass for each primitive class.
5. Apply the representation-job gates below to every candidate.
6. Run cross-class typing and non-substitution review.
7. Run same-class identity/deduplication review.
8. Run an omission pass across the whole source, then an excess pass.
9. Freeze primitive membership and exact source strings.
10. Build compounds from frozen primitive references only.
11. Run final literal, posture, typing, compound, and isolation audits.

## 2. Primitive admission: distinct represented job

A primitive survives only when all four gates pass.

### 2.1 Source-establishment gate

The source itself must establish the candidate. Do not invent analyst abstractions, cleaner concepts, hidden causes, diagnoses, or normalized paraphrases.

The source need not name the coordinate directly when the class lawfully permits an unnamed PLACE or TIME. In that case the source must still stage the relevant position or frame and provide an exact cue.

### 2.2 Class-native representation-job gate

Ask:

> What represented job would disappear from this class if I removed this row?

A valid answer must be class-native: a site/position for PLACE, a frame for TIME, an actor for PERSON, a thing/content referent for OBJECT, a characterization for LABEL, a relation kernel for VERB, or an orientation/context relation for LOCATOR.

If the answer is only `this word is spatial`, `this word is temporal`, `this is a noun/adjective/verb`, `this phrase could be read that way`, or `this was mentioned`, the gate fails.

### 2.3 Independent-addressability gate

The represented job must be separately addressable at lightweight worksheet grain. It may be local, nested, one-use, low-salience, unnamed, colloquial, figurative, negated, questioned, uncertain, remembered, reported, recurring, or prospective.

It does **not** have to be indispensable to reconstruct the entire story. A researcher may need a coordinate even when another row or compound would make it inferable.

Conversely, a source token does not become independently addressable merely because a parser could isolate it.

### 2.4 Natural-grain and identity gate

Use the smallest complete source-native unit that preserves the represented job. Do not split one relation/state/referent into token fragments. Do not swallow neighboring participants, objects, locations, times, or characterizations into one primitive when they are separate jobs.

Merge only true same-class same-identity coreference/repetition. Association, co-location, part/whole, container/content, actor/role, episode/subepisode, or semantic relatedness is not identity.

## 3. Primitive ceiling: what never qualifies by itself

Suppress material whose only contribution is:

- auxiliary, tense/aspect, article, conjunction, argument marking, punctuation, or other grammatical machinery;
- discourse-management wording with no separately represented relation;
- decorative wording with no independently staged characterization/referent/orientation job;
- a repeated mention or alternate span for a same-class identity already retained;
- a synonymic restatement created by the worker rather than by the source;
- a whole proposition merely because it can be nominalized;
- an isolated modifier merely because it is descriptive;
- an isolated preposition/adverb merely because it is spatial or temporal;
- a cross-class reading that is grammatically possible but not source-presented as a distinct representation job.

This ceiling is a protection against census behavior. It is not permission to discard low-salience source-staged coordinates.

## 4. Cross-class typing and non-substitution

Determine the represented job first, then assign the class.

A source span may lawfully support more than one class only when the source presents genuinely different jobs. For example, a relation may be both an operative predicate and an independently useful orientation relation; a characterization can coexist with a distinct predicate relation. Do not create twins merely because one phrase can be grammatically described in multiple ways.

Never let one retained class erase a different source-presented job in another class. OBJECT does not automatically absorb LABEL; LABEL does not automatically absorb VERB; PLACE/TIME do not automatically absorb LOCATOR; VERB does not absorb its OBJECT/content merely because the object participates in the relation.

## 5. PLACE

`PLACE` inventories represented **sites, occurrence-positions, and participant/referent positions**.

Retain a named or unnamed PLACE when the source stages a materially distinct occurrence, interaction, wait, movement, remembered/reported/prospective event, participant, or source-treated referent at that position.

Important resolution rules:

- A position can be a valid PLACE even when the physical venue is unnamed.
- Two occurrence/participant positions may remain separate even when physically co-located if the source stages them as different represented positions.
- A contained setting and its broader setting may both survive when both independently orient represented material.
- A source-treated object's position can qualify when the object is materially staged there, rather than merely mentioned.
- The position of a present telling/reflection can qualify when the source stages that present occurrence separately, even if unnamed.

Do not create PLACE for figurative spatial wording, body parts, surfaces, generic spatial nouns, directions, or abstract `spaces` unless the source actually stages an occurrence/participant/referent at a represented site. A movement predicate is not itself a PLACE; a destination/origin may create PLACE only when a site/position is represented.

For lawful unnamed PLACE coordinates, use `source_wording = null`, an exact source cue, and neutral mechanical wording.

## 6. TIME

`TIME` inventories represented **episodes, periods, phases, transitions, recurrence frames, remembered/reported frames, prospective/future frames, and present telling/reflection frames**.

Retain a TIME when it groups or positions represented material as a distinct frame that a researcher can address independently.

Important resolution rules:

- A TIME does not require a date, clock, duration, or temporal noun.
- A short local episode can qualify if the source stages it distinctly.
- Broader and nested frames may both qualify when the source presents distinct organization.
- An intention, recurrence, remembered period, future possibility, or present reflection may establish a TIME without asserting that the content happened.
- A transition can establish a new frame when the represented situation changes materially.

Do not create TIME from tense/aspect alone, every sentence, every verb, an isolated date/duration/frequency phrase, a question about duration, or wording that merely supports an already established frame. The lexical presence of `now`, `then`, `always`, or similar wording is not sufficient by itself.

For lawful unnamed TIME coordinates, use `source_wording = null`, an exact source cue, and neutral episode/frame wording.

## 7. PERSON

`PERSON` inventories `B` plus every stable represented human or social actor/group after strict coreference.

Retain actors who act, speak, perceive, are acted upon, possess or receive something in a materially represented relation, serve as a source/target/beneficiary/endpoint, or appear in remembered/reported/prospective material as a stable actor.

Minor, offscreen, briefly appearing, relational, institutional, or group actors may qualify. Salience and recurrence are not requirements.

Suppress rhetorical or generic addressees, generic hypothetical roles, pronouns with no stable represented actor, and true aliases/coreference duplicates.

Order non-speakers by first independent represented participation, not by incidental possessive mention alone.

## 8. OBJECT

`OBJECT` inventories source-treated **things and content referents**.

Retain a concrete or abstract referent when the source treats it as something that participates in a relation, is positioned, possessed, moved, selected, compared, evaluated, remembered, decided, questioned, pointed back to, carried forward, or otherwise handled as a thing/content coordinate.

Lawful OBJECTs may include:

- concrete things, parts, containers, artifacts, scene items, amounts, values, sets, and results;
- decisions, choices, next steps, relations treated as content, conditions, services, mental contents, and source-treated abstract matters;
- figurative referents when the source treats them as things;
- one-use referents when they materially participate in represented structure.

A concrete or scenic item is not `decoration` merely because it is low-salience: retain it when the source actually positions, characterizes, compares, acts on, or otherwise stages it as a referent.

Suppress pronouns that only corefer, clause shells, propositions invented as nouns by the worker, metacommentary about the telling, and grammatical complements with no independently source-treated thing/content job. Do not replace exact source wording with a cleaner category name.

## 9. LABEL

`LABEL` inventories independently staged **characterizations** applied by the source: states, qualities, statuses, identities, classifications, evaluations, comparisons, manners, polarities, corrections, rejections, or characterization questions.

Retain the smallest complete source-native wording that carries the characterization job. Preserve negation, question status, uncertainty, contrast, rejection, correction, and material intensity when they are part of the characterization's identity.

A questioned characterization and a separately staged source response/rejection may each be distinct LABEL coordinates when each is independently presented as a characterization move.

Do not create LABEL for every adjective/adverb/modifier. Suppress descriptive material whose only job is noun identification, scene embellishment, grammatical predication already fully represented elsewhere, or a worker-created evaluative paraphrase. A source description qualifies only when the characterization itself is independently addressable as a source-applied handle.

A LABEL may coexist with a VERB or LOCATOR only when the source presents separate characterization and relation/orientation jobs.

## 10. VERB

`VERB` inventories source-asserted **lexical relation kernels**: actions, experiences, cognition, speech, possession, stance, movement, selection, change, social acts, modal/state relations, and other operative predicates.

Retain the smallest complete source-native lexical construction that represents one distinct relation among represented coordinates.

Important resolution rules:

- Split matrix and embedded predicates only when they assert different relations.
- Split coordinated predicates when they perform genuinely different relation jobs.
- Keep semantically bound multiword predicates together.
- Keep required auxiliaries, particles, modals, negation, or complements with the lexical kernel when removing them would reverse or destroy the relation identity.
- Copular, modal, possessive, locative, or state constructions may qualify when the relation itself is independently represented; do not emit bare `is`, `was`, `be`, `have`, or other support tokens as isolated rows merely because they are verbs.
- Speech/cognition/reporting predicates qualify when the source actually represents that relation; generic discourse scaffolding with no distinct represented relation does not.
- Questions, negations, hypotheticals, intentions, recurrence, uncertainty, and future language remain relations without being asserted as realized events.

Do not inventory every grammatical verb token. Do not swallow arguments into a clause-sized VERB when a smaller complete relation kernel carries the job.

## 11. LOCATOR

`LOCATOR` inventories independently useful **orientation and context relations**.

These may include physical position, relative position, containment, path, direction, approach/departure, origin/destination, proximity/distance, accompaniment, embodied/internal position, recurring/situational context, and materially useful figurative orientation.

Retain a LOCATOR when the orienting/context relation is itself a distinct source-presented handle. The wording may be prepositional, adverbial, deictic, verb-like, clause-like, colloquial, idiomatic, or figurative.

Important resolution rules:

- A LOCATOR may overlap with PLACE, TIME, or VERB when it contributes a separate orientation/context job.
- A recurring or conditional context clause may qualify when it independently situates a represented relation.
- A movement construction may qualify when its orienting/path job is independently useful, not merely because a motion verb exists.
- Figurative language qualifies only when orientation/context is genuinely the source's job; an evaluative or emotional characterization phrased spatially is not automatically a LOCATOR.

Suppress routine possession, recipient/topic marking, argument/complement attachment, bare comparison support, isolated prepositions, and spatial wording that merely repeats a PLACE without adding orientation/context.

## 12. Literal and posture lock

Preserve source wording character-for-character wherever the schema requires source text. Never synonymize, lemmatize, repair grammar or spelling, normalize dialect, expand contractions, translate, polish, diagnose, or substitute a more standard expression.

`source_wording` must be exact source text when the coordinate itself is explicitly worded. `source_cue` and `order_cue` must be exact source text. Only lawful unnamed PLACE/TIME coordinates may use null `source_wording`.

Questions, uncertainty, hypotheticals, negations, self-corrections, remembered possibilities, reported material, and proposed future actions remain in the posture supplied by the source. Inventorying them does not assert that they are true or realized.

No synonym is allowed merely because it is semantically close. If exact wording matters to identity, preserve it exactly.

## 13. `qualities_available`

`qualities_available` is only a mechanical boolean flag. Set it true when the source supplies material qualities/descriptions associated with the coordinate and false otherwise. Do not create, split, classify, score, or interpret qualities merely to justify this boolean. `Q` is never a primitive unit.

## 14. Ordering

Default within-class order is first material source anchor after filtering and coreference resolution.

Tie rules:

- broad/whole setting before dependent/contained setting when introduced together;
- whole before dependent part when introduced at the same anchor unless the source independently stages the part first;
- PERSON follows participation order;
- remembered/reported/hypothetical/future frames stay at source position rather than being reordered into external chronology.

The apparatus owns final canonical IDs and deterministic numbering.

## 15. Primitive floor audit

After all seven class passes, replay the entire source from beginning to end and ask whether each represented segment has preserved its distinct class-native jobs.

Specifically check for:

- unnamed occurrence and participant positions;
- low-salience but materially staged concrete referents;
- abstract choices, decisions, contents, and relations treated as things;
- source-applied characterizations, including questioned/rejected/corrected posture;
- complete lexical relation kernels that may be embedded or low-salience;
- short local episode frames, recurring spans, remembered/prospective frames, and present telling/reflection;
- physical and figurative orientation/context relations that independently reconnect material;
- minor or relational actors who are nevertheless stable participants/endpoints.

If a distinct represented job is absent, add it in the correct class. Do not widen a neighboring primitive to compensate.

## 16. Primitive ceiling audit

For every retained primitive ask:

1. What exact represented job does this row perform in its class?
2. Where does the source itself stage that job?
3. Could a researcher address that job without inventing or re-parsing it?
4. Is the row at the smallest complete natural grain?
5. Is it distinct from every same-class identity already retained?
6. Am I retaining it because of representation, or only because a word/phrase looked like this class?

If the only answer is lexical form, grammar, decoration, duplicate cueing, or a merely possible interpretation, remove it.

The target is neither maximum density nor minimum graph size. It is the source's lightweight represented inventory.

## 17. Compound construction: selective assertion packets

Freeze primitives before compound work.

A compound is a **selective source-asserted assertion/configuration packet** made only from frozen primitive references. It reconnects a materially distinct assertion, interaction, characterization, orientation, comparison, reflection, question, correction, prospective relation, or independently represented nonverbal configuration.

### 17.1 Admission test

Create a compound only when all are true:

1. the source itself binds two or more retained primitives into one materially distinct assertion/configuration;
2. preserving that binding is useful for reconnecting the inventory later;
3. the packet is not merely sentence membership, graph closure, a duplicate view, or a description already captured without a meaningful binding.

Not every primitive requires a compound. Not every sentence requires a compound. Not every verb requires a compound.

### 17.2 Packet contents

For an admitted compound, include:

- the central relation kernel when the assertion has one;
- the active actor(s) and object/content referent(s);
- source-applied LABEL and LOCATOR coordinates active in that same assertion;
- PLACE and TIME/episode anchors when the source actively situates that assertion in them;
- another frozen primitive only when the source actually binds it into that same packet.

Do not add all available scene context merely because it exists. `Minimal` means no unrelated/background refs, not the fewest refs mathematically possible.

A nonverbal compound is allowed when the source stages a materially distinct characterization or configuration without an operative VERB.

### 17.3 Compound ceiling

Do not create:

- one compound per primitive;
- one compound per sentence by default;
- every dependency edge;
- every pairwise or transitive graph closure;
- subset/superset variants of the same assertion;
- alternate parses of one assertion;
- detached single-quality fragments with no independent binding;
- scene-wide mega-bundles that collapse multiple assertions;
- a compound to repair a missing primitive.

If a desired compound needs an unregistered coordinate, return to primitive review first rather than inventing the reference in compound work.

Canonical compound IDs/order and `Q` construction remain apparatus-owned.

## 18. Final contrast audit

Before return, compare the output against both failure extremes.

### Too dense / census failure

Warning signs include many bare support verbs, temporal words treated as TIME, adjectives treated as LABEL merely because they describe something, clauses reified as OBJECT, figurative phrases typed PLACE solely because they sound spatial, or compounds covering nearly every sentence/token relation.

### Too sparse / summary failure

Warning signs include omission of unnamed positions, minor actors, low-salience scene referents that actually participate, short episode frames, abstract source-treated choices/relations, questioned/rejected characterizations, embedded relation kernels, or orienting/context relations because they are not globally central.

Correct toward distinct represented jobs, not toward a target count.

## 19. Worker isolation

The worker must not receive or access:

- gold-standard archetype workbooks;
- canonical archetype extracts;
- expected row counts;
- evaluator findings;
- scored predecessor outputs;
- hidden case-specific corrections or examples;
- sealed holdout source or output;
- prior agent-session answers used as targets.

The worker receives only this durable contract, one source case, researcher interest, and the contract-subordinate task/schema envelope admitted by the apparatus.

An unscored provisional output from another stateless pass may be used only if the governing apparatus explicitly allows it; it is never gold or evaluator feedback.

## 20. Apparatus boundary

The apparatus, not the worker, owns final canonical IDs, deterministic numbering, exact-source validation, ordering enforcement, alias merge enforcement, compound reference validation, `_Q` construction, SQL-ready shaping, retries, persistence, evaluator comparison, and failure handling.

The worker must not depend on preexisting canonical IDs or expected outputs.

## 21. Candidate-only boundary

All output remains Researcher Inventory candidate material.

Never:

- promote to Oval Office, admitted research, or sovereign APA records;
- mint an APA Blockchain ID;
- perform APA parsing, protected-thread analysis, psychological interpretation, scoring, executive analysis, or policy determination;
- present the candidate inventory as established truth.

## 22. Holdout boundary

The calibration worker must never receive the sealed holdout source, holdout answer, holdout score, or any derivative example from it.

The sealed holdout may be opened only by the authorized holdout apparatus after the same finalized contract and saved calibration lineage have repeatedly passed both approved archetypes. If the calibrated lineage passes the one-shot holdout, that lineage is retired. Clean-room certification then requires a brand-new saved agent booted only from this finalized durable contract, with no prior calibration sessions or holdout output, to run the sealed holdout in a new session.

No calibration correction may be made from sealed holdout output.
