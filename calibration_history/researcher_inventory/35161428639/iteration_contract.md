# APA Researcher Inventory Agent Contract V61

Status: ACTIVE SUCCESSOR FOR CALIBRATION
Contract version: `RI-CONTRACT-V61`
Predecessor: `RI-CONTRACT-V60`
Effective date: 2026-09-16
Authority: Leah's standing Researcher Inventory calibration instruction. This successor is justified only by preserved paired-archetype V60 failure demonstrating a generalizable durable-instruction defect.

## Mission

Produce only a literal lightweight Researcher Inventory candidate from the supplied source. Inventory the source at the approved lightweight research-coordinate grain, preserve the source's own lexical/posture distinctions, then reconstruct materially distinct compounds from the frozen primitive inventory.

Do not interpret psychological meaning, score APA, infer protected threads, draw conclusions, promote records, mint APA IDs, or admit anything to sovereign/production fabric.

The worker never receives approved archetypes, expected counts, gold rows, evaluator findings, prior scored outputs, sealed holdout source during calibration, or holdout outputs.

## 1. Governing method: exhaustive source pass, then independent class projections

Read the complete source before extracting any class. Resolve speaker, represented actors, aliases/coreference, scene changes, temporal changes, quoted/reported material, questions, negation, uncertainty, correction, comparison, figurative material, and prospective/recurring material.

Build an internal source-role ledger in source order. The ledger is broader than a proposition graph: it must notice represented actors, stable things/content, source-present characterizations/states, lexical relations, physical occurrence positions, temporal/narrative frames, and orientation relations whether central or low-salience.

Then project that complete source independently into each requested primitive class.

**V61 controlling correction:** a represented source role does NOT have to choose one exclusive semantic home before class extraction. The same exact source span or closely overlapping span may legitimately survive in more than one primitive class when it independently passes each class's positive class-native test. Cross-class overlap is not an error merely because the semantic content overlaps. Shared wording alone is still insufficient: each retained instance must do the native job of its own class.

This supersedes V60's single-primary-home rule and its requirement that cross-class reuse prove a second different semantic role.

## 2. Primitive admission test

For each requested class, admit a candidate when all applicable conditions hold:

1. **SOURCE SUPPORT:** the source directly supplies the wording/role, or for permitted unnamed PLACE/TIME the source supplies the physical/temporal occurrence that the neutral coordinate represents.
2. **CLASS-NATIVE FUNCTION:** the candidate positively performs this class's function as defined below.
3. **RESEARCH REVISITABILITY:** a researcher can return to the coordinate as the same represented actor, referent/content, characterization/state, lexical relation, occurrence position, frame, or orientation relation.
4. **DISTINCTION:** merging it with another coordinate of the same class would erase a source-present distinction at lightweight grain.
5. **LITERAL GRAIN:** use the shortest complete source-native wording that preserves identity, polarity, modality, uncertainty, question, correction, comparison, direction, or fixed expression.
6. **NO ANALYST WRAPPER:** do not invent proposition labels, paraphrase containers, broad summary scenes/periods, or normalized synonyms merely to make the structure tidy.
7. **NO SAME-CLASS DUPLICATION:** aliases/coreference and alternate phrasings of the same coordinate within one class collapse unless the source establishes distinct occurrences/roles.

Do not require narrative importance, emotional salience, recurrence, compound membership, or proposition centrality.

## 3. Exhaustiveness without indiscriminate census

Coverage is asymmetric by class. Do not use one universal sparsity rule.

- PERSON, PLACE and TIME require complete represented actor/scene/frame coverage, including low-salience or unnamed/offscreen coordinates when source-supported.
- OBJECT requires complete stable-referent/content coverage, including background concrete things and source-reified abstract contents.
- LABEL requires complete source-present characterization/state/classification coverage at phrase grain.
- VERB requires complete material lexical-relation coverage, including embedded/reporting/cognitive/modal/state/movement relations when they independently express a represented relation.
- LOCATOR requires complete material orientation coverage, including source-native position/path/direction/containment/recurrence/internal-orientation expressions.

Do not turn every token into a unit. Function words, pure auxiliaries, discourse fillers, pronoun wrappers, bare conjunctions, and merely grammatical fragments are not coordinates.

## 4. PLACE — represented physical occurrence positions

PLACE answers where a represented actor, interaction, occurrence, or independently represented object is physically situated.

Retain:

- named physical settings;
- contained physical positions when the source distinguishes them;
- minimal neutral unnamed/offscreen places when an interaction/actor is physically situated but the exact place name is omitted;
- the physical setting of a later reported/remembered interaction when source structure distinguishes it;
- the present-telling physical position when the narrative contains a distinct present-telling frame and the source necessarily situates the current speaker somewhere, using a neutral unnamed tag if no location is named.

Scene completion is deliberately generous: if two represented interactions occur in distinct physical situations, preserve their PLACE distinction even if one place is unnamed.

Do not make every physical noun or surface a PLACE merely because it is concrete. A thing can be OBJECT while its position can separately support PLACE/LOCATOR.

`source_wording` may be null only for a genuinely source-supported unnamed PLACE; `source_cue` must remain exact source text.

## 5. TIME — represented episodes/periods/frames

TIME answers when/within what episode or period represented relations occur.

Retain each source-distinguished:

- attempt/episode;
- waiting or transition episode;
- remembered/reported episode;
- broad period when the source uses it as a frame for relations;
- recurring span;
- present-reflection or present-telling frame;
- prospective/future frame implied by an explicitly prospective relation;
- nested period when it organizes relations separately from a broader parent period.

A source frame need not have an explicit date or time noun. A neutral TIME tag may be used when the occurrence itself establishes the frame.

Do not create TIME from every predicate or tense marker. The test is whether the source distinguishes a revisit-able episode/period/frame.

## 6. PERSON — represented social actors/groups

Retain the speaker (`B`) and every source-distinguished represented human/social actor or stable social group, including indirect, possessive, relational, offscreen, remembered, reported, quoted, or prospective actors when they participate as represented actors.

Resolve coreference before deduplication. Do not treat a classification word as PERSON unless it actually denotes a represented actor/group.

## 7. OBJECT — stable represented things and source-reified content

OBJECT covers concrete and abstract referents the source treats as stable things/content.

Retain:

- concrete things that participate in source relations, including background details if independently referred to;
- body/internal referents when source-treated as things;
- choices, decisions, relations, categories/sets, amounts, results, services, topics, and other abstract content when the source reifies/revisits them as referents;
- figurative objects when they are source-present represented objects;
- named institutions/brands/products when used as thing-like referents.

Do not require an OBJECT to be central. Do not exclude it merely because another class also represents a relation/state involving it.

Reject pure pronouns/deictics, analyst-created nominalizations, and clause/proposition wrappers that the source itself does not treat as a referent.

## 8. LABEL — source-present characterization/state/classification

LABEL covers source-present words or phrases that characterize/classify a represented role or state.

Retain complete source-native characterizations including:

- descriptive qualities and manner states when the source presents them as meaningful attributes of a represented role;
- condition/state phrases;
- evaluations/comparisons;
- self/social classifications;
- questioned candidate labels;
- explicit rejection/correction labels;
- polarity/status statements;
- source-native figurative/comparative characterizations.

A LABEL may share wording with a VERB or LOCATOR when the same source span independently acts as a characterization and as a relation/orientation. Do not suppress one merely to enforce exclusivity.

Use the smallest phrase that preserves the source's actual characterization. Preserve question marks, negation, uncertainty, intensification and comparison when intrinsic.

Reject bare grammatical material and adjectives/adverbs that have no meaningful represented characterization role.

## 9. VERB — material source-present lexical relations

VERB covers material lexical relation atoms, not just dramatic actions.

Retain source-native relation phrases for represented:

- location/existence relations;
- action/movement;
- perception;
- possession;
- cognition/remembering/thinking/finding;
- speaking/reporting/asking/explaining;
- helping/causing/attempting;
- waiting/standing/sitting;
- state/change relations;
- modal/normative/prospective relations;
- comparisons/attributions when expressed relationally;
- embedded or matrix relations when each supplies a distinct source-present relation.

Do not suppress a material predicate merely because a LABEL or LOCATOR also captures part of the same wording. Classify VERB by whether the wording itself expresses a relation among represented roles.

Preserve required particles, fixed complements, negation/modality, reflexives and serial material when needed for relation identity. Split coordinated/serial predicates when the source presents distinguishable relation atoms; keep them together when splitting would destroy the source-native relation.

Exclude pure auxiliaries and discourse/floor-management predicates that add no represented relation.

## 10. LOCATOR — source-native orientation relations

LOCATOR covers material orientation, not merely prepositions.

Retain source-native expressions that materially position a role/binding in terms of:

- physical position;
- path/direction/origin/destination;
- entry/exit;
- containment/support/surface;
- accompaniment/carrying;
- proximity/distance;
- standing/stuck/movement orientation;
- recurring/temporal context when phrased as an orientation relation;
- figurative/internal orientation.

A LOCATOR may overlap PLACE, TIME, LABEL or VERB if the same wording independently functions as an orientation relation. Do not force an exclusive home.

Use the smallest complete source-native orientation phrase. Do not reduce a complete movement/destination/position expression to a bare preposition when the lexical material is necessary to preserve orientation identity.

Reject recipient/topic/content arguments and expressions with no orientation function.

## 11. Cross-class audit

After all primitive classes are extracted, compare classes using these rules:

1. Overlap is allowed and sometimes required.
2. Remove overlap only when one class instance has no positive native function of its own and exists merely because the words were available.
3. Never remove a valid class-native coordinate solely to reduce duplication.
4. Never move a unit from one class to another as a substitute for independently checking both classes.
5. Same-class aliases/duplicate grains still collapse.

This cross-class rule controls over any predecessor instruction requiring one exclusive primary home.

## 12. Literal/lexical preservation lock

Every non-null `source_wording`, every `source_cue`, and every non-null `order_cue` must be a character-for-character contiguous source substring.

Preserve spelling, punctuation, dialect, contractions, number, questions, negation, uncertainty, correction, comparison, attribution, intention, hypothetical/recurrence/report/prospective posture.

Never substitute a synonym, standardize dialect, repair grammar, singularize/pluralize, or use cleaner vocabulary as inventory content.

Researcher tags should use source wording when a named coordinate exists. Neutral tags are permitted only for supported unnamed PLACE/TIME navigation.

## 13. Ordering and qualities

Order by first source establishment after coreference, with speaker first in PERSON. `qualities_available` is boolean and is true only when the source supplies one or more qualities/descriptions for that coordinate; question/negation/intensity alone does not automatically make it true.

## 14. Compound reconstruction after primitive freeze

Freeze the complete primitive inventory first. Then reread the source and emit one smallest complete compound for each materially distinct represented binding.

For each binding include all and only frozen coordinates materially co-bound in that source occurrence, as applicable:

- participant(s);
- material VERB relation(s);
- acted-on/referred OBJECT content;
- source-present LABEL state/classification;
- TIME frame;
- PLACE scene/position;
- retained LOCATOR orientation.

A compound is not a clause census. Do not create pairwise/combinatorial closure, redundant subsets, or broad supersets merely because coordinates coexist nearby.

However, do not omit a frozen class-native coordinate that is materially part of the binding merely because another overlapping coordinate conveys related semantics. Overlapping classes may legitimately coexist in one compound.

Distinct matrix/reporting and embedded/content relations may form separate compounds when the source represents separate bindings.

Before finalizing compounds verify:

- every referenced unit exists;
- the relation's represented participants/content/state/frame/orientation are complete;
- no neighboring unrelated unit was added;
- no duplicate semantic compound is emitted through alternate decomposition;
- researcher bundle remains lexically faithful to the source.

## 15. Calibration isolation and holdout boundary

A holdout can run only after the controlling apparatus proves repeated Case 2 and Case 6 archetype passes under the exact same finalized contract. Holdout execution and clean-room certification are external apparatus responsibilities, not worker authority.
