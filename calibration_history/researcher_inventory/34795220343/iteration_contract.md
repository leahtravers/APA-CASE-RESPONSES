## Successor effect

V19 remains preserved as historical calibration evidence. V20 supersedes V19 for forward calibration behavior because the V19 run preserved at `calibration_history/researcher_inventory/34787385058/` showed a generalizable failure mode: the worker treated a broad represented-situation spine as a reason to create class rows. That produced many grammatically possible or contextually related coordinates that did not perform an independent positive inventory job.

V20 restores a simpler rule:

> **A row exists only because it performs one positive job for its own class. Do less. Do not create a row just because a phrase can be described, qualified, nominalized, temporally framed, spatially imagined, or grammatically separated.**

Retained unchanged:

- exactly seven inventory classes;
- literal/source-near lexical preservation and no synonym substitution;
- full-source reading before any class return;
- approved archetype, evaluator, scored-output, and sealed-holdout isolation;
- candidate-only status;
- mechanical apparatus ownership of canonical IDs, deterministic validation, retries, and SQL shaping;
- no APA parsing, scoring, promotion, APA-ID creation, or Oval Office research writing.

## Isolation

The worker never receives approved archetypes, gold outputs, expected answers, expected counts, evaluator findings, prior scored outputs, sealed holdout source, or holdout outputs.

The worker receives only this durable contract, one bounded source story, neutral task rules/schema, and, when explicitly supplied by the apparatus, an unscored provisional output from another stateless pass under this same contract.

Never infer or reconstruct a hidden expected answer.

## Job

Read the whole source. Build a lightweight Researcher Inventory in exactly seven classes:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

Then build lightweight compounds from the retained units.

This is an index of researcher-selectable coordinates, not a token inventory, grammar parse, summary, psychological analysis, or exhaustive ontology.

## Positive-job gate

For every proposed row, state its class job silently in plain language.

Keep it only when all four are true:

1. the source materially represents the coordinate or the coordinate is necessary to index a materially represented occurrence/relation;
2. the row performs the positive job of this class;
3. the same class job is not already carried by another retained row after alias/coreference resolution;
4. removing it would make a researcher lose a materially useful coordinate of this class.

If the only reason to keep a row is that grammar permits the phrase, another class already carries the meaning, or a broad situation could be described from that angle, omit it.

When uncertain between adding and omitting a marginal row, omit it unless its positive class job is clear. This is lightweight inventory.

The same source span may support more than one class only when each class has its own independent positive job.

## Source language

Never substitute a synonym for source language.

For an explicit coordinate:

- `source_wording` is a character-for-character contiguous substring of the source;
- `source_cue` is a character-for-character contiguous substring of the source;
- preserve punctuation, apostrophes, hyphens, capitalization, spelling, and dialect;
- copy from the source rather than reconstructing from memory;
- keep `researcher_short_tag` compact and source-near.

For a materially required unnamed PLACE or TIME only, `source_wording = null` is permitted. Its `source_cue` must still be an exact source substring and the short tag must neutrally describe the class job without inventing a named location or date.

`researcher_note` is normally null. Use it only for neutral coreference, an unnamed PLACE/TIME explanation, or required mechanical bookkeeping.

Preserve negation, questions, uncertainty, correction, comparison, recurrence, intention, hypothetical posture, reported speech, and futurity. Do not convert represented possibility into asserted occurrence.

## PLACE — where job

PLACE answers only: **where is a materially represented actual occurrence, person, object, or destination situated?**

Keep:

- explicit settings and contained settings when each materially locates something;
- explicit object/person positions;
- actual origins or destinations;
- an unnamed occurrence-position when an occurrence actually happens but its place is not named and a separate where-coordinate is useful;
- the actual present telling/reporting occurrence when it is materially distinct from the earlier reported events.

An unnamed place is allowed. A named physical place is not required.

Do not create PLACE merely for:

- a hypothetical or contemplated action that does not occur;
- a generic recurring frame with no separately represented occurrence-position;
- a metaphorical mental container whose job is not actual where-location;
- a direction/path word already doing only LOCATOR work;
- every predicate inside one scene.

Physical overlap does not force two actual occurrence-positions to merge, but separate predicates do not automatically create separate places.

## TIME — when/frame job

TIME answers: **what materially represented episode, span, transition, recurrence, reflection period, intended period, or prospective frame lets a researcher locate content in time?**

No clock or date is required.

Keep a distinct frame when the source materially establishes it as an episode/span/frame in its own right. This can include actual episodes, later reported episodes, standing or recurring spans, present reflection, intended periods, and prospective/future frames.

Do not create TIME simply because a clause has a verb, tense, duration phrase, question, hypothetical action, or embedded predicate. Several predicates may belong to one TIME. A hypothetical action gets its own TIME only when the source also establishes a materially distinct temporal frame for it.

## PERSON — human actor job

PERSON is a materially represented human or stable social group.

Keep the speaker and people/groups who act, speak, perceive, are acted upon, or are material human endpoints/owners/beneficiaries of retained relations or objects.

Resolve pronouns, aliases, kinship expressions, and stable groups before counting. Do not create PERSON from a generic audience, grammatical person, or hypothetical role with no distinct represented human actor.

## OBJECT — selectable referent job

OBJECT is an independently selectable represented referent.

It may be concrete or abstract, including a thing, source-distinguished whole/part, value, set/category, choice/decision, relation treated as a thing, internal object, or figurative object.

Keep it when a researcher can select and reconnect that referent independently across the story.

Do not create OBJECT for every noun phrase, complement clause, proposition, pronoun, metadiscourse wrapper, or phrase that merely can be nominalized. Do not duplicate a more specific retained referent with an abstract wrapper.

A choice or relation may be an OBJECT even without a neat noun phrase when the source materially treats that choice/relation as something being considered, discussed, maintained, or acted on.

## LABEL — quality job

LABEL is the **characterization itself**, not the whole clause that carries it.

Keep a source-applied quality, state, identity term, comparison, evaluation, correction/rejection, or other characterization when it materially describes a retained coordinate or represented situation.

Use the shortest complete source phrase that carries the characterization. Remove subject, question scaffolding, reporting scaffolding, and copular/support wording when those words do not belong to the characterization itself.

A question can contain a LABEL, but the question is not itself the LABEL. A copular clause can contain a LABEL, but the copula is not automatically part of the LABEL.

Do not create LABEL merely because wording is descriptive in a loose sense. The phrase must actually perform the quality/characterization job.

## VERB — relation/action job

VERB is the shortest complete lexical predicate relation needed to reconnect materially represented content.

Keep one row for each materially distinct action/relation. Preserve a particle or bound complement when it is part of that lexical relation.

Do not split one relation into auxiliary, support, control, negation, infinitive, or coordination fragments. Do not emit a second VERB whose only job is to carry a LABEL state.

A bare copula/support verb plus a characterization normally belongs to LABEL rather than becoming a separate VERB. A locative copular relation can still be a VERB when the relation itself is doing real location/relation work. Reporting/thinking/perception verbs remain VERBs when they carry a material relation.

Keep coordinated words together when they form one represented action. Split only when separate action/relation jobs would otherwise be lost.

## LOCATOR — locating relation job

LOCATOR is the source phrase that performs a locating/context relation: setting, position, path, direction, origin/destination, containment, movement, proximity, accompaniment, recurring context, or genuine mental/figurative location/path.

Keep it when the phrase independently tells how/where a retained coordinate or situation is positioned, moves, recurs, or is contained.

Do not create LOCATOR from isolated prepositions, routine possession/recipient/topic marking, a purely temporal phrase, or a characterization/state whose primary job is LABEL. Spatial-looking metaphor does not become LOCATOR when it is functioning only as a quality/state.

## qualities_available

`qualities_available` is a boolean only.

Set it true when material qualifying/descriptive language is associated with the coordinate in the source. Otherwise false.

Do not enumerate qualities. `Q` is not a unit reference and never creates a row by itself.

## Ordering

The apparatus owns final IDs and numbering.

Within each class, order by the earliest material source anchor of the resolved semantic coordinate after alias/coreference resolution.

When later wording refers back to an already established coordinate, keep the coordinate at its earliest material anchor. Where broad and contained coordinates are introduced at the same anchor, broad precedes contained. Keep reported/hypothetical material in source-discourse order rather than reconstructing real-world chronology.

## Stateless verification

If the apparatus supplies an unscored provisional output, rebuild from the source and this contract.

Verification is symmetric:

- add a row only for a clear missing positive class job;
- remove a row that has no independent positive class job;
- resolve aliases and duplicates;
- repair source copying without changing semantics;
- do not preserve a provisional row merely because it already exists.

## Compounds

Build compounds only after units are final.

Create one compound for each materially distinct proposition/situation useful for reconnecting retained coordinates.

For each compound:

- include only retained units that materially participate in that proposition;
- use the nearest specific PLACE/TIME/LOCATOR frame only when it actually belongs to that proposition;
- do **not** propagate broad scene, place, time, or locator units into every later proposition merely because they are globally true of the story;
- keep one proposition together and split materially different propositions;
- do not make quality-only fragments, arbitrary subsets, or every possible recombination;
- preserve source/semantic order of references.

A compound cannot compensate for a missing unit and cannot invent semantics.

## Apparatus boundary

The apparatus, not the worker, owns canonical IDs, deterministic numbering, exact-source validation, source-near tag validation, ordering enforcement, compound-reference validation, `_Q` construction, SQL-ready shaping, retries, evaluation, and failure handling.

The worker must not depend on hidden canonical IDs, archetypes, evaluator criteria, or expected counts.

## Forbidden work

Do not perform APA parsing, protected-thread analysis, psychological interpretation, scoring, promotion, APA-ID creation, executive analysis, or Oval Office research writes.

Never present a candidate inventory as established truth.
