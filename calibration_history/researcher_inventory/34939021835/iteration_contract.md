## 1. Mission

Produce a lightweight, literal Researcher Inventory of the supplied source and only the requested class.

This is a **source-coordinate inventory**, not a grammatical parse, lexical census, semantic-role census, sparse summary, interpretation, or APA analysis.

The inventory has two separate layers:

1. **UNIT LAYER** — source-grounded coordinates at the approved grain of the requested class.
2. **COMPOUND LAYER** — a selective reassembly spine joining already-final units into materially distinct source-presented bindings.

A unit is not required to be narratively important, repeatedly mentioned, globally reusable, foregrounded, or exclusive to one class. A compound never substitutes for a valid unit.

## 2. V35 admission architecture — positive capture before negative pruning

V34’s global `independent reusable research identity` test was too strong. It suppressed local source coordinates that are valid at the approved class grain. V35 therefore uses this order:

### Stage A — positive class-native capture

Retain a source-grounded candidate when:

1. the source literally presents it, or a PLACE/TIME is clearly established though unnamed;
2. it positively performs THIS requested class’s source-level job;
3. it is distinguishable from a true same-class alias/coreference duplicate;
4. it is at the class-specific grain below; and
5. literal wording and source posture can be preserved.

A candidate does **not** need an additional global test of importance, salience, repeated tracking, broad reuse, or independent story-level identity.

### Stage B — negative pruning

After positive capture, remove only candidates that are:

- true same-class aliases/coreference duplicates;
- unsupported inference or paraphrase;
- bare grammatical machinery with no requested-class job;
- analyst-manufactured clause nominalizations or scene abstractions not source-established;
- accidental duplicate restatements at the same class grain; or
- outside the requested class.

Do not use the negative pass to erase a coordinate merely because it is small, local, contained inside another scene/event, overlaps another class, or appears only once.

## 3. Cross-class rule

Classes are independent research views, not mutually exclusive bins.

Do not suppress a valid THIS-class coordinate merely because related wording also supports another class. Cross-class overlap is allowed whenever the source wording genuinely performs both jobs at their respective class grains.

At the same time, do not manufacture overlap by turning any clause into an OBJECT, any event into a TIME, any noun into a PLACE, or any preposition into a LOCATOR without the positive class job.

The decision is always: **does this source increment itself perform the requested class job?**

## 4. Whole-source procedure

For each requested class:

1. Read the complete source before writing rows.
2. Make a broad positive pass for all source-presented coordinates of THIS class.
3. Preserve local, nested, peripheral, prospective, uncertain, negative, comparative, reported, recurring, and figurative coordinates when the source presents the requested-class job.
4. Resolve aliases/coreference inside the class.
5. Apply the class-specific grain rules.
6. Run a second omission pass from beginning to end.
7. Only then run the negative pruning pass for true duplicates, unsupported inference, clause reification, or grammatical debris.
8. Verify exact source spans, posture, source order, Q, and schema.
9. Build compounds after all units are final.

Never target a hidden count or infer a hidden archetype.

## 5. Literal source lock

Never substitute synonyms, normalize dialect, repair punctuation, silently expand contractions, or rewrite quotation marks.

For every returned row:

- every non-null `source_wording` must be a character-for-character contiguous substring of `source`;
- every `source_cue` must be a character-for-character contiguous substring of `source`;
- every non-null `order_cue` must be a character-for-character contiguous substring of `source`;
- use the shortest complete literal span that performs the class job without stripping required posture or relation material;
- only a supported unnamed PLACE or TIME may use `source_wording = null`.

Preserve question, negation, uncertainty, intention, hypothetical, recurrence, report, comparison, rejection/correction, dialect, colloquial wording, and prospective posture.

Short tags are navigation aids only and may not replace or normalize source wording.

## 6. PLACE — physical/scene coordinate grain

Positive job: a represented **place, scene, or physical scene-position**.

Retain:

- broad and contained physical settings when both are source-established;
- local positions within a larger setting when the source separately establishes where a person/object/event is situated;
- supported unnamed physical locations for distinct represented encounters, conversations, waits, recollections, present telling, or other scenes whose physical location is not named;
- distinct source-established destinations/origins when they function as scene coordinates.

A larger setting does not automatically absorb all local positions inside it.

Reject:

- abstract community/context descriptions that do not actually locate the represented material;
- figurative spatial wording whose job is only LABEL/LOCATOR;
- objects merely capable of serving as spatial anchors;
- duplicate aliases for the same place-position.

For unnamed PLACE use `source_wording = null` plus an exact cue.

## 7. TIME — episode/temporal-anchor grain

Positive job: a represented **when-coordinate**.

Retain separately established:

- larger episodes/periods;
- contained action phases or event episodes when the source gives them their own temporal identity;
- explicit dates, durations, recurrences, relative-time anchors, and clock/daypart anchors;
- report/recollection periods;
- intended, hypothetical, future/prospective periods;
- present reflection/telling frames;
- local temporal anchors that organize a relation even inside a larger episode.

A broad episode does not automatically absorb every source-established contained phase. Conversely, tense alone or every action does not create TIME.

For unnamed TIME use `source_wording = null` plus an exact cue.

## 8. PERSON — resolved represented actor grain

Retain the speaker and every independently represented human/social actor or stable actor group, including peripheral actors.

Resolve pronouns, aliases, kinship terms, role descriptions, possessives, and group references before same-class duplicate removal.

Do not create a second PERSON for pronoun/case variants or a role characterization that clearly refers to the same actor. Generic discourse `you` is not automatically an actor unless the source represents an addressee/person coordinate.

## 9. OBJECT — referent grain

Positive job: a represented **referable thing/content/value/choice/result/relation**.

For concrete source referents, default toward retention when the source distinguishes the referent: objects, parts, surfaces, containers, documents, equipment, amounts, physical media, bodily/mental referents, and other named things may qualify even when locally mentioned once.

For abstract material, retain it when the source itself treats it as a referable thing/content/choice/value/decision/result/relation rather than merely as an entire clause that could be nominalized by an analyst.

A source-distinguished part may coexist with its whole when both are separately represented.

Reject only true aliases, pronoun/wrapper fragments, unsupported nominalizations, and wording whose actual source job is not referential.

Do not suppress an OBJECT merely because it also participates in PLACE, LABEL, LOCATOR, or another class.

## 10. LABEL — applied characterization grain

Positive job: a source-applied **characterization**.

Retain source-applied identities, qualities, states, evaluations, comparisons, descriptions, candidate labels, rejected labels, corrections, and characterization questions/responses when the wording itself characterizes represented material.

Local predicative, adjectival, idiomatic, comparative, deictic-characterizing, or colloquial wording may qualify even when brief or mentioned once.

Use the shortest complete literal formulation carrying the characterization and its required polarity/qualification.

Reject bare intensifiers, grammatical support alone, or wording that performs only an action/referent/locator job without characterization.

## 11. VERB — lexical relation-edge grain

Positive job: a distinct source-presented **action/state/relation edge**.

V35 returns from V34’s relation-package grain to lexical relation increments, but keeps V34’s protection against meaningless grammatical splitting.

Retain each distinct lexical predicate increment that contributes its own represented action/state/relation, including matrix, embedded, reported, perception, thought, purpose, intended, questioned, negated, hypothetical, recurring, and future relations.

When a clause contains multiple lexical predicates that each contribute a distinct relation, split them into separate VERB units. A matrix predicate and an embedded predicate may both qualify. Serial or coordinated relation steps may both qualify.

Keep together only words required for one lexical relation: phrasal/idiomatic particles, necessary negation, and other material without which the relation wording is incomplete.

Do **not** create separate VERBs for bare auxiliaries, complementizers, infinitival markers, or support words with no relation of their own.

Do not absorb subjects, objects, places, times, labels, or a full complement proposition into VERB wording when the lexical relation can be represented by a smaller exact span.

Event/proposition assembly belongs in COMPOUNDS.

## 12. LOCATOR — orienting/contextual relation grain

Positive job: a source-presented **locating, orienting, positioning, movement, contextual, or materially spatialized relation**.

Retain source increments that independently situate represented material relative to:

- position, proximity, containment, surface, path, origin, destination, direction, entry/exit, or movement;
- a recurring/situational setting when the phrase actually orients the represented relation;
- participant association/accompaniment when it materially locates participants relative to one another;
- genuine figurative/mental/social orientation when the source uses spatial/positional structure as a represented relation;
- source-presented comparative orientation where the locating relation itself is material.

Use the smallest complete literal orienting construction.

Reject isolated prepositions, ordinary recipient/beneficiary/topic/possession arguments with no orienting job, and metaphors whose spatial word is merely decorative rather than a represented orientation.

Do not suppress a LOCATOR merely because the same wording also contributes TIME, VERB, LABEL, or OBJECT material.

## 13. `qualities_available`

`qualities_available` is a boolean only. Set true when the source supplies descriptive/qualifying language materially associated with the retained coordinate; otherwise false.

It never creates, suppresses, splits, or merges a unit.

## 14. Ordering

Resolve coreference before ordering.

Order coordinates by first source establishment, subject only to mechanical speaker-first PERSON and broad-before-contained PLACE/LOCATOR when established together.

Do not order by importance, ontology, emotional force, or evaluator expectation.

## 15. Compounds — selective source reassembly spine

Build compounds only after all units are final.

A compound exists to reconnect a **materially distinct source-presented binding** among two or more final coordinates. The compound layer is selective; it is not a sentence list and not a graph of every possible subset.

Create a compound when the source presents a relation/proposition/question/comparison/reflection/intention/characterization cluster whose connectivity would otherwise be lost by the unit rows alone.

For each compound:

- use only final unit refs;
- include all and only coordinates that actually participate in that binding;
- preserve source/semantic relation order;
- include frame/place/locator coordinates only when they genuinely anchor that binding;
- do not create a compound merely because a unit exists;
- do not create multiple nested subset/expanded variants of the same binding;
- do not create a compound for every sentence or every clause;
- do not build single-unit showcase compounds;
- do not use compounds to repair missing units or retain invalid units.

Prefer the smallest complete binding that preserves the material relation while avoiding redundant parallel compounds.

## 16. Final adjudication

Before returning units:

1. re-read the source from beginning to end;
2. ask whether every source-presented THIS-class coordinate has been captured, including small/local/nested ones;
3. confirm no valid row was removed merely for lack of salience, broad reuse, or exclusive semantic ownership;
4. confirm each row performs a positive requested-class job;
5. merge only true same-class aliases/coreference duplicates;
6. remove unsupported inference, analyst clause-reification, and bare grammatical machinery;
7. verify exact literal spans, posture, ordering, and `qualities_available`.

Before returning compounds:

1. units are frozen;
2. create only materially distinct connective bindings;
3. remove redundant nested/subset/showcase compounds;
4. verify every referenced unit exists and materially participates.
