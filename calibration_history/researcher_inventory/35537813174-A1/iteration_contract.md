## Mission

Produce a literal, lightweight Researcher Inventory of the complete supplied source in exactly seven primitive classes:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

Then build selective compounds only from frozen registered primitives.

The inventory is a researcher-facing coordinate system at the source's natural editorial grain. It is neither a sparse summary nor a lexical census.

## 1. Read the whole source first

Read the complete source before answering any class. Resolve obvious coreference and notice shifts in setting, period, participants, remembered/reported material, prospect, question, correction, and present reflection.

Do not emit private reasoning or a hidden scene model.

## 2. Pass A — explicit source-native coordinate inventory

First inventory only explicit coordinates that have an exact source-native nucleus.

An explicit coordinate qualifies when the source itself makes that exact unit independently researcher-selectable as one of these jobs:

- human/social participant;
- concrete or abstract thing/content handle;
- target-bearing characterization/state/status/evaluation;
- operative action/state/relation kernel;
- orientation/path/containment/direction/context relation;
- explicit spatial support;
- explicit temporal period/support.

Literal wording alone is not enough. Grammar alone is not enough. Reject narration/discourse scaffolding, generic pronouns/deictics, proposition/question shells, rhetorical color, detached intensifiers, and subordinate wording that does not have its own represented job.

Do not suppress a legitimate coordinate merely because it is local, one-use, mundane, colloquial, uncertain, negated, remembered, reported, prospective, figurative, idiomatic, or peripheral.

## 3. Exact source nucleus and editorial grain

For every explicit primitive choose the smallest complete exact source-native unit that performs the researcher-coordinate job without destroying its represented meaning.

Keep together what functions together: phrasal relations, particles, reflexives, required complements, negation, modality, comparison, idiom, and orientation constructions when splitting would change the job.

Do not inflate a primitive into a whole clause, proposition, rhetorical sentence, or question shell when a smaller exact nucleus carries the represented job.

Every non-null `source_wording`, `source_cue`, and `order_cue` must be character-for-character source text.

Never normalize, polish, translate, diagnose, euphemize, substitute synonyms, or lemmatize into a different surface form.

## 4. Pass B — unnamed support reconstruction

After explicit coordinates are identified, reconstruct unnamed `PLACE` and `TIME` support separately.

Create an unnamed support only when all of these are true:

1. the source materially differentiates a represented setting or period from another setting/period;
2. that support is needed to locate a distinct represented participant/relation/thing configuration;
3. no explicit source-native PLACE/TIME unit already supplies the support adequately;
4. an exact source cue anchors the support; and
5. the support can be described mechanically without inventing where or when.

For unnamed support use null `source_wording`, an exact source cue, and a neutral mechanical short tag.

An action, question, decision, intention, proposition, remembered content, or rhetorical span is **not** itself a TIME merely because it marks an event or discourse segment. It may imply an unnamed temporal support only when the source differentiates a period needed to situate the represented configuration.

A concrete thing, destination phrase, spatial image, or orientation phrase is **not** itself a PLACE merely because it is spatial. It may participate in or imply a support while remaining another class.

Present telling/reflection support qualifies only when the source itself establishes a current reflective frame distinct from represented past/prospective material.

## 5. Class rules

### PLACE

Return spatial supports, explicit or lawfully reconstructed unnamed supports. PLACE answers **where the represented configuration is situated**, not what physical words appear. Broad and contained supports may both qualify when the source differentiates them. Do not turn every physical noun, destination, comparison, or locator phrase into PLACE.

### TIME

Return temporal periods/supports, explicit or lawfully reconstructed unnamed supports. TIME answers **which differentiated represented period the configuration occupies**, not which clause contains an event. Explicit temporal wording may qualify when it itself functions as period/support; otherwise it may be LOCATOR/context or no primitive.

### PERSON

Return the speaker plus each distinct represented human/social actor or stable group after true coreference when the actor functions as participant, relation endpoint, possessor/beneficiary, remembered/reported actor, institutional actor, prospective actor, peripheral actor, or one-use actor. Reject rhetorical/generic/nonreferential `you` or person wording.

### OBJECT

Return concrete or abstract thing/content handles that the source treats as independently referable endpoints/nodes. This includes a source-distinguished part, amount/value, service/result, choice/decision treated as a thing, internal content/mental handle, named set/category, remembered/reported content, and figurative/quoted content when it is being referred to as content.

A physical detail qualifies when the source separately acts on, checks, locates, compares, possesses, moves, refers to, or reasons about it as its own endpoint. Reject scenic furniture merely mentioned inside a larger description, generic noun phrases, bare pronouns/deictics, proposition/question shells, and nominalized actions with no independent thing/content job.

### LABEL

Return exact target-bearing characterization/state/status/evaluation events that the source makes independently selectable. A LABEL may be one-use, uncertain, questioned, negated, corrected, rejected, comparative, colloquial, idiomatic, or figurative.

Require a represented target/state being characterized. Prefer the complete natural characterization phrase over an isolated adjective when the phrase is what the source applies. Reject decorative description, generic manner, detached intensity, and characterization wording that does not function as its own represented state/evaluation.

### VERB

Return exact operative relation kernels that independently connect/position represented coordinates or establish a material relation/state. Include the smallest complete natural predicate nucleus and preserve particles, bound complements, reflexives, negation, and modality when needed for identity.

Do not create one VERB for every lexical verb. Reject auxiliaries/support verbs, discourse/report/question shells whose represented content is carried elsewhere, duplicate restatements, whole-clause wrappers, and fragments nested inside a stronger natural relation kernel.

### LOCATOR

Return exact source-native orientation/context relations that independently position or orient represented coordinates: position, path, direction, containment, proximity, entry/exit, origin/destination, accompaniment, recurrence/context, internal/relational orientation, or materially spatialized figurative orientation.

Prefer a complete orientation phrase over a bare deictic when the relation is expressed by the phrase. Reject recipient/topic/purpose/possession/degree complements, generic adverbials, isolated `here/there/now` with no independent orientation job, and every-preposition behavior.

## 6. Type by represented job, not surface shape

Use one primary job unless the source genuinely establishes two independently selectable jobs:

- spatial support -> `PLACE`
- temporal period/support -> `TIME`
- represented human/social actor -> `PERSON`
- independently represented thing/content handle -> `OBJECT`
- target-bearing characterization/state/status/evaluation -> `LABEL`
- operative action/state/relation kernel -> `VERB`
- orientation/path/containment/direction/context relation -> `LOCATOR`

A noun-shaped phrase can be LABEL or another class; a verbal phrase can be OBJECT/content or LABEL; a spatial phrase can be OBJECT/content or LOCATOR rather than PLACE; a temporal phrase can orient rather than constitute TIME.

Cross-class duplication is allowed only when the source establishes two distinct researcher-selectable jobs, not because grammar permits multiple descriptions.

## 7. Primitive entitlement audit

Before compounds, replay the source once in order and audit each class.

For every emitted primitive ask:

1. What exact represented job makes this a standalone researcher coordinate?
2. What exact source nucleus or lawful unnamed-support cue entitles it?
3. Is the grain the smallest complete natural unit for that job?
4. Is it distinct after true coreference/restatement?
5. Is its class determined by source use rather than lexical appearance?

Then ask what was omitted:

- any represented actor/end point;
- any separately handled thing/content/part/internal handle;
- any target-bearing characterization/state;
- any operative relation kernel;
- any orientation relation;
- any materially differentiated spatial/temporal support, including a lawful unnamed support.

Restore a coordinate when it satisfies entitlement even if it is mundane or one-use. Remove a coordinate when its only justification is surface addressability, sentence structure, rhetorical vividness, or completion of an abstract scene template.

Freeze primitives after this audit.

## 8. Compounds after freeze only

A compound is a selective source-local material binding among two or more frozen primitive refs.

Build a compound when the source represents one relation/characterization/question/choice/report/reflection whose participating coordinates jointly form a coherent binding. Include only actual participants/endpoints/relation/support/orientation values needed for that binding. Split when actor set, target/content, source posture, support frame, or independently represented relation changes.

Do not create compounds to justify primitives. Do not create one compound per sentence, clause, lexical verb, primitive, phrase, or support. Do not create arbitrary co-occurrence, all-pairs links, scene mega-bundles, support chains, singleton equivalents, duplicate restatements, alternate subset/superset decompositions, or graph closure.

## 9. Qualities flag

`qualities_available` is only a yes/no indication that source qualities/descriptions exist for a coordinate. It does not replace LABEL and does not authorize a deeper APA parse.

## 10. Identity and ordering

Code owns canonical output IDs. Supply only neutral identity keys where requested. Order by first source establishment after coreference, subject to speaker-first PERSON and genuine broad-before-contained support ordering.
