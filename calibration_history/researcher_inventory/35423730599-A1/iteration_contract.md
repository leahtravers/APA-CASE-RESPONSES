## Prospective correction basis

Preserved V89 execution `35418642627-A1` passed both immutable Leah-approved Case 2 / Case 6 workbook SHA-256 gates and all deterministic apparatus checks before semantic calibration. Its first archetype then showed a broad, internally consistent failure: V89's primitive-entitlement/minimality rule treated the inventory too much like a minimal ontology. Source traces that remain useful editorial reconnection handles were suppressed when another primitive or compound already represented related material. A separate later fixture reached a backend agent session that remained in progress beyond the bounded wait; that runtime uncertainty is not semantic evidence and is corrected outside this contract.

V90 therefore makes one generalizable semantic correction:

> **COVERAGE-FIRST EDITORIAL ENTITLEMENT, THEN CLASS-NATIVE GRAIN. The Researcher Inventory is a lightweight source-reconnection index, not a minimal ontology. Retain every materially source-present trace that a researcher could independently select in the requested class to get back to a distinct source relation, referent, characterization, scene/frame, or orientation. Do not suppress a valid class handle merely because related material also appears in another class or in a compound. After coverage is established, use the smallest complete source-native wording appropriate to that class.**

This remains narrower than a token, grammar, modifier, or preposition census. A span must do an independently selectable editorial job in the requested class. Pure grammar, exact repeats/coreferent aliases, incidental fragments, and analyst-created abstractions remain excluded.

V90 does not expose approved archetypes, expected counts, evaluator findings, prior scored outputs, calibration answers, or sealed holdout content/output to the worker. All V89 and earlier contracts, runs, outputs, failures, and training records remain immutable historical evidence.

## Mission

Produce only the literal lightweight Researcher Inventory candidate requested by the schema.

Read the complete source. Recover source-native handles in exactly seven classes: PLACE, TIME, PERSON, OBJECT, LABEL, VERB, LOCATOR. Preserve literal language and source posture. Freeze primitives, then reconstruct the smallest useful source-local compounds that reconnect those primitives.

Do not perform APA scoring, protected-thread analysis, psychological interpretation, promotion, APA-ID creation, executive analysis, or sovereign/admitted writing.

## 1. Construction order

### Pass A — whole-source coverage ledger

Read the entire represented source before extracting any class. Silently track each materially represented:

- setting or occurrence-position;
- episode, period, recurrence, remembered frame, present frame, or prospective frame;
- human/social actor;
- concrete or abstract referent/content handle;
- characterization, value, state, status, manner, comparison, candidate label, rejection, or correction;
- action, relation, state, stance, cognition, report, intention, question, negation, or modality;
- spatial, path, containment, situational, comparative, internal, or recurring-context orientation.

Include actual, remembered, reported, relational, recurring, reflective, intended, questioned, hypothetical, negated, corrected, figurative, and prospective material when it is materially represented.

### Pass B — requested-class editorial entitlement

For each material source trace ask:

1. **Class job:** does this trace perform a recognizable job of the requested class in the source?
2. **Independent selection:** could a researcher reasonably select this trace in this class to reconnect to something materially distinct in the source, even if a related primitive exists elsewhere?

Retain when both answers are yes.

Do **not** ask whether another class or a compound already “covers” the meaning. Coverage elsewhere is not a reason to suppress a valid class-native handle.

### Pass C — duplicate and artifact suppression

Suppress only when the proposed primitive is one of these:

- a true coreferent/alias/repeated mention already represented by the same primitive;
- pure article, tense/aspect auxiliary, do-support, syntactic glue, or punctuation with no separately selectable source relation;
- a token fragment that has no meaningful class-native identity by itself;
- an incidental modifier or prepositional fragment that does not remain a useful class handle;
- an analyst-created abstraction the source does not itself represent;
- a discourse wrapper such as a generic “point,” “part,” “thing I said,” or similar shell when the source-tracked content underneath is the actual selectable referent and the wrapper is not independently revisited.

When uncertain between “lightweight useful trace” and “too minimal to preserve,” favor source-faithful recoverability while avoiding token census.

### Pass D — class-native grain

After entitlement, use the smallest **complete** source-native wording that preserves the class job.

Different classes may require different grain for the same source material. Cross-class overlap is allowed and expected when the same literal trace performs multiple independently useful jobs.

Do not force all classes into one primary semantic home.

### Pass E — literal lock, coreference, and order

Resolve true aliases/coreference while preserving separately represented actors and relations. Preserve source language, dialect, uncertainty, negation, comparison, and question posture. Order each class by first material source establishment, subject to broad-before-contained place navigation and speaker-first PERSON.

### Pass F — primitive freeze

Freeze the complete primitive inventory before compounds. Compounds may not create missing primitives or erase valid ones.

### Pass G — source-local compounds

Re-read the source and construct the smallest useful proposition/relation/state/report/intention/characterization bundles that reconnect frozen primitives. A compound represents one source-local binding, not an arbitrary graph closure.

## 2. Cross-class overlap rule

Cross-class overlap is legitimate whenever the same source trace performs distinct jobs.

Examples of the **kind** of overlap allowed, not case answers:

- a phrase may identify a PLACE position and also operate as a LABEL-like positional characterization;
- a movement phrase may be a VERB relation and a LOCATOR/path orientation;
- a source-staged state may be both a LABEL and part of a VERB relation;
- a recurring-context phrase may supply a TIME frame and a LOCATOR/context relation;
- a concrete destination can be a PLACE while the directional wording leading to it is a LOCATOR.

Do not manufacture overlap from grammar alone. Each projection must itself be useful for reconnection.

## 3. PLACE — settings and represented occurrence-positions

PLACE includes not only named locations but source-relevant positions needed to distinguish where represented material occurs.

Retain:

- explicit physical/institutional settings;
- contained locations when independently useful;
- materially represented object positions;
- destinations or offscreen positions materially implicated by movement toward/away from them;
- waiting/interaction positions when the source stages them as a distinct occurrence-position;
- remembered/reported conversation locations when a distinct represented scene exists but exact place is unstated;
- present-telling/reflection location when the current reporting scene is itself a distinct represented occurrence and exact place is unstated.

For an unnamed required position, use `source_wording: null` and anchor it with an exact source cue. The short tag may mechanically describe the occurrence-position without inventing substantive facts.

Do not create PLACE merely from every physical noun, surface, body part, path word, distance phrase, or figurative expression. The position must help distinguish source organization or navigation.

## 4. TIME — source-organizing episode and period frames

TIME is a distinct represented when-frame that organizes source material.

Retain materially distinct:

- attempts/conditions;
- response/help episodes;
- transitions/departures;
- waits;
- intended periods or modes of activity;
- later conversations/reports;
- recurring spans and relationship periods;
- remembered/comparison frames;
- broad life periods;
- present telling/reflection;
- future recurring or prospective periods implied by a represented forward-looking concern.

Do not create a TIME merely because a single contemplated action is hypothetical, because every action has tense, or because a duration/frequency word appears. A candidate action can remain VERB/OBJECT/LOCATOR without becoming a separate TIME unless the source stages an actual period/frame around it.

Several relations can share one TIME. Split when the source materially changes frame.

## 5. PERSON — represented actors and stable social groups

Retain `B` plus every distinct represented human/social actor or stable group after true coreference when the actor participates materially in the source, including:

- direct participants;
- minor/offscreen participants;
- possessive/relational actors;
- remembered/reported actors;
- prospective actors;
- institutional/social groups treated as actors.

Suppress only true aliases/coreferent repeats and nonreferential/rhetorical addressees.

## 6. OBJECT — source-represented referents and content handles

OBJECT is any source-treated thing or content handle that can be selected independently.

Retain as applicable:

- physical things and salient parts;
- products, documents, services, results, amounts, values, sets, categories;
- choices, decisions, next steps, plans, alternatives, or options when represented as selectable content;
- stable relations/practices/relationships treated as something the source is talking about;
- explicitly reified mental/content objects;
- figurative objects when the source gives them referential identity;
- represented situations, events, or “something happening” when the source itself turns them into a thing-like referent;
- internal containers or content-bearing objects such as a mind, memory, account, or similar source-reified locus when explicitly represented.

Do not nominalize every clause. Suppress generic discourse wrappers when their only function is to point toward more specific source content. Prefer the source-tracked content over a wrapper like “my point” or “that part” unless the wrapper itself remains independently tracked.

A source-reified event may be OBJECT even though its underlying action also appears as VERB/TIME. Cross-class overlap is allowed when both jobs remain useful.

## 7. LABEL — staged characterization, value, state, status, manner, or comparison

LABEL is broader than an adjective list and narrower than every modifier.

Retain a source span as LABEL when the source stages it as a selectable characterization of a person, object, relation, episode, position, action, or the speaker’s own posture.

This includes, as applicable:

- evaluative/state words and phrases;
- validity/status classifications;
- manner descriptions;
- positional characterizations when source-significant;
- identity/social labels;
- comparisons and metaphors used as characterizations;
- explicit candidate labels, including question-mark/uncertain candidates;
- explicit rejection/correction responses to candidate labels;
- source-staged continuing states;
- phrases whose exact negation is itself the characterization.

A LABEL may overlap a VERB or LOCATOR when the same source wording also expresses a relation or orientation.

Do not create a LABEL from every adjective, determiner, intensity word, or relational noun. The source must stage the characterization strongly enough that a researcher could independently select it.

Use the shortest complete exact source wording that preserves posture. Preserve question marks/uncertainty, negation, intensifiers, rejection, comparison, and dialect when identity-relevant.

## 8. VERB — represented relation edges, including stance/support when semantically active

VERB is a materially represented action, relation, state, stance, cognition, report, intention, question, modality, or happening that reconnects source coordinates.

Coverage precedes minimality. Retain semantically active relation heads even when they would be called “support,” “matrix,” “copular,” or “control” predicates in grammar.

Retain, when materially represented:

- location/existence relations;
- attempts and intentions;
- actions and movements;
- perception/cognition/reporting acts;
- embedded content relations when independently source-present;
- modal/obligation/expected-state relations;
- possession/having when it establishes a source relation;
- source-negated relations;
- source-questioned or hypothetical relations;
- comparison/figurative relations;
- sequential/coordinated relations when each does distinct source work.

Do not suppress a relation merely because a LABEL, OBJECT, PLACE, TIME, or LOCATOR also carries related material.

### Verb grain

Use the smallest complete source-native predicate wording that preserves the relation actually represented.

- Keep particles and complements that are part of predicate identity.
- Keep modal/negative posture when needed to preserve the represented relation.
- A semantically active copula/preposition combination may be a valid relation.
- A control/matrix predicate may be valid when it contributes intention, attempt, report, cognition, obligation, or stance rather than pure grammar.
- Split coordinated relations when the source presents separable edges; keep one phrase when splitting would destroy a single source-native relation.

Suppress only truly empty auxiliary support that contributes no independent relation.

## 9. LOCATOR — spatial, directional, situational, comparative, and contextual orientation

LOCATOR captures an independently useful orientation relation. It is not limited to bare geography.

Retain as applicable:

- setting relations (`at/in/on/...`) when useful independently of the PLACE;
- position/proximity;
- origin/destination;
- path/movement/entry/exit;
- movement toward a person/place or away from one;
- containment;
- accompaniment/carrying when orientational;
- recurring situational context that locates an action within a source practice;
- internal/mental orientation explicitly represented by the source;
- figurative/comparative orientation when the source uses it to position a referent;
- relative-distance/orientation constructions.

A LOCATOR may contain a verb phrase when the full construction is what supplies the orientation (for example, a directional/purpose construction). A LOCATOR may overlap a VERB, PLACE, TIME, or LABEL when its orientation job is independently useful.

Suppress only routine argument marking or phrase-internal prepositions that add no selectable orientation.

## 10. Literal-language lock

Every source-derived non-null `source_wording`, `source_cue`, `order_cue`, and source-near tag must preserve the source's actual language.

Do not repair grammar, normalize dialect, substitute synonyms, change numbers, expand contractions, or clean punctuation.

Unnamed PLACE/TIME support coordinates may use `source_wording: null`, anchored by exact source text.

`researcher_note` should be null or minimal mechanical/coreference bookkeeping. Do not use it to justify a semantic theory or reveal evaluator logic.

## 11. Q / qualities flag

`qualities_available` is a mechanical boolean indicating that source-present qualitative/descriptive material is available around the coordinate under the schema. It does not determine whether a LABEL exists and a LABEL does not automatically force a Q flag unless the source/schema supports it.

Preserve the source's actual availability of qualities rather than using Q as a confidence score.

## 12. Primitive freeze audit

Before compounds, inspect each retained primitive and the coverage ledger:

1. Did every materially represented class-native trace receive consideration?
2. Was any valid trace suppressed merely because another class or compound carries related meaning? If yes, restore it.
3. Is each primitive useful for independent source reconnection in this class?
4. Is the wording the smallest complete source-native class grain?
5. Are true duplicates/coreferents merged?
6. Are pure grammar/token fragments and analyst-created abstractions excluded?
7. Are unnamed PLACE/TIME support frames present where distinct source scenes/periods otherwise collapse?
8. Are cross-class overlaps preserved when each class job is independently useful?

Only after this audit freeze the units.

## 13. Compound reconstruction — proposition coverage without graph closure

Compounds reconnect frozen primitives into source-local propositions, events, states, reports, intentions, questions, comparisons, or relation clusters.

For each materially presented source binding:

1. identify the central relation/state/characterization;
2. include all frozen participants/referents materially belonging to that binding;
3. include the PLACE/TIME/LOCATOR/LABEL coordinates materially belonging to that binding;
4. include multiple VERBs when the source presents them as one tightly bound local relation cluster;
5. preserve source-local semantic order, although serialization order is not itself meaning;
6. set Q from source-present qualitative availability for the compound.

Do not create arbitrary pairwise closure. Do not emit every subset/superset permutation. Do not make broad scene mega-bundles spanning several separately presented propositions. Do not create a compound solely because two units happen to co-occur in a sentence.

A sentence may yield several compounds when it presents several independent relations. A single compound may include several class-overlapping primitives when all belong to the same source-local binding.

## 14. Final audit

Before returning, verify:

1. whole source read;
2. coverage-first editorial entitlement applied before minimality;
3. no valid primitive suppressed merely because meaning appears elsewhere;
4. cross-class overlap retained whenever it supplies a distinct selectable class job;
5. PLACE includes necessary scene/object/destination/wait/report/telling positions without physical-noun census;
6. TIME includes source-organizing frames but not every hypothetical action or tense marker;
7. PERSON includes all represented actors after true coreference;
8. OBJECT includes source-reified choices/relations/content while suppressing empty discourse wrappers;
9. LABEL includes staged states/manners/comparisons/candidate labels without modifier census;
10. VERB includes semantically active support/stance/copular/modal relations and preserves relation grain;
11. LOCATOR includes useful spatial/directional/contextual/internal/comparative orientations without preposition census;
12. literal wording, dialect, uncertainty, negation, and order preserved;
13. compounds use frozen units and cover source-local relations without graph closure;
14. candidate-only boundary preserved.

Never target hidden counts or infer hidden gold.

Clean-room certification requires the fresh agent to have no access to the retired agent's sessions or holdout output and to pass the holdout in a new session.
