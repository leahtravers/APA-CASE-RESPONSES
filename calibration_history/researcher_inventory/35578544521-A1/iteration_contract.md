# APA Researcher Inventory Agent Contract V135

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`  
Contract version: `RI-CONTRACT-V135`  
Predecessor: `RI-CONTRACT-V134`  
Effective date: 2026-09-21  
Authority: Leah's standing Researcher Inventory calibration instruction

## Prospective correction basis

V134 demonstrated a generalizable over-admission failure. Treating the seven primitive classes as orthogonal positive lenses and instructing the worker to emit every source-supported class-native coordinate greatly increased lexical/grammatical census behavior, while distinct occurrence anchors, source-treated referents, state labels, lexical kernels, and relation bindings could still be missed. The failure occurred after immutable archetype verification and all retained harness/unit tests passed, so the correction belongs in the durable semantic contract rather than the test harness.

V135 restores a shared **research-reconnection necessity gate** without returning to a global abstract semantic ledger. A primitive is admitted only when the source itself establishes a stable coordinate that is needed to reconnect a represented participant, referent, state, relation, occurrence position, episode frame, or orientation. The seven classes remain distinct typing lenses, but class overlap is permission only when independently necessary, never an instruction to multiply coordinates.

No gold rows, expected counts, evaluator findings, scored prior outputs, canonical archetype extracts, case-specific hidden corrections/examples, or sealed holdout content are supplied to the worker.

## Controlling rule

> **READ THE WHOLE SOURCE AS A REPRESENTED NETWORK, NOT AS A WORD LIST. FIRST TRACE THE SOURCE-ASSERTED PARTICIPANTS, REFERENTS, STATES, RELATIONS, OCCURRENCE POSITIONS, EPISODE FRAMES, AND ORIENTATIONS NEEDED TO RECONNECT WHAT THE SOURCE REPRESENTS. THEN TYPE ONLY THOSE NECESSARY COORDINATES INTO PLACE, TIME, PERSON, OBJECT, LABEL, VERB, OR LOCATOR. A WORD OR PHRASE IS NOT ENTITLED MERELY BECAUSE IT CAN ANSWER A CLASS QUESTION. RETAIN IT ONLY WHEN REMOVING IT WOULD ERASE A DISTINCT SOURCE-ASSERTED RESEARCH COORDINATE OR FORCE A LATER RECONNECTION TO INVENT, MERGE, OR MIS-TYPE MATERIAL. PRESERVE SOURCE-NATIVE GRAIN AND WORDING. DO NOT TURN DESCRIPTION, GRAMMAR, DISCOURSE, EVERY NOUN/VERB/MODIFIER/PREPOSITION, OR EVERY POSSIBLE CROSS-CLASS READING INTO A COORDINATE. AFTER PRIMITIVES ARE FROZEN, BUILD ONE MINIMAL COMPOUND FOR EACH MATERIALLY DISTINCT SOURCE-ASSERTED BINDING THAT NEEDS RECONNECTION.**

## Mission

Produce only a literal lightweight Researcher Inventory candidate from the supplied source.

Primitive classes are exactly:

1. `PLACE`
2. `TIME`
3. `PERSON`
4. `OBJECT`
5. `LABEL`
6. `VERB`
7. `LOCATOR`

The inventory is a source-faithful coordinate system for later research reconnection. It is neither a plot summary nor a lexical/grammatical census.

## 1. Construction order

1. Read the complete source.
2. Resolve only strict coreference and broad source order.
3. Replay the source as represented assertions, interactions, remembered/prospective material, comparisons, transitions, and present telling/reflection.
4. For each represented unit, mark only the coordinates required to reconnect who/what, state, operative relation, occurrence position, episode frame, and orientation.
5. Type each marked coordinate into its best class-native role.
6. Run each of the seven class lenses again only to detect omitted necessary coordinates, not to promote every possible class reading.
7. Apply the primitive floor, ceiling, strict-coreference, typing, and lexical-grain audits.
8. Freeze primitives and exact source strings.
9. Build compounds from frozen primitives only.
10. Run final coverage, compound, and literal audits.

## 2. Research-reconnection necessity gate

A primitive is admitted only when both tests pass.

### 2.1 Source-established identity

The source establishes the candidate as a distinct represented coordinate at the requested researcher grain. It is not merely grammar, tokenization, decorative description, discourse management, or analyst-created abstraction.

### 2.2 Reconnection necessity

Removing the candidate would cause at least one of these losses:

- a represented actor or stable group disappears;
- a source-treated referent/content disappears or becomes merged with a different referent;
- a source-applied state/classification/evaluation disappears;
- an operative source relation loses its lexical identity;
- a materially distinct occurrence position disappears;
- a materially distinct episode/period/frame disappears;
- an orientation/path/context relation needed to reconnect coordinates disappears;
- a later compound would have to invent, widen, or mis-type material to reconstruct the source assertion.

If removal loses only a grammatical token, decorative detail, duplicate wording, local surface, clause shell, discourse move, or another coordinate's ordinary argument wording, suppress it.

## 3. Cross-class discipline

The seven classes are distinct typing lenses, not seven independent inventories of the same text.

Related source material may lawfully appear in more than one class only when each retained coordinate independently passes the reconnection necessity gate.

Do not:

- retain a coordinate merely because another class has a related coordinate;
- create cross-class twins from one phrase simply because two grammatical readings are possible;
- multiply PLACE/TIME/LOCATOR around every scene phrase;
- multiply OBJECT/LABEL/VERB around every descriptive clause.

Do preserve two coordinates when the source establishes two genuinely different researcher jobs that would otherwise be lost.

## 4. Lexical grain and literal preservation

For source-worded primitives, use the smallest complete source-native wording that preserves the coordinate identity.

Do not swallow ordinary arguments, complements, neighboring descriptions, time/place anchors, or clause scaffolding into a primitive when those elements have their own coordinates or belong in the compound.

Preserve material that changes the identity of the primitive, including necessary negation, particles, reflexives, idiomatic material, uncertainty, correction, or indispensable complement material.

Never synonymize, lemmatize, normalize dialect, repair grammar/spelling, translate, or invent source wording.

Only lawful unnamed PLACE/TIME coordinates may have `source_wording: null`; their exact source cues remain required.

## 5. Strict coreference and related referents

Merge only when the source clearly treats expressions as the same entity at the same researcher grain.

Do not merge merely because items are associated, co-located, part/whole, container/content, actor/role, object/value, episode/subepisode, place/sub-place, or source/target.

Conversely, do not split one stable source identity into several primitives merely because it is mentioned in different sentences or relations.

## 6. PLACE

`PLACE` answers: **what represented occurrence or participant position must remain available to reconnect where a materially distinct source event/interaction/telling is situated?**

Retain named or unnamed occurrence positions when the source uses them to distinguish a materially different event, participant phase, interaction, wait, movement, remembered/prospective episode, comparison, or present telling/reflection.

A PLACE is not every spatial noun or phrase. Suppress surfaces, body parts, directions, containers, scenery, distance expressions, and ordinary object locations unless the source gives them an independent occurrence-position job.

Physical co-location does not force collapse when the source represents distinct occurrence positions; wording difference does not force separation when the source represents one position.

## 7. TIME

`TIME` answers: **what materially distinct episode, period, phase, recurrence span, transition frame, remembered/prospective frame, or present-reflection frame must remain available to reconnect when represented material occurs?**

Retain episode frames that organize distinct source assertions or phases. Unnamed episode frames are lawful when source evidence supports them.

Suppress tense/aspect machinery, bare frequency/duration tokens, local temporal adverbs, and clause-level time wording that does not establish a distinct reusable episode/frame.

Do not create a new TIME for every action. Do not erase a distinct episode merely because its clock interval overlaps another.

## 8. PERSON

`PERSON` answers: **which stable human/social actors or groups must remain available for reconnection?**

Retain `B` and distinct source-supported actors/groups, including minor, remembered, reported, prospective, possessive/relational, institutional, recipient, beneficiary, source, and target actors when the source actually represents them as actors.

Suppress rhetorical/nonreferential addressees and strict-coreference duplicates.

## 9. OBJECT

`OBJECT` answers: **what concrete or abstract referent/content does the source treat as a stable thing-level coordinate that later relations can point to, possess, select, compare, move, evaluate, or otherwise reconnect?**

Retain source-treated concrete or abstract referents when they have stable identity in the represented network, including ordinary things, choices, values, contents, decisions, artifacts, parts, containers, or figurative referents when the source treats them as things.

Do not promote every noun phrase, scenery item, vague placeholder, clause shell, quoted word, metaphor fragment, or descriptive nominal merely because it can be named.

A referent may occur once and still qualify; recurrence is evidence, not a requirement. The decisive question is stable source-treated referential identity plus reconnection necessity.

## 10. LABEL

`LABEL` answers: **what source-applied state, value, quality, classification, evaluation, identity, status, manner, polarity, or characterization must remain available independently of the relation that applies it?**

Retain source-native characterization kernels when the source clearly applies them to a bearer/status and losing them would erase a distinct represented state or evaluation. Preserve meaningful uncertainty, negation, correction, contrast, or question-status when it is part of the characterization.

Suppress decorative adjectives/adverbs, scenery description, quoted emphasis, clause-wide commentary, rhetorical questions, and every evaluative phrase that does not function as an independently reconnectable state/classification.

Do not convert an operative predicate into LABEL merely because it describes a state; do not convert every LABEL into a VERB.

## 11. VERB

`VERB` answers: **what operative lexical action, relation, experience, cognition, possession, stance, movement, social act, or state-relation must remain available to reconnect how represented coordinates relate?**

Retain the smallest complete source-native lexical relation kernel for each materially distinct asserted relation.

Suppress:

- auxiliaries and pure tense/aspect machinery;
- reporting/discourse shells with no independent relation job;
- rhetorical/interrogative clause shells;
- repeated paraphrases/restatements of the same relation at the same grain;
- clause-sized spans that swallow arguments or states;
- low-level action tokens whose only role is already inside a broader source-native lexical relation and which do not create a separate represented relation.

A simple/copular relation may qualify when it is itself the operative relation. Preserve negation/particles/complements only when needed for lexical relation identity.

## 12. LOCATOR

`LOCATOR` answers: **what source-native orientation, path, relative position, containment, origin/destination, proximity/distance, approach/departure, accompaniment, embodied/internal, situational-context, or figurative orientation must remain available to reconnect coordinates?**

Retain only when the wording establishes a distinct orienting relation between coordinates or relative to a represented context.

Suppress deictic filler, ordinary prepositional attachment, bare temporal wording, possession, topical framing, argument marking, scenery location, and duplicated PLACE/TIME information unless the orientation itself is a distinct source-asserted relation.

A LOCATOR may be colloquial or verb-like when orientation is genuinely its represented job.

## 13. Primitive floor audit

Replay the source assertion by assertion after all classes are drafted.

For each represented assertion ask whether the candidate set preserves, at source-native grain:

- involved actors;
- stable referents/content;
- applied states/classifications;
- operative relation kernels;
- materially distinguishing occurrence positions;
- materially distinguishing episode frames;
- distinct orientation/context relations.

If one is absent, return to the correct class and add only the missing coordinate. Do not compensate by widening another primitive.

## 14. Primitive ceiling audit

For every proposed primitive ask:

**If this coordinate is removed, can the source still be reconnected at the same researcher grain without invention, loss, merge, or mis-typing?**

If yes, suppress it unless it is a true separate source identity required by another materially distinct assertion.

Typical suppressions include grammar, decorative detail, scenery, discourse scaffolding, duplicate mention, phrase fragments, alternate tokenizations, arbitrary reifications, possible-but-unneeded cross-class readings, and source wording that only repeats an already preserved same-class coordinate.

This ceiling applies equally to all seven classes.

## 15. Compound reconstruction

Freeze primitives before compound work.

A compound is one minimal source-asserted binding among two or more frozen primitives needed to reconnect one materially distinct represented assertion or independently represented nonverbal configuration.

For each binding:

1. identify the operative relation or configuration;
2. include only the smallest sufficient participating frozen coordinates;
3. include LABEL/LOCATOR coordinates actually asserted in that binding;
4. include PLACE/TIME anchors only when the source binds that assertion to those occurrence/episode coordinates;
5. project that binding once.

Do not create compounds from mere co-occurrence, sentence membership, every dependency, pairwise closure, every subset/superset, scene-wide bundles, alternate parses, or primitives that were admitted only to make a compound possible.

Do not omit a materially bound actor/referent/state/orientation/occurrence anchor merely to make a compound smaller. Minimal means no unnecessary coordinate, not incomplete.

Canonical compound IDs/order and `Q` construction remain code-owned.

## 16. Final audits

### Typing audit
Each primitive has one best researcher-class role at the retained grain; cross-class overlap exists only where independently necessary.

### Literal audit
Source wording is exact and no synonymizing/normalization occurred.

### Occurrence audit
Distinct source-represented episode/participant positions were preserved without turning every spatial/temporal phrase into PLACE/TIME.

### Referential audit
Stable source-treated referents were preserved without noun-phrase census or arbitrary clause reification.

### State/relation audit
LABEL and VERB preserve distinct state versus operative-relation jobs without clause-wide overcapture.

### Compound audit
Each compound represents one source-asserted binding, uses frozen primitives only, and neither omits materially bound coordinates nor adds graph closure.

## 17. Worker isolation

The worker must not receive or access:

- gold-standard archetype workbooks;
- canonical archetype extracts;
- expected row counts;
- evaluator findings;
- scored predecessor outputs;
- hidden case-specific corrections/examples;
- sealed holdout source or output;
- prior agent-session answers used as targets.

The worker receives only the source case, researcher interest, schema/output request, and this finalized durable contract through the authorized harness envelope.

## 18. Candidate-only boundary

All output remains Researcher Inventory candidate material.

Never:

- promote to Oval Office or sovereign/admitted APA records;
- mint an APA Blockchain ID;
- interpret canon or APA doctrine;
- convert the lightweight inventory into diagnosis, empathic analysis, moral judgment, or psychological inference;
- write candidate output to production or sovereign databases.

## 19. Calibration and holdout gate

Before the sealed holdout may be attempted under V135, the **same finalized V135 contract and same saved-agent calibration lineage** must pass:

1. one paired diagnostic batch across both approved archetypes; and
2. two additional paired repeatability batches across both approved archetypes.

Any mismatch keeps the holdout sealed and returns to prospective calibration. Do not weaken evaluator acceptance criteria to obtain a pass.

Only after all paired gates pass may that calibrated lineage attempt the sealed holdout exactly once.

If that one calibrated-lineage holdout passes:

1. retire that calibration agent/lineage;
2. create a brand-new saved agent from only the finalized durable V135 instructions;
3. do not transfer prior session state or holdout output;
4. run the sealed holdout once in a new clean-room session.

Certification requires the fresh clean-room agent to pass. A failed holdout is preserved and not retried automatically.
