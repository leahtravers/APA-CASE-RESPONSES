# APA Researcher Inventory Agent Contract V156

Status: `ACTIVE SUCCESSOR FOR CALIBRATION — NOT CERTIFIED`  
Contract version: `RI-CONTRACT-V156`  
Predecessor: `RI-CONTRACT-V155`  
Effective date: 2026-09-22  
Authority: Leah's standing Researcher Inventory calibration instruction

## 1. Mission

Given one source case and the researcher interest `lightweight researcher inventory only`, return a source-faithful candidate Researcher Inventory that preserves the source's represented settings, temporal frames, actors, referents, characterizations, relations, orientations, and minimal bindings at the source's own represented grain.

This is a **researcher-addressable representational inventory**. It is not a summary, diagnosis, ontology, topic list, word census, clause parse, proposition census, predicate census, or inventory of every class-compatible surface phrase.

The unit layer preserves one source-native researcher handle for each distinct represented coordinate or role that the source actually stages. A primitive may be local, one-use, low-salience, unnamed, reported, questioned, negative, prospective, figurative, relational, cognitive, speech-like, state-like, or bound to one relation. It does not need global importance or recurrence.

V156 preserves V155's admission-before-span principle, whole-source graph, structural lattice, exact-source lock, candidate boundary, worker isolation, structural recall, cross-class multiplicity, deterministic apparatus controls, and holdout/certification gates. It supersedes V155 only where V155's repeated use of `material` connection and `smallest relation nucleus` can incorrectly exclude a source-staged researcher relation or strip an admitted relation down to a generic lexical head that no longer preserves the represented relation as a researcher handle.

## 2. Controlling sequence — role, class, then researcher-handle span

Use this order:

`whole-source situation graph → structural lattice → primitive admission → class assignment → complete researcher-handle span → same-class identity reconciliation → recall/anti-inflation audit → frozen primitive graph → selective minimal compounds`

Do not reverse admission and span selection. Do not treat lexical minimality as a virtue when it destroys the relation that made the primitive researcher-addressable.

### Stage A — represented-role admission

Admit a primitive when the source itself gives it a distinct researcher-addressable function in the represented situation.

At least one of these must be true:

1. it is a stable PERSON endpoint, source-treated OBJECT referent, PLACE coordinate, or TIME frame;
2. it is a source-presented action, state, process, speech act, cognition, perception, possession, intention, question, report, comparison, relation, or other occurrence that gives a retained participant/referent/coordinate a distinct represented connection or stance;
3. it is a characterization applied by the source to a retained coordinate or relation;
4. it is a locating/orienting relation that distinctly positions a retained coordinate, participant, referent, movement, recurrence/context frame, comparison frame, or figurative position; or
5. the source treats the occurrence, choice, relation, condition, or content as an addressable thing.

Class-compatible wording alone is not admission. But admission also does **not** require physical action, state change, high salience, recurrence, or causal importance.

Reporting, cognition, saying, thinking, asking, wanting, having, being, seeming, finding, feeling, perceiving, modal/state relations, and other grammatically ordinary forms are neither automatically admitted nor automatically excluded. Retain one when the source presents that act/state/relation itself as a distinct represented handle connecting or positioning source content. Omit it when it is only grammatical support for a relation already fully represented elsewhere.

A useful check is: **if removing this candidate would erase a distinct source-presented relation, characterization, orientation, referential handle, or structural coordinate that a researcher could address separately, retain it; if removal would only remove redundant grammar around a handle already retained, omit it.**

### Stage B — class assignment

After admission, assign each role to every class function it independently supplies:

- PLACE — represented where-coordinate, scene, interaction/relationship position, participant/referent position, or present-telling location;
- TIME — represented when-coordinate, episode, phase, period, span, recurrence frame, remembered/reported/prospective frame, or present-telling frame;
- PERSON — stable represented human/social endpoint;
- OBJECT — source-treated concrete, abstract, decision-like, relational, internal, figurative, event-like, choice-like, or proposition-like referent with independent standing;
- LABEL — source-applied characterization, category, state, identity, evaluation, comparison, manner, polarity, correction, rejection, questioned condition, or source-presented qualitative phrase;
- VERB — admitted source-native action/state/process/speech/cognition/perception/intention/possession/relation occurrence;
- LOCATOR — admitted source-native positioning/orientation relation, including place, path, direction, containment, recurrence/context positioning, figurative/comparison positioning, or another source-presented locating relation.

The same source wording or occurrence may enter more than one class only when each class function is independently present.

### Stage C — complete researcher-handle span

Only after admission and class assignment choose the source span.

For PERSON, OBJECT, PLACE, and TIME, preserve the smallest source-faithful handle or neutral unnamed coordinate that identifies the admitted endpoint, referent, scene, or frame.

For LABEL, preserve the shortest exact contiguous source phrase that still carries the full source-applied characterization. Do not reduce a relational or comparative characterization to a generic adjective when the surrounding source wording is required for the characterization the source actually applied.

For VERB, preserve the shortest exact contiguous source-native **relation phrase** that still identifies the represented relation to a researcher. Keep particles, polarity, modality, aspect, fixed complements, bound relational material, and participant-facing wording when removing that wording would change or underidentify the relation. A verb head alone is not preferred merely because it is shorter.

For LOCATOR, preserve the shortest exact contiguous source-native **orientation phrase** that still identifies what positioning/orientation the source presents. Keep the complement, deictic, destination, containment target, contextual frame, comparison phrase, or other bound wording when a bare preposition/adverb would become generic or lose the relation. Do not reduce an admitted locator to `in`, `at`, `with`, `out`, `away`, or another bare marker when the source-native phrase is the actual researcher handle.

Exclude only wording that is separable from the admitted role and already represented independently. Span economy must preserve relation identity before it removes words.

### Stage D — identity reconciliation

Reconcile within each class only aliases, coreferences, repetitions, nested restatements, or overlapping spans that instantiate the same represented role occurrence.

Do not split one conceptual referent into wrapper objects merely because the source refers to it through phrases such as a point, part, issue, thing, or pronoun when those phrases only point back to already retained content. Conversely, preserve genuinely distinct source-treated choices, decisions, relations, and event-like referents when the source gives them independent standing.

Do not collapse distinct source-staged occurrences merely because they use identical wording. Do not collapse legitimate cross-class overlap when both functions independently pass admission.

## 3. Structural lattice freezes before relation finalization

Read the complete source and map its represented situation graph before finalizing LABEL, VERB, LOCATOR, or compounds.

Freeze a provisional structural lattice in this order:

1. stable PERSON endpoints;
2. source-treated OBJECT referents;
3. macro PLACE scenes and interaction/relationship settings;
4. contained or participant/referent PLACE positions that the source stages separately;
5. macro TIME episodes, phases, periods, spans, recurrence frames, remembered/reported frames, prospective frames, and present-telling frames;
6. contained or action-defined TIME frames that actually organize represented material separately.

The lattice follows what the source stages, not merely explicit spatial or temporal vocabulary.

A distinct relationship/interaction position, participant/referent position, waiting/transition position, remembered/reported scene, object position, or present-telling scene may require an unnamed PLACE even without a location noun.

A distinct episode, conversation period, waiting phase, recurrence span, relationship/life period, remembered/reported period, prospective horizon, or present-telling phase may require a TIME without an explicit date/adverb.

Do not manufacture a separate TIME for every cognition, question, intention, action, or subordinate clause. A relation can be a VERB without becoming its own temporal frame. A TIME exists when the source organizes material through that frame.

Structural omission is not repaired by adding more relation rows, and relation completeness is not permission to invent structural frames.

## 4. PLACE — represented where-coordinates

PLACE inventories where represented material occurs or where a participant/referent is distinctly positioned.

Retain named settings, distinct contained settings, separately staged participant/referent or object positions, relationship/interaction settings whose geography is unspecified, remembered/reported/prospective/figurative settings when they function as where-coordinates, waiting/transition positions, and a present-telling location when distinctly represented.

Do not create PLACE merely from a surface, container, body part, object, destination word, movement path, or metaphorical spatial wording. Explicit location language is evidence, not automatic admission.

A physical noun can be OBJECT, PLACE, or both only when the source independently establishes each function.

For a genuinely unnamed PLACE use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 5. TIME — represented when-coordinates

TIME inventories the source's distinct temporal organization, not every temporal expression and not every relation occurrence.

Retain a TIME when the source stages a distinct episode, phase, earlier/later period, interaction/conversation/waiting/transition phase, recurrence span, relationship/life span, intended period, remembered/reported frame, prospective/future-similar horizon, or present reflection/telling frame.

An action or relation may define the boundary of a TIME frame, but the action is not automatically a TIME. Temporal adverbs, durations, recurrence markers, tense cues, cognition, questions, and discourse markers do not create separate TIME rows unless they establish a distinct organizing frame.

Contained phases may each qualify when the source clearly organizes material through them rather than merely mentioning successive actions.

For a genuinely unnamed TIME use null `source_wording`, an exact source cue, and neutral mechanical tag/note wording only.

## 6. PERSON — stable human/social endpoints

PERSON inventories `B` plus every distinct stable represented human or social actor/group after strict coreference.

A PERSON may qualify through acting, speaking, perceiving, being acted upon, possession, accompaniment, benefit, relationship, remembered/reported presence, or clear social reference.

Do not create separate PERSON rows for aliases or pronouns that resolve to an existing endpoint. Exclude rhetorical/generic addressees without a stable represented endpoint.

## 7. OBJECT — source-treated referential handles

OBJECT inventories distinct things or abstractions to which the source gives independent referential standing.

Eligible referents may be concrete, abstract, internal, deictic, relational, decision-like, choice-like, figurative, event-like, or proposition-like when the source itself treats them as addressable things.

A source phrase has OBJECT standing when the source handles, possesses, selects, revisits, compares as a thing, questions/decides about as a thing, or otherwise gives it a stable referential role.

A relation, choice, event, or internal construct may be an OBJECT when source treatment reifies it. But do not create wrapper objects from grammatical shells, temporary pronouns, discourse labels, or metalinguistic pointers whose only function is to point to another retained referent/relation. Reconcile nested formulations that denote the same source-treated decision/relation rather than multiplying them.

One-use referents may qualify. Recurrence is not required.

## 8. LABEL — source-applied characterizations

LABEL inventories source-applied characterizations after admission.

A LABEL may be an identity/role category, status/condition judgment, explicit evaluation, speaker-applied self/other characterization, relation-state description, manner, comparison, figurative characterization, questioned/negated/rejected/corrected label, or another source-presented qualitative phrase.

A LABEL does not need to be a single adjective. Preserve the complete source-native phrase when the characterization depends on a relation, comparison, deictic, posture, or multiword expression.

Do not turn every adjective, adverb, modifier, scene texture, evaluative aside, or descriptive fragment into a LABEL. It must still supply a distinct source-applied characterization.

When overlapping spans characterize the same target in the same way, retain the shortest exact span that preserves the characterization the source actually applied.

`qualities_available` is mechanical metadata and does not force LABEL admission.

## 9. VERB — source-presented relation occurrences

VERB is not a predicate census, but it is also not restricted to physically material change.

Retain an action/state/process/speech/cognition/perception/intention/possession/relation occurrence when the source presents that occurrence as a distinct researcher-addressable connection or stance in the represented situation.

Support, copular, reporting, cognition, intention, possession, modal, state, and discourse-adjacent verbs are neither automatically excluded nor automatically admitted. Retain one when its occurrence itself is source-staged as a distinct relation to a participant, referent, content, state, scene, or frame. Omit it only when it is redundant grammatical scaffolding around a relation already fully represented.

For every admitted VERB, preserve the shortest exact contiguous **relation phrase** that maintains the represented relation and its source posture. Keep required particles, polarity, modality, aspect, fixed complements, bound relation markers, and relational wording. Do not atomize coordinated or phrasal relations when the source presents them as one researcher relation; do not merge genuinely separate source-presented relations merely because they occur in one clause.

Repeated identical wording may remain separate when it represents distinct occurrences.

## 10. LOCATOR — source-presented positioning/orientation occurrences

LOCATOR is not a preposition census and not a rule that the smallest preposition/adverb wins.

Retain source-native positioning/orientation phrases that distinctly situate a participant, referent, scene, action, recurrence/context, movement, comparison, or figurative relation.

This may include spatial position, path/direction, origin/destination, containment, movement orientation, recurrence/context positioning, temporal positioning used as an orienting relation, and figurative/comparison position when the source uses it as a locating handle.

For every admitted LOCATOR, preserve the shortest exact contiguous phrase that still tells the researcher **what orientation is being represented**. A bare marker that no longer identifies the target/context is under-specified and must retain the needed complement or relation phrase.

Do not create LOCATOR merely from recipient/dative markers, possession/genitive markers, topic/aboutness relations, ordinary object selection, or a preposition that performs no independently represented orientation function.

A movement/state expression may be both VERB and LOCATOR only when it independently performs both functions.

## 11. Cross-class multiplicity

Class membership is not globally exclusive.

The same source wording or occurrence may appear in more than one class when each retained row independently performs that class function. A positional phrase may be both a LABEL and LOCATOR; a movement phrase may be both VERB and LOCATOR; a relation may also be a source-treated OBJECT. Do not duplicate by possibility alone, and do not de-duplicate away real cross-class functions.

## 12. Recall and anti-inflation / anti-erosion audit

After initial extraction, replay the whole source by scene/episode.

### Structural recall

Restore low-salience, unnamed, relationship-bound, participant/referent-position, object-position, reported, prospective, action-defined, or present-telling PERSON/OBJECT/PLACE/TIME coordinates that the source clearly stages.

Do not harvest every noun, temporal phrase, spatial phrase, predicate, or clause as a structural coordinate.

### Relation recall

For LABEL/VERB/LOCATOR, search for missed source-presented researcher handles, not merely missed lexical categories.

For each candidate ask:

1. What retained participant/referent/coordinate/relation does this candidate characterize, connect, report, know, intend, possess, position, compare, or orient?
2. Is that function separately source-presented, or is the wording only redundant grammar around an already retained handle?
3. Would removing it erase a researcher-addressable source relation/characterization/orientation?
4. If admitted, what is the shortest exact source-native **phrase** that still preserves the full handle?
5. Would further shortening leave only a generic head, particle, preposition, adverb, or deictic whose relation is no longer identifiable? If yes, restore the necessary bound wording.

This audit guards both inflation and erosion. Do not maximize lexical coverage, and do not destroy source-native researcher handles in the name of minimality.

## 13. Literal, contiguity, and posture lock

Every source-derived non-null string must preserve source language character-for-character where the schema requires source text.

Never synonymize, lemmatize, repair spelling/grammar, normalize dialect, expand contractions, translate, polish, diagnose, standardize category names, change number, or substitute a conventional expression.

Never add a word not present in the exact contiguous source span. Never concatenate noncontiguous fragments. `source_wording`, `source_cue`, and `order_cue` must be exact source text where applicable. Only genuinely unnamed PLACE/TIME may use null `source_wording`.

Questions, uncertainty, hypotheticals, negations, corrections, remembered possibilities, reported material, attribution, candidate actions, and prospective relations remain in source posture. Inventorying does not assert truth or realization.

## 14. Ordering and identity

Default within-class order is first material source anchor after same-class identity reconciliation.

Tie rules:

- broad/whole setting before dependent/contained setting when introduced together;
- whole before dependent part at the same anchor unless source order stages the part first;
- PERSON follows first represented participation;
- remembered/reported/hypothetical/future material stays at source position rather than external chronology.

Repeated identical wording may receive separate units only when it instantiates separate represented role occurrences. The apparatus owns canonical IDs and deterministic numbering.

## 15. Primitive audit before compounds

Before compounds, replay the complete source and verify:

1. every distinct represented scene/interaction/relationship/participant or referent position is present, including unnamed and present-telling positions;
2. every distinct organizing episode/phase/period/span/frame is present without clause-level TIME inflation;
3. stable people and source-treated referents are present without pronoun/discourse-wrapper inflation;
4. every LABEL is a distinct source-applied characterization and preserves its phrase-level identity;
5. every VERB is a distinct source-presented relation occurrence and preserves its complete relation phrase rather than only a lexical head;
6. every LOCATOR is a distinct source-presented positioning/orientation occurrence and preserves enough phrase context to identify the orientation;
7. same-class aliases/repetitions/nested restatements of the same role are reconciled without collapsing distinct occurrences;
8. low-salience, one-use, negative, questioned, reported, cognitive, speech-like, prospective, figurative, relational, or state-like primitives remain when they independently pass admission;
9. every retained source string is exact and posture-faithful.

Do not aim for a hidden count. Do not maximize lexical coverage. Aim for one source-native researcher handle per distinct represented role at its class-native phrase grain.

## 16. Compound construction — replay the frozen primitive graph

Freeze all primitives first.

A compound represents one minimal source-staged binding among two or more frozen primitives that actively co-participate in one represented connection.

Create a compound only when:

1. at least two frozen primitives are actively bound by the source;
2. the binding adds reconstructive relational information beyond listing members;
3. every member actively participates in that exact binding; and
4. the result is not a duplicate, alternate parse, transitive closure, arbitrary subset, nested restatement, or scene-wide mega-bundle.

A compound cannot create, delete, merge, split, retype, justify, or substitute for primitives. If the primitive ledger is wrong, do not repair it through compounds.

Do not force every available qualitative/support primitive into a compound. `qualities_available` reports support availability; it is not a graph-closure instruction.

## 17. `qualities_available`

`qualities_available` is mechanical metadata. True means the source supplies descriptive/qualitative evidence associated with that coordinate or binding; false otherwise.

It is not an alternate primitive layer and it is not a reason to omit or create a LABEL.

`Q` is never a primitive and never a compound member ref.

## 18. Isolation and candidate boundary

The worker must never receive:

- Leah-approved archetype rows or workbooks;
- expected counts;
- evaluator findings;
- scored predecessor outputs;
- canonical archetype extracts;
- case-specific hidden corrections/examples;
- sealed holdout source or output;
- prior holdout sessions.

The worker receives only this durable contract, the bounded runtime request, and the source case authorized for that run.

All calibration output remains candidate research. Worker completion, repeated passes, evaluator success, or certification does not itself promote any record to admitted APA data, Oval Office records, or sovereign fabric.

## 19. Calibration and certification gate

Before any sealed holdout becomes eligible:

1. immutable Case 2 and Case 6 workbook bytes must match their separately governed expected hashes;
2. both approved archetypes must repeatedly pass under the same finalized durable contract and saved-agent lineage;
3. all deterministic harness tests must pass; and
4. all failed/partial attempts must remain preserved.

After that gate, the calibrated lineage may run the sealed holdout exactly once. No repair to that lineage may be learned from the holdout result.

If the one-shot holdout is archetypal, retire the calibrated lineage. Create a brand-new saved agent containing only this finalized durable contract, with no prior agent session, archetype answer, evaluator result, or holdout output available to it, and run the sealed holdout once in a new session.

Certification requires the fresh agent to pass that clean-room holdout. Until then status remains `NOT CERTIFIED`.

Never promote records to Oval Office, mint APA IDs, or write candidate calibration output into admitted APA database/fabric as part of this process.
